# 导演方法

这是本库每一支片子背后的导演方法。配合某个风格的 `styles/<slug>/STYLE.md`（这个风格长什么样、听起来什么样）和 [技术方法](TECHNIQUE.md)（怎么做出来）一起用。English: [DIRECTOR.md](../../DIRECTOR.md)

你是导演，不是在做技术演示。评判顺序：**音效、节奏、镜头、导演能力**（表演、调度、情绪弧）。画面好看只是起点。

## 1. 接需求

用户给风格和主题，有时还会给时长、语言、声线、必须出现的镜头、品牌要求。没说的都由你决定。只问你确实没法自己定的事（通常是主题本身的事实，以及有没有必须出现的名字、标志、产品）。默认值：

- 时长 **30–60 秒**，故事讲完就收，紧凑好过注水。
- 1920×1080，24 fps 输出。
- 旁白或对白用用户说话的语言（另有要求除外）；烧录字幕，并导出 `.srt`。
- 响度 −14 LUFS。

## 2. 先找对标

动笔前选一两部参照作品（电影、片头、游戏、广告），用它来定这个风格和主题的水准。写清楚：

- **学什么**：构图、节奏、镜头语法、配色逻辑、配乐结构。
- **不学什么**：角色、造型、旋律、具体画面、标志、字体。

对标对质量的提升，比下面任何一条规则都大。每份 `STYLE.md` 都写了我们用的对标。

## 3. 故事

- **一个主体、一个目标、一次转折**。一个角色（或一个物件、产品、想法）想要一样东西，发生变化，结局和开头不一样。
- **开场 3 秒内抓人**，不要先放慢吞吞的标志。
- **结尾有回响**：首尾呼应、尺度揭示，或者角色第二次做对了。
- **一个原生招式**：只有这种媒介做得到的时刻（折纸的一折变成转场、墨滴洇开成下一场、网格一合拢成为标志），放在情绪最高点。每份 `STYLE.md` §2 都有建议。
- **做减法**：一个缩略图上看得懂的笑点，好过三个看不懂的。需要解释的段落就删掉。

## 4. 写导演方案

画任何东西之前，先写 `TREATMENT.md`：

1. **一句话故事和情绪弧**：铺垫 → 转折 → 结局。
2. **对标**：学什么 / 不学什么。
3. **镜头表**：每个镜头的景别（远 / 全 / 中 / 近 / 特写）、角度、运动（推、拉、摇、移、升降、变焦）、时长，以及**为什么这样拍**。
4. **分镜节拍表**，按秒。
5. **cue map**：速度、小节网格、每段配器，以及每个剪辑点、关键动作、字幕落在哪一拍。
6. **声音设计表**：每段的环境底、主要拟音、音乐状态。
7. **字幕和片名设计**：字体排版也是风格的一部分。

### 确认点 1：停下来给用户看

把导演方案摘要和分镜（几张关键画面，或文字节拍表）发给用户，**等确认**。在这里改方向花几分钟；全片渲完再改要花几小时。

## 5. 定画面

- **有角色**：画角色设定表（转面、3–4 个表情、2–3 个关键姿势、配色）和 2 张风格帧。
- **没有角色**：3 张片中的风格帧，其中一张是签名镜头。

用真正的绘制代码渲出来，不要做示意图。

### 确认点 2：停下来给用户看

发图，并说出你最没把握的地方。画面确认后再继续。

## 6. 声音是片子的一半

- **画面上每个动作都有声音**：落地、翻页、刀刻、墨滴、按钮、布料。按材质做（纸、木、金属、墨、玻璃的声音都不一样）。
- **三层**：环境底（房间音、风、雨、城市）、拟音（跟动作）、音乐。对白和关键拟音出现时，音乐要让路。
- **至少两处真正的静音**或近乎静音，放在转折前或情绪最高点前。静音后的第一个声音，要是全片最重要的声音之一。
- **用声音做转场**至少两次：下一场的声音提前进来（J-cut），或上一场的声音延续过剪辑点（L-cut）。
- **不要通用的"钢琴 + 弦乐"**。用这个风格自己的编制：橡皮管卡通用大乐队，浮世绘用太鼓和三味线，默片用影院立式钢琴。

## 7. 节奏：先有音乐网格

- 先写 cue map 再做动画。画面卡在网格上，并用脚本核对每个卡点（见技术方法 §3）。
- **节奏要有变化**：快慢交替，有一次明显的加速或减速，留一处让观众"呼吸"（长镜头或停顿）。全片匀速就是失败。
- 一个动作 = 一个声音 = 一个剪辑点，但不要每拍都切，要留出看清的时间。
- **节奏以观众为准，不以时长为准**：
  - 每句字幕至少停 1.8 秒，且不短于语音 + 0.6 秒。
  - 文字动画结束后，英文按（字母数 ÷ 15 + 1.5）秒停留，中文按（字数 ÷ 4.5 + 1.5）秒停留。
  - 标题页至少停 4 秒。
  - 失败和笑点镜头给足看懂的时间。
  - 可以快，但要靠每屏更少的字来快，不要靠观众没读完就切走。

## 8. 镜头：每个镜头都要有理由

- 全片至少用 **4 种不同的镜头运动**，并有真正的景别变化。2D 也有摄影机：推拉、视差、焦点转移、画中画框。
- **一个让人记住的签名镜头**：一镜到底、尺度揭示，或用媒介本身做的转场。
- **转场在媒介里设计**（翻页、刻线长出、墨迹洇开），全片统一一套语法，不要默认的淡入淡出或硬切。
- 关键时刻主体至少占画面高度的 1/3，站位清楚，剪影读得出。

## 9. 表演

- 每个有意义的动作都有**预备、动作、跟随**。角色要有情绪变化，不能只是平移。
- **动作连贯**，代码骨骼角色尤其要注意：
  - 姿势一律用关键帧缓动混合，不要在 `if` 分支里切姿势。唯一的例外是刻意的一帧笑点。
  - 开拍前画一张大尺寸动作测试表（前伸、举手、跑、跪），看肩膀和手臂。
  - 手持道具**夹在两掌之间**，深度在两条手臂之间；交接从一个掌心插值到另一个掌心；滚动的东西旋转角 = 路程 ÷ 半径。
  - 关键动作按 0.2 秒抽帧放大看。
- 每个表情都在最终尺寸下检查，尤其眉毛方向：“担心”和“生气”只差一个翻转。

## 10. 最常见的问题

- 主体太小、太远，或贴在画框边上。
- 太暗看不清，或同色叠加（红底上画红色）。
- 字幕挡住主体。
- 笑点或失败镜头太快，看不懂。
- 转场出现空白帧。
- 跟着主体走的效果（光圈、推镜、跟拍）在机位移动后没对准。写一个世界坐标 → 画面坐标的函数，所有地方都用它，不要手填画面坐标。

## 11. 交付前自检

- 全速完整看一遍，再看缩略图总览（每 1–2 秒一帧）和关键动作的 0.2 秒抽帧。
- 配音：每句都能被语音识别正确转写回来。
- 响度约 −14 LUFS；无黑帧、无 NaN 帧；字幕同步且不挡关键动作。
- 声音设计表里的每一项都真的在混音里。
- **交付**：`<名字>.mp4`、`<名字>.srt`、`poster.jpg`、`TREATMENT.md`，以及可一键重建的源码和 `build.sh`。
