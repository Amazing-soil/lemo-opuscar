## 1. 一句话故事

新来的夜班员工举着摄像机录下入职第一晚：一栋无尽的黄色办公层，天花板广播用温柔的声音一条条念《员工守则》。他照着做——灯闪三下时不看天花板；可守则第 2 条说"这层只有你一个员工"，第 5 条却说"同事向你挥手，要挥手回应"。摄像机在走廊尽头拍到一个挥手的"同事"，再对上焦时那里空了；一道磁带噪声之后，时间码跳过了三个小时，他还站在原地。最后他看见了不该存在的出口标志，推门进去——墙上是第 6 条守则："Do not rewind this tape."，然后 REC 灯熄灭。

情绪弧：**无聊的平常 → 细小的不对劲 → 规则被验证（灯闪）→ 看见（又看不见）→ 时间被剪掉 → 违反规则 → 规则转身对观众说话**。
一个主体（摄像者，全程只闻其声、只见其脚）、一个目标（按守则完成第一晚的巡视）、一次转折（时间码跳了三小时——他已经不在"正常"里了）。

## 3. 原生招式（只有 found footage / 录像带这个媒介能做到）

1. **自动对焦找焦 = 看见又看不见（情绪高点 A，32.2–35.2 s）**：他推变焦看走廊尽头，摄像机的自动对焦来回拉：第一次拉到位（0.5 s）时，灭灯的缺口里站着一个过高的、在挥手的人影；对焦滑走、他低声"Hello?"；第二次对上焦时，那里空了。**东西只在"焦点正确"的半秒里存在**——这是摄像机的机械缺陷在讲故事。
2. **磁带跟踪撕裂 = 时间被剪掉的证据（情绪高点 B，36.35 s）**：一道跟踪噪声横扫画面，之后构图一模一样，只有 OSD 时间码从 `PM 11:59` 变成 `AM 2:59`、电量从三格掉到一格并开始闪。没有任何特效，只有摄像机自己的读数"揭发"了丢失的三小时；他一句 "It was midnight a second ago." 把观众的眼睛引到时间码上。
3. **REC 灯熄灭 = 规则对观众说话（结尾）**：门后墙上是第 6 条 "Do not rewind this tape."；广播只念了"Rule six."就停了，剩下的由纸面替它说完——观众此刻正在看这盘带子。REC 熄灭，画面冻结、撕裂、黑。
4. 配套的媒介细节：开机时带子滚入 + **自动白平衡**从冷蓝漂到黄（摄像机"适应"了这里的日光灯）；片名用**摄像机字幕机**的点阵字叠在告示上；灯闪时**自动曝光/AGC** 滞后提亮、噪点变多；变焦有伺服电机声；OSD 时间码就是剧情。

## 6. 声音设计

- **日光灯**：120 Hz 基频（北美 60 Hz 电网的磁致伸缩）+ 240/360/480 Hz 谐波、轻微不稳；镇流器高频啸叫（~9 kHz 窄带，很轻，灯闪时跳变）；坏灯管的"滋滋"颤音跟画面里频闪的灯同步（按距离衰减）。
- **脚步**：潮湿短绒地毯——低频闷击（80–200 Hz）+ 一点湿黏的中高频"吧唧"，没有硬质敲击；步点由画面步态相位导出（events.json），低头拍脚时更近更响。
- **摄像者**：近距离呼吸（带通噪声 + 包络，恐惧时加快变浅，屏息后一口长呼气）、衣服摩擦（转身、低头）、4 句 am_michael 气声（Kokoro 不会真的耳语：降速、压低电平、叠一层由人声包络调制的带通气流噪声、近讲低频提升；whisper 逐句校对）。
- **广播**：af_bella 经"天花板喇叭"链：带通 280–3800 Hz + 轻失真 + 纸盆共振峰 + 大空间混响；每个位置远近不同（开场远、门后房间最近最干）；原创两音叮咚（颤音琴 E5→C5，同样过喇叭）；撕裂之后叮咚和广播都跟着带子轻微走调。
- **电梯音乐**：原创轻音乐，sampler 颤音琴 + 钢琴 + 电贝斯，隔墙滤波；加磁带 wow/flutter，随时间越来越慢越低，到屏息时消失，之后再也不回来。
- **摄像机**：上机/停机的机械咔哒与马达、变焦伺服电机、对焦马达细碎咔嗒、带子底噪（全程极轻）、跟踪撕裂时的音频断续。
- **唯一的声音惊吓**：屏息 1 秒后，所有镇流器同时重启的一声闷"咚"。不做尖叫、不做突然的巨响。

## 7. 字幕设计

- **样式 = 录像带时代的隐藏式字幕**（CEA-608 式）：等宽字（IBM Plex Mono 600，42 px），**每行一条纯黑底块**、白字，一行最多 32 字符，居中，位于 4:3 画幅下方、OSD 时间码之上。它是这个媒介真实存在的字幕格式——干净、和带子上的噪声形成对比（字幕是电视解码的，不吃磁带噪声）。
- 说话人：广播用 `[PA]` 前缀；摄像者的气声用斜体（第一句加 `(whispering)`）；环境声按 SDH 习惯写在方括号里：`[FLUORESCENT LIGHTS HUMMING]`、`[LIGHTS FLICKER]`、`[TAPE NOISE]`，以及全片最安静的那一秒 **`[SILENCE]`**。
- 守则本身不加字幕——它们是画面里的告示（英文打印体），特写时停留足够长、没有字幕遮挡，要求在 1080p 下清楚可读。
- 节奏：每条 ≥1.9 s 且 ≥ 语音 + 0.65 s；长句按 whisper 词时间戳拆成两条。

## 8. 视觉规格

- **空间**：手工路线（开场房间 → 主走廊 → 出口走廊 → 门后小房间）+ 程序化填充的无尽格子间（2.4 m 网格上随机隔墙与柱子、合并共线段），吊顶 2.70 m，矿棉板 0.6×1.2 m、嵌入式日光灯板每 2.4 m 一盏，数千盏灯的颜色/亮度/坏灯由一张 128×128 浮点数据贴图驱动，自写着色器每个像素读周围 5×5 盏灯（无阴影、无遮挡——后室的光本来就"平"）。
- **材质**：墙纸（暖黄底、宽窄相间的竖条 + 菱形列、每幅褪色不同、局部墙根潮痕、吊顶下烟黄、接缝暗线、踢脚线）；地毯（芥末棕短绒 + 大块潮湿发暗区 + 湿处的微弱高光）；吊顶（虫蛀孔、龙骨、个别板子的黄褐水渍环）；灯板（棱镜扩散板 + 灯管 + 死虫影子）。
- **光与镜头**：全部来自日光灯，平、偏黄绿，远处经"跟随当地亮度的雾"变暗（灭灯的地方雾也暗，剪影才是"光里的一个洞"）；GTAO 压暗墙角；物理景深承担自动对焦；变焦 52°→27°。
- **VHS 摄像机后期**（自写，替代 CRT）：4:3 左右黑边；逐行时基抖动 + 底部磁头切换条 + 跟踪撕裂；镜头桶形畸变与暗角（OSD 不畸变）；亮度带宽限制 + 锐化振铃白边；色度宽窗糊开并向右滞后；高光向右拖尾；自动白平衡与曝光漂移、AGC 噪点（暗处更多）；掉磁白线；黑电平抬升、高光软削。**不加扫描线和光栅**——这是被录下来的带子，不是在显像管上看。mux 颗粒 = 0。
- **OSD**：自制 5×7 点阵字：左上 `● REC`，右上电量，右下 `PM 11:58 / SEP.27.1996`（时间码是剧情）。

## 9. 相对风格说明的改动（及理由）

1. **"东西"= 一个挥手的"同事"**：说明里只要求"远处一瞬的剪影"。我让它回应第 5 条守则（"同事向你挥手，要挥手回应"），与第 2 条（"这层只有你一个员工"）构成矛盾——剪影不只是吓人的东西，而是**矛盾本身被拍到了**；他没有挥手回应，而是说了 "Hello?"，观众自己去想这算不算违规。
2. **字幕用 CEA-608 隐藏式字幕**而不是 OSD 或打印体：OSD 已经被时间码/REC/片名占用，再用点阵字会混；608 字幕是这个年代真实的字幕形态，干净、可读，还能写 `[SILENCE]`。守则本身仍是画面里的打印体告示。
3. **片名卡 = 摄像机字幕机**：满足"开场片名卡"的同时留在戏里。
4. **4:3 + 黑边**（说明允许 4:3 或 16:9）：更像被转录的原始带子，也和 Kane Pixels 的语法一致。
5. 没有写配乐；"电梯音乐"作为唯一的旋律来源，是画内声（diegetic）并随带子走调，符合"无配乐"的要求。

## 10. 风险与对策

- Kokoro 做不出真耳语 → 后处理成气声 + whisper 校对；必要时改写成更短的句子。
- 剪影在 VHS 噪声里可能太清楚或太难看见 → 以"对上焦的 0.5 s 里一眼能认出是人在挥手、但看不清任何细节"为标准，逐帧调对焦曲线与雾。
- 声音全是合成的，我听不见 → 用频段能量、电平表、whisper 自检，嗡鸣与呼吸避免过响刺耳。

## 11. 关卡 1 之后的改动（成片以此为准）

- **时长 59.7 s**：节拍表里的秒数是压缩前的"原始时间"。成片用 `story.js` 的分段线性映射 `W()` 只压走路段：7.0–7.9 s 段 −0.3 s、39.6–40.2 s 段 −0.3 s、49.5–54.3 s（走向出口门并进屋）−0.7 s。因此 7.9 s 之后的事件整体提前 0.3 s，40.2 s 之后提前 0.6 s，54.3 s 之后提前 1.3 s（片尾卡 56.8–59.7 s，REC 熄灭 56.4 s）。片尾卡和 REC 熄灭前告示的停留没有压缩。
