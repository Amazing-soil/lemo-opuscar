# Blueprint · 导演方案（Treatment）

**片名** *Patent Pending: The Cloud Catcher*（片内标题：THE CLOUD CATCHER ／ PATENT PENDING）
**时长** 46.7 秒（21 小节 × 2.222 s，108 BPM）｜ **画幅** 1920×1080 ｜ **帧率** 24fps 输出；线条"画出"、零件飞行、镜头全部逐帧平滑；齿轮按八分音符**步进**转动（擒纵式"一格一格"咬合，本身就是节奏）
**一句话** 一位老发明家的晒图纸上，一台"接云浇花机"自己画了出来、爆炸拆解、装配、运转——可这张图纸上根本没有云。发明家的手伸进来，在空白的天空处画了一个"修订云线"。这个工程符号鼓了起来、离开纸面，变成一朵真的雨云，雨落在图纸上，蓝色洇开，一朵白线画的花从水渍里长了出来。
**主题** 图纸是对世界的承诺；修订，是承认世界还缺一样东西。

## 一、对标：学什么 / 刻意不学什么

| 对标 | 学什么（语法） | 刻意不学 |
|---|---|---|
| **《Iron Man》(2008) 片尾字幕（Prologue Films）** | 技术线稿在运动中爆炸拆解；引线标注跟着零件飞；线条在黑/蓝底上发光地"被画出来"；镜头沿机械结构滑行；投影方式本身在变（平面 → 有纵深） | 不出现任何钢铁侠/漫威元素（装甲、反应堆、红金配色、HUD 字体）；不做发光科幻 HUD，本片是纸上的墨线 |
| **达·芬奇手稿（Codex Atlanticus）** | 机器、手写注释、剖面同在一页的"思考的痕迹"；注释本身是叙事（我们的注释里藏着干幽默：配重是"祖母的熨斗"） | 不复刻任何达·芬奇的具体机器、镜像字、棕色纸 |
| **19 世纪美国专利图** | Fig. 1 / Fig. 2 编号、零件号圆圈（balloon）、细线阴影法（hatching）、斜二测（cabinet oblique）投影——正面保持真形所以齿轮永远是正圆、一加纵深就有体积 | 不复刻任何真实专利的图面、编号、签名 |
| **《Hugo》(2011) 的自动人偶图纸** | "机器等于角色"：图纸里的机器有性格和心事；机械运转的喜悦 | 不借用自动人偶造型 |
| **真实晒图（cyanotype / blueprint）** | 普鲁士蓝不均匀褪色、纸纹、折痕、边缘发白、白线略软微晕；**水会让氰版洇开**（蓝变深、边缘留浅色水痕线） | 不做成数码干净的"蓝底白线矢量图"——所有质感在一个纸张着色器里模拟 |

## 二、为什么这个媒介讲这个故事（原生能力 → 故事用法）

| 蓝图的原生能力 | 故事里怎么用 |
|---|---|
| **绘图顺序**：先中心线（点划线）、再轮廓（粗线）、再细节、再剖面线、最后尺寸和标注 | 开场的"画出来"严格按制图顺序走，每一层落在一个拍点上：观众看到的是一个工程师的思路 |
| **标注是活的**（原生招式 1） | 爆炸视图里：引线 + 零件号跟着零件飞；尺寸线实时测量零件间距，数字跟着变（0 → 480）；剖切线 A–A 扫过齿轮箱，扫过之处外壳消失、露出内部齿轮和剖面阴影线 |
| **Fig. 编号** | 转场 = 编号改写："FIG. 1" 的 1 被划掉写成 2（爆炸视图），再改成 3（运转） |
| **投影方式** | 爆炸时图纸"转身"：正立面（深度 0）→ 斜二测（深度系数 0.5），线稿第一次有了厚度，零件沿纵深轴飞出——不用 3D 渲染，只改投影公式 |
| **修订云线（revision cloud）**（原生招式 2，情绪高点） | 制图里用来圈出"这里改了"的扇贝形云线符号——发明家在空白天空处圈了一个，写上"REV. 1 — ADD ONE (1) CLOUD"。音乐停在悬置和弦，符号的扇贝鼓成云团、长出阴影线体积、在纸上投下影子（它离开了纸面），然后被网接住、下雨。符号 = 云，这是本片的双关 |
| **氰版遇水洇开**（原生招式 3） | 雨滴落在纸上：每一滴都晕开一圈更深的蓝和一道浅色水痕；水渍里的白线被泡软；一朵白线花从最大的水渍里画出来。结尾一滴雨落在签名上，签名洇开 |
| **标题栏** | 片名卡、状态（STATUS: PATENT PENDING → 红色印章 WORKS）、片尾卡都在同一个标题栏里：片尾卡 = 标题栏最后一行被写上 "STYLE: BLUEPRINT ／ DRAWN: LemoLab × Claude Opus 5.5" |

**情绪弧**：好奇（空白纸 → 机器被画出）→ 骄傲（爆炸视图，发明家在炫耀）→ 兴奋（运转，齿轮按节拍咬合）→ 落空（网扫过空白的天空，什么也没有；机器泄气、吊臂垂下、风向标耷拉；音乐停）→ 灵机一动（手伸进来画修订云线）→ **奇迹**（符号变成云，悬置和弦）→ 满足（接住、下雨、花长出来）→ 回响（印章 WORKS、签名被雨洇开、"Slightly damp."）。

一个主体（这台机器 / 发明家的执念）、一个目标（让干旱的小花园下雨）、一次转折（机器完美但世界里没有云 → 改的不是机器，而是图纸本身）。
开场 3 秒钩子：黑暗里一卷晒图纸"啪"地甩开铺满画面，丁字尺滑过，第一根白线被拉出来。
结尾回响：开场第一根线来自丁字尺，结尾最后一笔是标题栏里的署名行；开场"PATENT PENDING"，结尾被印章改成"WORKS"。

## 六、声音设计（拟音跟材质走：纸 / 木 / 金属笔尖 / 黄铜齿轮 / 水）

- **纸**：纸卷甩开（高频沙沙 + 卷筒滚动）→ "啪"落平（低频闷拍 + 纸面脆响）；纸面环境底噪（极轻的纸纤维摩擦 + 远处室内底噪）。
- **绘图工具**：丁字尺木头滑动（低通噪声 + 细小颤动）；针管笔划纸（带通 2–6 kHz 颗粒噪声，笔画长短 = 声音长短，每层线条对应一簇）；写字（短促的点划）；圆规转动（画齿轮圆时，一圈金属"吱"）。
- **机器**：零件飞出 = 纸面"嗖"（短带通 whoosh）；装配 = 黄铜"咔"（瞬态 + 3.1/5.2 kHz 共振）；齿轮步进 = 擒纵"嗒"（每八分音符一声，与跳弓弦乐重叠）；风箱呼吸（低通噪声吸气/呼气）；链条沙沙；失败时齿轮减速的"咔…咔……咔"。
- **修订云线变云**：纸面轻微"起鼓"声（低频膨胀 + 纸张轻响），无其它拟音，让悬置和弦独占。
- **雨**：雨滴落纸（每滴一个柔软的"嗒"，纸面阻尼、无金属感）+ 雨床；水渍晕开无声。
- **印章**：木柄橡皮章砸下（低频 thump + 纸面拍击 + 极短的橡皮"噗"）。
- **笔帽**：结尾一声塑料/金属笔帽"咔"。
- 混音：旁白压缩后置前，音乐在旁白下闪避约 −8 dB；拟音干、近（桌面距离）；最终 −14 LUFS，mux grain = 4（轻；晒图纸颗粒在画面里做）。

## 七、字幕与标题设计

- **字幕 = 图纸上的注释**：画面左下固定一个"NOTES"注释框（细白双线框，框角有一个小的引线折角），前缀 "NOTE 1." 用 B612 Bold 小号字，正文用 **Architects Daughter**（OFL 手写工程字）44 px 白色，出现时像被写出来一样从左到右逐字显现（0.3 s 内写完，保证阅读时间）。框底色是比纸略深的半透明蓝，保证在任何画面上可读。
- 同一句话同时被写进图纸右侧的 **GENERAL NOTES** 栏（第 12 镜全纸揭示时，观众看到全部旁白都成了图纸上的注释）。
- **片名**：页眉大字 THE CLOUD CATCHER（Architects Daughter，大写，加宽字距），下方 PATENT PENDING 与副标题（B612）。
- **片尾卡**：标题栏特写，最后一行写上 STYLE: BLUEPRINT ／ DRAWN: LemoLab × Claude Opus 5.5。

## 八、视觉规格（摘要）

- 纸：普鲁士蓝在 #1F3F7A–#2A5CAA 之间低频不均匀褪色；纸纤维；两道折痕（十字折，亮边 + 暗边）；边缘不规则发白；全在 WebGL 着色器里按纸面坐标程序生成（任意缩放都清晰）。
- 线：浅蓝白 #E6EEF8；线宽分级（轮廓 3.2 / 细节 2.0 / 尺寸与引线 1.2 / 点划中心线 1.2 / 虚线隐藏线 1.2，纸面单位；屏幕线宽 = 纸面线宽 × 缩放^0.65，特写不会糊成粗棒）；白线轻微晕开、随纸纹有极轻的断墨。
- 遮挡：每个零件先用"纸色"填充再描边（画家算法），线稿自带消隐。
- 投影：正立面 → 斜二测（cabinet，45°，深度系数 0–0.5 可动画）。
- 唯一的强调色：印章红 #C23B2E。
- 影子（手、云）：纸面变暗的柔和投影，不是黑色。

## 九、对风格说明的调整（及理由）

1. **时长 40 s → 46.7 s**：六句旁白都要留足阅读时间，情绪高点（28.9–33.3）刻意无旁白，片尾卡需要约 3.5 s 读清署名；按"节奏以观众为准"加了 3 小节。
2. **爆炸视图同时"转身"成斜二测**：派单只说爆炸拆解；我把"投影方式改变"作为另一个只有工程图才有的语法，让线稿第一次有厚度，零件沿纵深轴飞出更像对标的爆炸视图。
3. **发明家的手只以影子 + 笔尖出现**：影子天然"来自纸外"，和"符号变成真实"的主题一致，也避免在蓝图语言里混入写实的手。
4. **两个结尾建议都用了**：印章 WORKS + 雨滴洇开签名，再加一句干幽默的 "Slightly damp." 收尾；片尾卡直接做在标题栏里，风格名和署名成为图纸的一部分。
