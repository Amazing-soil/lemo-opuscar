## 1. 一句话故事与情绪弧

**大雪封山的冬天，村里的钟楼是空的。老铸钟匠和学徒用村民捐出来的锅、钥匙、戒指熔铜铸钟；第一口钟敲下去是一声闷响——裂了，全村无声。学徒把脖子上那枚一直带他回家的铜指南针丢进坩埚。第二次浇铸，熔铜的光把整张版画"刻"亮。钟第一次敲响，雪停在半空听它，然后慢慢消失。**

- **主体**：学徒男孩（成长的那个人）+ 老铸钟匠（他的手，是全片的"刻刀"）。
- **目标**：给没有声音的村子铸一口钟——雪天里，钟声是迷路人回家的方向。
- **转折**：第一口钟裂了。所有人都已经给过了；只剩男孩手里那枚指南针——"让我找到路的东西"换"让所有人找到路的东西"。
- **回响**：
  - 开场第一刀刻出的一条白线是雪地的地平线 ↔ 结尾白点般的雪全部消失后，画面只剩那条地平线和钟；
  - 开场雪是一片密集的白点（刻痕）↔ 钟声响起时白点**停在空中**，再一颗颗被墨"填回去"；
  - 全片第一个声音是刻刀入木 ↔ 最后一个声音是片尾卡上的最后一刀 + 钟的余音；
  - 老匠人抹泥模的手（长特写）↔ 拉钟绳的同一双手，男孩的手搭上来。

**开场 3 秒的钩子**：全黑、只有极轻的风声；第 1 秒"笃"——刀尖咬进木头，一道白线沿着画面横着犁开。观众还不知道这是什么，只知道有人在黑暗里下了第一刀。

## 2. 对标：学什么 / 刻意不学什么

| 对标 | 学什么（语法） | 刻意不学 |
|---|---|---|
| **Frans Masereel《Passionate Journey》(1919)**、**Lynd Ward《Gods' Man》(1929)** 无字木刻小说 | ① **每个镜头是一块"版"**：一张完整、自足的构图，靠画面序列讲故事，旁白压到最少（4 句）；② 大块黑与大块白的对比做戏剧性，人物常被处理成白色刻线勾出的黑剪影；③ 城市/山谷用**放射状刻线**表达光、声音、情绪（光是"刻出来的"）；④ 画面四周留白纸边，页码/说明文字排在纸边上 | 不复刻任何一幅具体版画、人物造型、构图；不用 Ward 的装饰边框和 Masereel 的都市题材；片中不出现书名、作者名 |
| **Käthe Kollwitz 的木刻**（农民、哀悼系列） | 粗刀、强黑白、**情绪全靠刻痕方向**：人脸只刻受光一侧的几道白线，其余交给黑；群像的"静默"——一群人低头站着的剪影本身就是情绪（用在第一口钟裂开后的全村静默） | 不做她的悲恸母题和具体人物；我们的群像是雪地门口的村民，不是哀悼场景 |
| **Gustave Doré 的版画排线** | **用线的疏密和方向表现明暗与体积**：线宽随亮度变（亮处线宽、暗处线细到消失）、线的方向顺着形体（钟身是横向环绕的弧线、山坡顺坡向、天空横线、火焰放射）；远景线细密、近景线粗疏 | 不做 Doré 的写实细密木口雕刻（那是 engraving 的细腻），我们保留木刻（woodcut）刀的粗犷与毛刺 |
| **实际木刻工艺**（参考语法） | 刀具分级：V 刀（细线）、U 刀（粗圆槽）、平刀（清底留下的刀痕脊）、刻刀（勾轮廓）；**印版是反的**——字在版上是镜像，印到纸上才正；滚墨、覆纸、马连压印、揭纸 | 不做成剪纸（papercut-red：镂空红纸、纸影）、皮影（shadow-puppet：透光剪影）；**不做 ukiyoe 那种"一版一版套色 + 見当对位"**——本片只有一块黑版 + 一块唯一的橙色版，转场是"揭纸翻面"而不是逐版叠印 |

**与已完成风格的区分**：ukiyoe 是平涂多色版 + 手卷平移；本片是**单黑版、排线表现明暗、白线即光**。唯一的颜色（熔铜橙）只在熔化的金属出现时才被"套印"上去。

## 3. 原生招式（只有木刻能做到）

| 招式 | 位置 | 怎么做 / 为什么只有木刻能做 |
|---|---|---|
| **① 刻线生长**（贯穿） | 开场、手的特写、裂纹、放射光、片尾 | 画面不淡入，而是**被刻出来**：刀痕沿形体方向一刀刀出现，**先 U 刀粗槽、后 V 刀细线**（先大明暗后细节，符合真实刻版顺序）。每一刀是带锥形刀尖的独立笔触，起刀钝、收刀尖、边缘有崩口；刻的时候有木屑卷起飞走。黑是木头表面，白是刻掉的——**光是被刻出来的**。 |
| **② 反字印版 → 揭纸翻面**（统一转场语法） | 7.0 开场、43.0 进钟楼、55.0 片尾 | 开场在木版上刻的片名是**镜像反字**（观众先看到反着的字母），滚墨、覆纸、马连压印、揭起纸翻向镜头——**翻过来的纸上字是正的**，第一张印品出现时，世界才"活"过来：雪开始落。揭纸时带轻微套印错位（橙版相对黑版偏 3–6 px 再落定）和纸纹。 |
| **③ 放射刻线爆开 + 唯一的橙版**（情绪最高点） | 39.0 第二次浇铸 | 熔铜倒出的一瞬，**几十道放射状 U 刀刻线从坩埚口向整张版爆开**（从中心往外"刻"，0.5 s），同时唯一的橙红色版 `#C8502A` 沿着这些刻线套印进来，铺满半个画面，照亮男孩和老人的脸（脸上的受光刻线也套上橙）。第一次浇铸只有 6 道短放射线，第二次是满版——同一招的升级。 |
| **④ 颜色退去，只留一道铜光** | 47.3 钟响之后 | 钟响的一刻橙版从全画面往钟身收缩，最后只剩钟身上一道铜色高光——"熔铜变成了钟"。此后全片只有这一道颜色，一直留到片尾卡。 |
| **⑤ 雪停在空中，再被墨填回去** | 47.3–55.0 | 雪在木刻里是刻掉的白点。钟声一响，所有白点冻结；然后一颗颗**被墨填回**（刻痕消失 = 雪消失），夜空变得干净，只剩地平线那一刀和钟。这是"刻痕即雪"才成立的结尾。 |

## 4. 角色（关卡 1 交设定表 `demo/stills/modelsheet_v1.jpg`）

所有角色原创，按木刻语法设计：**剪影先读出来（大块黑），再用白刻线给受光面和结构**。光源默认来自右上（室内时来自右下的炉火）。

- **老铸钟匠（The Founder）**：高个、驼背，头比身体往前探；光头、**一大把白胡子**（胡子是一束束 V 刀白线，是他最亮的部位）；深眼窝、鹰钩鼻，脸是黑的，只在受光一侧刻 4–6 道顺着颧骨和额头的白线，皱纹是短刻痕；厚皮围裙（横向粗刀纹）、卷起的袖子露出前臂；**一双过大的手**——指节粗、每道皱纹都是一刀。道具：铸锤、长柄钳、刮板。剪影标志：驼背 + 前探的头 + 胡子 + 围裙下摆。
- **学徒男孩（The Apprentice）**：12 岁左右，瘦小，穿一件**明显过大的旧外套**（袖子盖过手背、下摆到膝），羊毛帽、一条长围巾一端垂在身后；脸圆、眼睛大，白刻线少（孩子的脸"刻得少"= 更柔）；**脖子上挂着一枚圆形铜指南针**（绳子 + 带盖的圆盒），整片他习惯性地摸它。剪影标志：大外套 + 帽子 + 围巾尾巴 + 胸前一个圆。
- **村民**：斗篷、头巾、帽子的简单剪影群像，白色轮廓刀勾边，脸只有一两道刻线。
- **表情**（换刻线组合，不做渐变）：老匠人——专注 / 失落（眼窝全黑、嘴角下压）/ 点头认可 / 仰望；男孩——好奇 / 犹豫（手攥指南针）/ 决心（下巴收、眉线压低）/ 仰望惊喜。
- **关键姿势**：老匠人抡锤（预备后仰 → 砸 → 跟随下沉）、提坩埚浇铸（重心后坐）、拉钟绳；男孩拉风箱（全身压下）、丢指南针（攥 → 松手 → 手停在空中）、仰望。
- **色板**：墨黑 `#111111`（版面墨，带墨色不匀 ±6% 与木纹）· 纸白 `#EFE8D8`（带纤维与云斑）· 木版刻痕面 `#D8C29C`（只在"看到木版"的镜头）· 唯一套色 熔铜橙红 `#C8502A`（叠印在纸白上呈 `#C8502A`，叠在墨上几乎看不见——所以橙版永远落在刻白的地方）。

"摄影机 = 刻刀"：刻刀的刀尖永远是画面的焦点；镜头运动在纸面上做（推拉平移都是 24 fps 平滑），纸边外框固定不动。

|---|---|---|---|---|---|

## 6. 分镜节拍表（按秒）与 cue map

### 速度网格
- **A 段**（0–3.0）自由拍，没有音乐。
- **B 段 60 BPM**（3.0–23.0）：1 拍 = 1.000 s，4/4，每个剪辑点都在整秒上。
- **C 段 90 BPM**（23.0–32.333）：3:2 的**节拍转换**——60 BPM 的三连音八分音符（0.333 s）变成 90 BPM 的八分音符，1 拍 = 0.6667 s。"打铁节奏"进来，全片第一次明显加速。
- **D 段 60 BPM**（32.333–36.333）：回到慢速，孤独的大提琴。
- **E 段 90 BPM**（36.333–44.333）：打铁节奏加倍到十六分音符，第二次也是最强的加速。
- **F 段 真静音**（44.333–47.333，3.0 s，全片最长）。
- **G 段 钟**（47.333–）：钟声本身，自由拍 → 余韵里弦乐以 60 BPM 进入。

## 8. 视觉语言

- **两个世界**：
  - **木版**（0–9 s、片尾）：满版黑墨（带光泽和木纹走向的墨色起伏），刻掉处露出淡木色 `#D8C29C`，刀槽里有纵向刀痕阴影和木纤维；图像是**镜像**的。
  - **印品**（9 s 起）：纸白 `#EFE8D8`（纤维 + 云斑 + 极细颗粒）上的墨黑 `#111`。版画四周留纸边（左右上 40 px，下 120 px，字幕排在下纸边），版面边缘是毛糙的墨边（木版的边）。
- **刀具分级（线宽，以 1080p 画面像素计）**：刻刀轮廓 1.2–2 px；V 刀细线 2–4 px；V 刀中线 4–8 px；U 刀粗槽 10–22 px；平刀清底 = 大面积白 + 残留的平行刀痕脊（黑）。**刻线生长永远先粗后细**。
- **排线规则（Doré 语法 → 木刻）**：线的**方向顺着形体**（钟身横向环绕弧线、山坡顺坡、天空横线、火焰和光放射、人物衣服顺褶皱）；**线宽随亮度**（亮 → 宽白线几乎连成白，中间调 → 细线，暗 → 无线纯黑）；远景线密而细，近景线疏而粗；每道线是独立的一刀（带锥形刀尖、起刀钝、收刀尖、长度 30–160 px 随机断开），不是连续的机械线。
- **印刷质感（WebGL2 合成）**：边缘毛刺（噪声扰动取样 + 噪声阈值 → 刀口崩边）、墨色不匀（大尺度 ±6% + 木纹走向的条纹 + 小块"没吃墨"的白点）、纸纹透出墨层、极轻压印凹凸；橙版单独一层，带自己的斑驳与 3 px 固定套印错位，只在刻白处显色（墨上几乎看不见）。
- **雪**：戳刀刻出的白点（小泪滴形，大小 3 档），12 fps 飘落（像逐张印出来），近处大、远处小。
- **人物**：剪影黑块 + 白色轮廓刀（人物与黑背景之间刻一圈白边分开）+ 受光面排线；脸只刻受光一侧。

## 9. 动作语言

- **角色 12 fps 步进**（on twos），镜头、雪、火焰、光 24 fps。每个关键动作做预备—动作—跟随：抡锤（后仰 4 帧 → 砸 2 帧 → 下沉跟随 + 3 帧画面震）、拉风箱（身体压下时围巾甩起、回弹）、丢指南针（攥紧 → 松手 → 手停在空中 0.5 s）、拉钟绳（两人同时下沉）。
- 排线在角色部件的**局部坐标**里生成，部件动时刻线跟着走、不"沸腾"；只有火焰和熔铜的刻线每 2 帧重刻一次（有意的沸腾 = 火的生命）。
- 刻线生长：每一刀有自己的开始时间和刀速（0.08–0.35 s），刀尖有 3 px 亮点和飞出的木屑（只在木版世界）。

## 10. 字幕与片名设计

- **字幕 = 纸边上的铅字说明**（木刻小说的图版说明）：排在版画下方的纸白边里，永远不压画面。字体 **IM Fell English**（OFL，17 世纪 Fell 铅字的数字化，带印刷的不规则），42 px，墨黑 `#111`，经过同一个印刷着色器（墨色不匀、边缘毛刺）。出现方式：像铅字被压印——0.1 s 内墨从浅到实，没有滑动；消失时同样 0.15 s 淡出。每句停留 ≥ max(1.8 s, 语音 + 0.6 s)，不重叠。
- **片名**：*THE BELL FOUNDER*，在木版上**刻成反字**（IM Fell English SC 字形作骨架，刻刀沿字形轮廓一刀刀刻出），印到纸上才读正；片名下一道刻线横线。
- **片尾卡**：一张新印品——片名、*A Woodcut Print*、*Lemo-Opuscar*、*LemoLab × Claude Opus 5.5*、素材署名（Kokoro、VSCO 2 CE / VCSL、IM Fell 字体），钟的图案保留那一道铜色高光。

## 11. 与风格说明的差异及理由

1. **时长 ~58 s（说明参考 40–55 s）**：本片要讲清楚两次浇铸（失败必须演出来：砸模、敲、裂纹爬 1.3 s）、两处静音（2.7 s + 3.0 s）、一个长特写（手 4 s）和签名拉镜（5 s）。压到 50 s 会让裂纹和静默变成看不懂的快闪。仍在 30–60 s 规格内。
2. **C 段 / E 段 90 BPM**（说明 60–72 BPM）：主体仍是 60 BPM 的庄重慢板；两次浇铸用 3:2 节拍转换进入 90 BPM（60 BPM 的三连音 = 90 BPM 的八分音符），这就是说明里"浇铸段加入打铁节奏"——让节奏有真正的加速，而不是全片匀速。
3. **钟响之前配乐里不用任何钟**：说明的配器里有铜钟/管钟；我把它们全部留到钟响之后。前 47 秒只有低音弦和木、皮、铁——"村子没有声音"本身就是配乐的结构，钟声才会是高潮。
4. **指南针**：说明里学徒"把自己的东西也丢进坩埚"，我把它具体成一枚一直带他回家的铜指南针，并在捐献蒙太奇的最后一格埋下伏笔（他攥住了，没给）。"让我找到路的东西"换"让所有人找到路的东西"——钟在雪天就是给迷路的人指方向的。
5. **旁白 4 句**（说明 4–5 句）：向无字木刻小说致敬，第一口钟裂开后的段落完全不说话。
6. **字幕排在纸边**：每个镜头都是一张带纸边的印品，字幕是纸边上的铅字说明——风格的一部分，也保证永远不挡主体。
7. **补一个"反字"招式**：木刻印版是镜像的——开场片名刻成反字，揭纸后读正，是"印版翻转"转场的第一次、也是最有戏剧性的一次使用。
