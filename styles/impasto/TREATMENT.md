# 厚涂油画 · 第二版（调色刀）导演方案
**片名** *The Colour of Rain*（雨的颜色） · **时长** 39.7 秒 · 1920×1080 · 24fps（全平滑，不步进）· 无旁白音乐片

**为什么重做**：第一版被评"不清晰"。这一版把清晰当硬指标：调色刀大块锐边；先定明暗再上笔触；焦点硬边、其余平整；静止的颜料不抖；2 倍超采样；成片不加颗粒。

**一句话**：雨中灰色的广场，一位街头大提琴手拉琴没人停下，他拉到一半放弃了。一个小女孩在他面前撑开了一把红伞，这是全片第一抹颜色。琴声重新响起，变成圆舞曲，伞一把接一把在拍子上变色。俯拍时，人群的圆舞在石板上画出一幅彩色曼陀罗。最后一个和弦落下，雨停了，颜色铺满整个广场。

**情绪弧**：孤独（灰）→ 放弃（静音）→ 一点颜色（红伞）→ 被听见（圆舞曲）→ 群体（俯拍编舞）→ 回响（同机位，灰变彩；开头断在 E 的乐句在结尾解决到 D）。

## 原生招式
1. **颜色被刀重新铺上**：每一笔都存了灰和彩两种颜色，揭示波沿着笔的方向一笔一笔扫过去。这招用在女孩开伞、大提琴手复苏、结尾和弦铺满广场三处。
2. **舞蹈画出画面**：俯拍时每把伞沿路径滴下自己的颜色，拉远后是一幅曼陀罗。
3. **掠射光**：和弦落下时太阳贴地斜照，每一道颜料脊都亮起来，随后回落。
4. **重涂转场**：下一个镜头的笔触扫着盖上来，声轨上配刀刮声。

## 音乐网格（cue map）
- A 段：大提琴独奏，D 小调 3/4，80 BPM，从 0.4s 开始。乐句在 10.15s 停在没解决的 E3 上，0.3s 后弓离弦。
- 静音：10.45–12.4。雨声几乎消失，11.15 一滴水，11.5 / 11.95 两声小脚步先入画（J-cut），12.4 大水花 = 静音后的第一个声音。
- B 段：街头圆舞曲，D 大调 3/4，132 BPM。
  - 15.3 POP（弱起小节）：钟琴 + 竖琴上行刮奏。
  - 16.66 伴奏进，低音拨奏 + 手风琴"嘭-嚓-嚓"。
  - 18.03 大提琴主旋律进。
  - 19.39–23.03 九把伞，每拍一把，钟琴音高按 G→B→D / A→C#→E / D→F#→A 逐级升高。
  - 23.48–31.21 俯拍，六小节编舞；手风琴高八度重复旋律，每小节一个竖琴琶音。
  - 31.21 大停顿，数字全零；雨停在半空。
  - 31.66 终止和弦（全体 + 定音鼓 + 吊镲）。
  - 尾声 F#→E→D，把开头断掉的乐句解决掉。
  - 35.75 最后一个拨奏，片尾卡。
