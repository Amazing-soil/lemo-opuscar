# TREATMENT · 34 1920s Silent Film ·《The Runaway Loaf》（v2 精简版）

> 2D ｜ 54.2 s ｜ 1920×1080 · 24 fps 输出；画面 4:3 放在剧院幕布之间；动作按 16 fps 采样（手摇放映感），追逐段 18 fps + 1.3× 速；闪烁、片门抖动、划痕每帧变化 ｜ 无旁白，字幕卡叙事 ｜ 配乐：原创默片影院钢琴（立式钢琴）+ 簧风琴
>
> v1 方案（`TREATMENT_v1.md`，16 段、集市连锁机关 + 电车 + 警察雾中追捕）因内容太满、关卡 1 迟迟交不出而被叫停。v2 由主会话接手：保留 v1 的引擎（胶片老化后期、重画模式、字幕卡、人物骨骼），故事砍到**一条主线、一个连锁笑料**。

## 1. 一句话故事与情绪弧

**面包店学徒 Otto 烤出一个完美的圆面包（乡村大圆包），高高举起向全世界炫耀；他把面包放在窗台上晾，拍了拍它，一转身，圆面包晃了晃、滚下了山。他一路追，伸手一抓扑了空，踩翻跷跷板，把一颗西瓜送上天——西瓜落在刚走进画面的警察头上。面包最后停在一个坐在台阶上的小女孩脚边。她捧起面包："Is it yours, mister?" 他跪下来，把面包掰成两半，递给她一半。她也把面包高高举起——然后对着镜头眨了一下眼。**

- **情绪弧**：得意（举起面包）→ 狼狈（双重反应、扑空、闯祸）→ 静（面包停下，全场只剩放映机声）→ 温柔（掰面包）→ 会心（眨眼）。
- **回响**：开场 Otto 把整个圆面包举过头顶，结尾女孩把半个面包举起来——同一个动作，从炫耀变成了分享。开场光圈从面包张开，结尾光圈收在女孩脸上。开场幕布拉开，结尾幕布合上。

## 2. 对标：学什么 / 刻意不学什么

| 对标 | 学什么（语法） | 刻意不学 |
|---|---|---|
| Buster Keaton《将军号》(1926)、《福尔摩斯二世》(1924) | **固定机位全景里完整发生的机关笑料**；面无表情反而更好笑；主角永远在跑 | 不复刻任何具体桥段、造型 |
| Harold Lloyd《安全至下》(1923) | 追逐里的"差一点"：扑空、回头看空拳头 | 不做高楼悬挂（v1 有，v2 删） |
| Georges Méliès | 光圈（iris）转场、舞台感 | 不做魔术特效 |
| 《艺术家》(2011) | 现代观众可读的默片情感节奏：字幕卡少而准，情绪段放慢 | 不用它的配乐与角色 |
| 默片影院钢琴伴奏（photoplay cue sheet） | 按段落换曲式：Maestoso / Andante / Hurry / Misterioso / Agitato / Tenderly；**钢琴本身模拟音效**（滑音 = 坠落，簇音 = 跷跷板，震音 = 悬念，砸和弦 = 西瓜） | 不用任何公版曲；旋律全部原创 |

**刻意不学**：卓别林流浪汉造型（圆顶礼帽、小胡子、手杖）一律不出现；不做 30 年代橡皮管卡通（那是 rubber-hose）。这里是真人比例的"版画式默片"：人物 7.5 头身、写实街景，只是黑白、帧率抖动。

## 3. 原生招式

| 招式 | 位置 | 做法 |
|---|---|---|
| **光圈开合** | 开场 5.3 s、结尾 45.9–49.2 s | 光圈是摄影机里的遮罩，所以在胶片后期**之前**画上，跟画面一起被做旧。开场从举起的面包张开；结尾收拢到女孩的脸，停住，她眨眼，再合上。 |
| **手摇放映速度** | 追逐 / 集市 | 动作采样 16 fps（平时）→ 18 fps + 1.3× 速度（追逐），放映机闪烁同时加快（`crank`）。温柔段回到 16 fps、老化减弱、棕褐加深。 |
| **胶片老化随情绪变化** | 全片 | `strength`：追逐 0.85 → 温柔 0.3；`sepia`：0.1 → 0.36。划痕、灰尘、烧边、片门跳动都跟着这个值走。 |
| **剧院幕布** | 开场 / 片尾 | 丝绒幕布在脚灯下拉开，放映机先响；片尾幕布合上，片尾甩片声。 |
| **钢琴当音效** | 全片 | 没有任何拟音：面包掉落 = 下行滑音，弹地 = 低音"嘣"，跷跷板 = 前臂砸簇音，西瓜上天 = 上行滑音，悬念 = 减七和弦震音，西瓜落下 = 高→中滑音 + 砸和弦，掰面包 = 一个清脆的高音小二度。 |

**静音**：① SIL（32.6–34.6 s）只剩放映机，之后第一个声音是簧风琴进入；② 集市里西瓜出画后的 2.5 s 是"停拍"——只有极弱的震音在涨，第一个重音是西瓜落头的砸和弦。**J-cut**：CARD1 结尾的加速跑句提前把追逐的速度带进来；簧风琴在字幕卡上就进入，延续进温柔段。**L-cut**：ROLL 的停止和弦余音延续进静音段后才消失。

## 7. 字幕设计

默片没有字幕条：**字幕卡就是字幕**。黑底卡片 + 装饰艺术边框，边框繁简随情绪变：`level 0` = 一道粗框（喊叫，文字抖动），`level 1` = 双线 + 阶梯角 + 扇形（叙述），`level 2` = 再加藤蔓和小花（温柔）。字体 OFL：Playfair Display SC（片名、喊叫）、Old Standard TT Italic（叙述、对白）。每张卡停 2.5–3.75 s。`.srt` 列出卡片文字。

## 8. 与风格说明的差异

1. **砍掉**电车、警察雾中追捕、悬挂在栏杆上的高处惊险（v1 的 16 段 → v2 的 13 段、一个连锁笑料）。理由：v1 就是因为内容太满被叫停；一个读得懂的机关笑料好过三个读不懂的。
2. **集市连锁机关简化**：v1 是跷跷板 → 西瓜 → 遮阳篷倾倒 → 橙子滚落 → 摊主踩橙子风车转 → 推车翻 → 箱子飞上路灯 → 砸警察，缩略图上完全看不清。v2 只保留"跷跷板 → 西瓜出画 → 等待 → 砸警察"，中间留 2.5 s 空白让观众等。
3. **片尾卡同时承担署名**："The End" 下面直接排片名、风格名、Lemo-Opuscar、LemoLab × Claude Opus 5.5 和素材署名，不另加一张卡。
4. **角色不用大特写**：引擎画的脸在大特写里像木偶，所以全片用全景和中景（这也正是 Keaton 的镜头语法），唯一的近景是光圈里的眨眼。
