# TREATMENT · 01 · 16-bit Pixel RPG ·《The Last Save Point》

> 时长 55.0 s ｜ 320×180 原生像素 ×6 = 1920×1080 ｜ 24 fps 输出（精灵 8–12 fps 步进，卷轴按帧走整数像素）
> 旁白：Kokoro `bm_george` speed 0.9，第一人称（主角 ARLO 本人）｜ 字幕 = RPG 对话框

---

## 1. 一句话故事

勇者 ARLO 独自站在最终之门前的存档点。选存档位时，三个旧存档一个比一个老、一个比一个"色少"——出发的村庄（4 色）、篝火的夜晚（8-bit）、失去 WREN 的那场战斗（16-bit 满色）。战斗里她倒下，回忆的颜色一级一级塌掉，塌成他现在活着的这个灰色世界。他新建存档（不覆盖任何回忆），系紧她留下的红围巾，推门——颜色从围巾开始，涨回整个画面。

情绪弧：**孤独 → 温暖 → 失去 → 决心**。一个角色（ARLO）、一个目标（推开那扇门）、一次转折（回忆里她为他挡下致命一击 → 他明白该带着她往前走）。

## 2. 对标：学什么 / 刻意不学什么

| 对标 | 学什么 | 刻意不学什么 |
|---|---|---|
| 《To the Moon》 | 用像素 RPG 讲记忆与失去；**用游戏自身的系统当叙事语言**（存档、道具、HP 在这里都有情绪含义）；克制，靠一两个小物件（这里是红围巾）贯穿全片；逆着记忆走向"核心时刻"的结构意识 | 它的具体故事（改写记忆的医生）、钢琴主导的配乐、俯视角地图的画面构成 |
| 《Chrono Trigger》《Final Fantasy VI》时代 SNES | 蓝色渐变对话框 + 头像 + 逐字打印；侧视战斗画面与屏上战报；遇敌旋涡转场；调色板动画（水晶、火把）；多层视差卷轴；SNES 回声（echo buffer）式的芯片配乐；存档点主题"温柔、短、可循环"，地区变奏用同一动机换配器与节拍，Boss 战前奏用同一动机转小调 | 任何具体角色、精灵、字体、UI 边框样式、菜单布局、旋律、音效；ATB 条之类可辨认的系统设计；Mode 7 旋转地面这种"炫技"；不做 CRT、不加颗粒（本风格说明要求干净像素） |
| 更早的掌机 / 8-bit 主机 | 4 色单色、2 脉冲 + 波表 + 噪声；8-bit 的黑夜天空、3 色精灵、三角波低音 | 不用任何真实机型的专用绿色色值，不复刻开机画面 |

与库里 `hd-2d` 风格划清界线：本片**没有**景深、辉光、实时光照，所有"光"都是调色板和抖动画出来的。

## 3. 原生招式（只有像素 / 调色板媒介能做到）

1. **色深即记忆（贯穿全片的规则）**：越久远的回忆色深越低。
   - 最早：**4 色单色**，而且分辨率也退一半（160×90，像素块 12×12），像更早的掌机；
   - 较早：**8-bit** 限定调色板（13 色、黑夜天空、3 色精灵）；
   - 最近：**16-bit 满调色板**（ENDESGA-32 全色 + 调色板动画 + 多层视差）；
   - **现在：褪色**——他失去她之后的世界只剩 6 阶蓝灰，全屏唯二带颜色的是存档水晶（青）和她的红围巾。
   - 声音也跟着"色深"走：4 色回忆的配乐是 4-bit 音量阶梯 + 采样率降格；8-bit 回忆是脉冲 + 三角波；16-bit 回忆有立体声和回声；"现在"的配乐被闷住（低通）。
2. **情绪高点 A · 调色板塌缩（失去）**：WREN 倒下后，16-bit 回忆的调色板每 0.6 s 掉一级：32 → 16 → 8 → 4 → 褪色灰，每掉一级一声"掉位"哔声。颜色塌到最后，正好就是"现在"的颜色——**这就是现在为什么是灰的**。只有地上她的红围巾不褪色，**匹配剪辑**到现在 ARLO 脖子上同一位置的红围巾。
3. **情绪高点 B · 调色板回涨（决心）**：推门的那一小节，颜色从围巾开始，用有序抖动（Bayer 阈值）一圈圈向外涨回满调色板；身后走廊的火把按顺序点燃，横幅、彩窗恢复本色。同一小节配乐从闷住的存档主题"满配"进入 Boss 前奏。
4. **转场语法**：温暖的回忆用**马赛克**进出（存档缩略图放大 + 块逐级变小）；失去那段用 RPG 的**遇敌旋涡**硬切进战斗——温暖被"遇敌"打断。
5. **游戏系统当情绪**：存档位 = 回忆清单（他最后选"NEW FILE"，一个都不覆盖）；她的名字在战斗窗口变灰、在现在的状态栏里仍是灰的；"没有旅店能治好的伤"；WREN 在回忆里**没有真人声音，只有打字哔声**——她只剩文字了。

## 6. 声音设计

- **全部程序化合成的芯片拟音**（numpy），并按"色深"处理：4 色回忆里的声音降到 4-bit / 11 kHz；8-bit 回忆 8-bit；16-bit 与"现在"满保真。
- 清单：水晶叮 / 嗡鸣（正弦合唱 + 慢 LFO）、光标移动（方波短哔）、确认（上行两音）、打字哔（ARLO 低、WREN 高）、脚步（石头：噪声短促 + 回声；村庄：更粗的 4-bit 噪声）、篝火噼啪（带通噪声爆点）、遇敌扫频、护盾（上行琶音闪烁）、冲击（噪声爆炸 + 降位）、HP 滚动（细哔）、KO 闪烁（下行哔）、掉位（每级更低、更粗）、存档完成、门轴摩擦（低频棕噪声 + 降位 + 摩擦纹理）、火把点燃（嘶 + 叮）、白闪（反向镲）、呼吸（**唯一不"芯片"的声音**：真实的气声滤波噪声，让 ARLO 在最后一刻像个真人）。
- 静音：33.2–35.0 战斗后真静音（连回声尾巴一起清零）。
- 混音：旁白压缩、音乐在旁白下闪避约 −8 dB；打字哔在旁白句下降到很轻（只做质感），在 WREN 无声的句子里才是主角。−14 LUFS，grain 0。

## 7. 字幕设计（字幕就是 RPG 对话框）

- **原生像素对话框**，画在 320×180 帧缓冲里（不是叠加的矢量字）：底部 y 134–174，圆角像素边框（外黑 / 白 / 浅灰三层），蓝色有序抖动渐变底，左侧 32×32 头像（ARLO 四种表情：怅然 / 微笑 / 悲伤 / 决心），自制**大小写可变宽像素字体**（x 高 5、升部 7、降部 2），白字 + 深蓝投影，逐字打印（约 40 字符/秒，与语音同时开始），打完后右下角 ▼ 跳动。
- **对话框跟着色深换皮**：4 色回忆里是掌机式浅底深字；8-bit 回忆是黑底白框；16-bit 与现在是蓝渐变（现在褪色时是灰蓝，颜色回涨后变回鲜蓝）。
- 战报（"WREN used WARD!"、"WREN fell."）用顶部细长窗口，和对话框区分。
- 每句停留 ≥ 1.8 s 且 ≥ 语音 + 0.6 s；下一句开始时上一句截止。另交 `.srt`（旁白 + WREN 的文字 + 战报）。

## 8. 相对风格说明的改动与理由

1. **回忆顺序改为 村庄 → 篝火 → 失去**（说明里是村庄 / 失去 / 篝火）：短片里要先让观众在乎 WREN，失去才会疼；并且"失去"放在最后，才能让调色板塌缩直接塌成"现在"的灰色，把原生招式变成因果（现在为什么褪色）。情绪弧仍是说明里的"孤独 → 回忆 → 失去 → 决心"。
2. **"现在"从开场就是褪色的**：说明要求推门那一刻"从褪色恢复满调色板"，所以褪色必须有来源——本片把它设定为失去之后的世界，并由塌缩那场戏揭示。
3. **4 色回忆分辨率也减半（160×90）**：让"越早越粗糙"在缩略图尺度也一眼可读；三段回忆各自是独立场景，不存在同屏混用像素尺寸的问题（只有马赛克转场里块大小在变，本来就是转场语言）。
4. **加入存档位列表 + "NEW FILE"**：把"存档读条就是回忆转场"具体化为"存档位就是回忆清单"，并给 ARLO 一个无声的选择。说明里的"SAVE COMPLETE"保留。

## 9. 画面规格

- 帧缓冲：320×180 **索引色**（Uint8 调色板索引），所有色深 / 褪色 / 塌缩 / 回涨都是换调色板查找表，像 SNES 的 CGRAM；最后 ×6 最近邻放大。
- 主调色板 ENDESGA-32 + 保护色（围巾红 3 阶、水晶青 3 阶——褪色表对它们不生效）。
- 有序抖动 4×4 Bayer 做天空、光晕、阴影渐变；无任何模糊、辉光、景深。
- 精灵：ARLO 约 22×32，WREN 约 20×30，8–12 fps；小时候版本（4 色）约 8×12；8-bit 版本 3 色 + 描边。
- 镜头：所有卷轴按整数像素；视差层独立取整；仰拍按整数像素上下摇。
