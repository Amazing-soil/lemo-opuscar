# Risograph Print · 导演方案（Treatment）

**片名** *Sunday Ride*
**时长** 40.0 秒（20 小节 × 2 秒，120 BPM）｜ **画幅** 1920×1080 ｜ **帧率** 24fps 输出；角色表演、墨粒、套色抖动按 12fps（on twos）步进 = "每两帧印一张"；横移镜头每帧平滑（镜头步进会被看成卡顿，brick-toy 的教训）
**一句话** 一个高瘦的眼镜男周日一早骑车穿城去河边吃早饭：城市一开始只印了一块蓝版，他每经过一个地方，印刷机就多上一块专色版——面包店上黄，公园上荧光粉，到河边三版叠印成最丰富的画面；最后镜头拉远，原来这是刚从 riso 印刷机里出来的一张纸。
**主题** 同一条路，每个周日都一样；同一块版，每一张都印得不一样。"Same ride every Sunday. Never quite the same print."

---

## 一、对标：学什么 / 刻意不学什么

| 对标 | 学什么 | 刻意不学 |
|---|---|---|
| **Tom Haugomat 的 riso 插画** | 大色块 + 剪影，人物很小、环境很大；极简构图（一条地平线、一个太阳、一个人）；用两三种专色的叠印做出第四、第五种颜色；长影子与低角度阳光 | 不照搬任何具体画面、人物造型、他的配色方案；他的人物多数没有五官，我们的主角要演喜剧，所以给了圆眼镜、大鼻子和简单表情 |
| **雅克·塔蒂《Jour de fête》骑车邮差** | 喜剧调度：角色在大全景里小小地完成一个动作（不剪近景也看得懂）；"不减速的交接"（邮差骑车递信 → 我们骑车接法棍）；城市节奏感：日常声响组成音乐；身体是细长而僵直的，靠姿态搞笑 | 不用他的角色形象（风衣、帽子、烟斗、邮差制服），不复刻任何具体桥段；我们的喜剧更轻，只有两个小笑点（接法棍、鸽子搭车） |
| **真实 riso 印刷的物理特性** | 专色是半透明的、multiply 叠印；每块版单独上机，所以一定有套色错位；网点、墨粒、实地里的漏白、沿走纸方向的墨色不均；荧光粉是 riso 最标志的颜色 | 不做"数码干净版"的扁平插画再加一层噪点——所有质感都在"分版"这一层模拟，颜色只能来自三块版 |

## 二、为什么这个媒介讲这个故事（原生能力 → 故事用法）

| Riso 的原生能力 | 故事里怎么用 |
|---|---|
| **分版：一次只能印一种颜色** | **分版即叙事**：开场只有蓝版（清晨未醒的城市是单色的），面包店一开灯 → 上黄版，公园 → 上荧光粉版。角色本身也是按版设计的：只开蓝版时他是一个完整的蓝色剪影，加黄版多了围巾和法棍，加粉版多了脸颊和紫色的车 |
| **专色叠印混色**（粉 + 蓝 = 紫，黄 + 蓝 = 绿，黄 + 粉 = 橙） | **叠印转场（情绪高点）**：一轮荧光粉的太阳从公园的画面里长出来，盖满整个画面——它经过的蓝色全部变成紫色——再缩回去，变成河上的太阳，而底下已经换成了河边 |
| **套色错位** | 套色随节拍"跳一下"（片名、每次上新版、鸽子起飞、每个重拍）；**音乐停顿的一小节里，三块版慢慢漂开**（画面在"呼吸"），下一个重拍"咔"地套准，全乐队回来 |
| **倒影 = 错位** | 河面倒影里三块版各自摆动、互相错开——水波就是套不准的版 |
| **网点半调 + 墨粒** | 天空、草地、阴影全部用网点做中间调；墨粒每两帧重新"印"一次（12fps 沸腾），像一本逐张印出来的翻页书 |
| **它是一张纸** | 结尾尺度揭示：俯拍河边的长影子，镜头一路拉远，这张画从印刷机出纸口滑出，落在一叠纸上——底下几张露出前面的场景（只有蓝版的街、面包店、公园） |

**情绪弧**：困倦（单色、安静）→ 苏醒（上黄）→ 欢快（上粉、鸽子）→ 小小的转折（一只鸽子搭车抢了他的早饭位置）→ 高点（河边，全版叠印，音乐停一拍再回来）→ 温暖（他把法棍掰一半分给鸽子）→ 回响（尺度揭示 + "每一张都不一样"）。
一个角色、一个目标（带着法棍去河边吃早饭）、一次转折（多了一个不请自来的同伴，独自的早饭变成了分享）。

## 三、角色

> **关卡 1 后的修改（协调者意见）**：原设计"高瘦 + 圆眼镜 + 横条纹毛衣"容易联想到一个著名的找人绘本角色 → 去掉条纹，改成纯色毛衣（蓝 40% + 粉 100%，单蓝版时是浅蓝网点、全开时是莓紫），标志换成一条粗针织大围巾（黄 + 粉：单蓝版时是纸白挖空，加黄版时第一个被点亮，全开时是橙红），裤子改成蓝 + 黄（全开变绿）。鸽子放大到约为他头部的 1.2 倍，给了圆胸、小碎步点头、歪头的性格和 4 帧扑翅循环。设定表 v2：`demo/stills/modelsheet_v2.jpg`。以下为原方案文字（配色以 v2 为准）。


**骑车的人**（无名）：三十来岁，8 头身的高瘦个子（塔蒂式的细长僵直身体）、圆框眼镜、大鼻子、一头蓬松的"拖把"短发、蓝白条纹毛衣、深蓝裤子、露出一截袜子、长长的黄色围巾（运动方向的指示器：骑车时向后飘）。骑一辆老式城市车：前筐、挡泥板、链罩、车铃。
**鸽子**：灰蓝身体、颈部一点粉色（加粉版后才"亮起来"），配角兼转折。
**面包师**：只出现一只从门里伸出来的手。

按版配色（颜色 = 三版浓度 蓝/黄/粉）：头发蓝 100 + 粉 22（全版时发紫），皮肤黄 26（只开蓝版时是纸白），脸颊粉 62，条纹 蓝 100 / 纸白，裤子蓝 100 + 粉 18，围巾黄 100，车架蓝 72 + 粉 100（只开蓝版时是蓝网点，全版时是紫色）。

## 六、声音设计（拟音跟材质走：纸 / 金属车铃 / 城市）

- **印刷机**（全片的标志音效）：每次上新版 = 进纸"唰" + 滚筒低沉的"咔嚓—咚"；结尾出纸 + 纸张落在纸堆上的轻"啪"。
- **自行车**：飞轮棘轮的滴答（滑行时响、蹬车时停）、链条轻微沙沙、轮胎压过石板路的低频颗粒、车铃（金属钟，两个非谐和分音 + 快速连击 = "叮铃铃"）、刹车的短促金属尖音。
- **地点环境**：蓝色街道 = 远处鸟叫、几乎无声；面包店 = 门铃、烤箱暖气般的低频嗡声；公园 = 鸽子咕咕、鸽群起飞的振翅（大量短促带通噪声）；河边 = 水拍岸、远处教堂钟（周日）。
- **法棍**：面包皮碎裂的"咔嚓"（高频颗粒噪声 + 短共振）。
- 混音：旁白压缩后置前，音乐在旁白下闪避约 −8 dB；拟音不做混响堆叠，保持"纸感"的干、近。最终 −14 LUFS，mux grain = 0（颗粒已在画面里）。

## 七、字幕与标题设计（也是 riso 印出来的）

- **字幕**：底部居中一条"纸白贴纸"——三块版上都挖空的圆角条（因为三块版各自错位，挖空的边缘会有一点彩色毛边，像真的套印），文字只印在**蓝版**上（Jost 500，44px，字距 0.5），跟着蓝版一起错位、一起有墨粒。
- **片名**：SUNDAY RIDE，Bricolage Grotesque 800 大写，只用蓝版印在天空里；上场时从左往右被"刷"出来，节拍上跳一下。
- **片尾卡**：同一个片名用三块版分别印（粉、黄、蓝各偏移几像素 = 经典 riso 三色错位字），下面是 "Risograph Print" 和 "LemoLab × Claude Opus 5.5"，角落有套准十字线。

## 八、对风格说明的调整（及理由）

- **配乐**：风格说明里 STYLES.md 写 Lo-fi 爵士，批次说明写 bossa nova —— 采用 **bossa nova**（尼龙弦吉他 + 轻打击），并把"每加一版多一件乐器"扩展成"拉远时逐件撤掉"，让音乐的叠版和画面的叠版在结尾一起"卸版"。
- **第四件乐器**：只有三块版，但河边需要"比公园更满"，所以河边加的是颤音琴，对应的画面变化不是新颜色，而是**叠印最多**（太阳、倒影、紫色的影子）。
- **结尾**：两个建议（俯拍影子 / 印刷机尺度揭示）合成一个镜头：先俯拍影子，再一路拉远到出纸口。
- **转折**：加了一只"搭车"的鸽子，把纯风景片变成有一个小转折的故事（独自吃早饭 → 分享）。
