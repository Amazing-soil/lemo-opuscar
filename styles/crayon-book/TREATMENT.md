# Crayon Picture Book · 导演方案（Treatment）

**片名** *The Moon Can't Sleep*
**时长** 约 52 秒（风格说明建议 45 秒，理由见第八节）｜ **画幅** 1920×1080 ｜ **帧率** 24fps 输出；角色、线条、涂色一律 12fps（on twos，每 2 帧重画一次笔触 = 线条沸腾）；镜头运动、水彩刷子前沿、星星闪烁走 24fps
**一句话** 月亮失眠了；屋里一个也睡不着的小女孩爬上屋顶给它唱摇篮曲——她一开口，一把看不见的大刷子把"还没涂的夜空"刷成深蓝，藏在白纸上的蜡笔星星全浮了出来，月亮终于拉上被子，睡成一弯新月。
**主题** 夜空原来一直空着，是一首歌把它"涂"满的。

---

## 一、对标：Raymond Briggs《The Snowman》（1982）

| 向它学 | 具体怎么用 |
|---|---|
| **蜡笔/彩铅的"手感"就是画面本身**：每一帧都像重画过，线条和纹理轻轻呼吸 | 全片线条 12fps 沸腾；涂色是看得见一趟一趟来回的排线；纸纹在每一帧里都在 |
| **无对白、音乐主导情绪**：飞行段一整首歌接管叙事，画面让位给音乐 | 唱歌段 10 秒（4 小节）**完全没有旁白**，旋律完整走一遍，画面只做一件事：刷夜空、显星星 |
| **夜空的抒情段落**：深蓝的夜 + 暖黄的窗 + 小小的人 | 冷暖对比贯穿：暖黄窗光 / 黄月亮 vs. 群青水彩夜空；人物永远小于天空 |
| **窗边的孩子**：孩子隔着窗看外面的奇迹 | 女孩第一次出场就在亮着灯的窗里，隔着窗和月亮对视、挥手 |
| **慢**：留白、停顿、不急着讲下一件事 | 每句旁白后都留一拍；数羊之后有一整拍静音；片尾音乐盒自己慢慢停 |

| 刻意不学 | 为什么 |
|---|---|
| Briggs 的写实彩铅素描（成人插画家的体积、光影、解剖） | 这个风格是"孩子现场画出来的"：平面、孩子式透视、涂出边界，才是蜡笔绘本的辨识度 |
| 雪人、男孩的造型，《Walking in the Air》的旋律，飞越雪原的画面 | 版权红线；角色、旋律全部原创 |
| 伤感结尾（雪人融化） | 这是睡前故事，结尾是"安心"——两个都睡着了 |
| 完全无旁白 | 绘本本来就有文字；旁白 = 书页上的那几行字，极少（7 句），唱歌段让位给音乐 |

## 二、为什么选这个讲法：蜡笔 + 水彩的"天生本事"

| 媒介能力 | 故事里怎么用 |
|---|---|
| **蜡笔防水（wax resist）**：白蜡笔画在白纸上几乎看不见，水彩一刷就显出来 | **情绪最高点**。开场夜空是白纸（孩子还没涂夜空），星星早就用白蜡笔画好了、只是看不见；女孩唱歌时三道大刷子扫过，星星一片片浮现 |
| **"现场画出来"**：线条一笔一笔出现，颜色一趟一趟涂进去 | 开场白纸上画出房子和月亮；梯子在她伸手之前一格一格画出来；数羊时孩子在天上歪歪扭扭写 1、2、3；她唱歌时蜡笔音符一个个画出来飘走 |
| **涂色就是动作** | 月亮"拉上被子"= 用紫蜡笔把月亮的一大半**涂**掉，剩下的一弯就是睡着的新月（月相 = 被子） |
| **线条沸腾（boil）** | 每 2 帧重画一次：静止的画面也是活的；睡着以后沸腾幅度减半，画面"安静下来" |
| **孩子式透视与涂出边界** | 房子正面山墙 + 斜着的侧墙侧屋顶（孩子画房子的典型"错误透视"）；颜色永远出一点边 |
| **它本来就是一本书** | 全片一镜到底在"同一张画"上移动，结尾拉出——原来是一本打开的绘本的一页，旁边放着蜡笔和一支还湿着的蓝色水彩刷；翻页收尾 |

**情绪弧**：好笑的失眠（翻身、数羊，越数越精神）→ 一个同样醒着的孩子（温柔）→ 爬上去（小小的勇敢）→ 唱歌 + 夜空显现（奇迹、情绪最高点）→ 月亮睡着、女孩也睡着（安心）→ 合上的故事（回响）。
**首尾呼应**：开场一张白纸画出一轮睁大眼睛的圆月 → 结尾同一张画已涂满夜色、月亮成了闭眼的弯月；开场第一笔是屋顶线 → 结尾女孩就睡在这条屋顶线上；片尾翻到下一页，又是一张白纸，写着 The End。

## 三、角色

- **女孩（设定表里叫 Pip，片中不出现名字）**：约 2.6 头身，圆脸、点点眼、圆腮红；深棕蘑菇头 + 锯齿刘海 + 头顶一根小呆毛；**黄色星星发夹**（和星空呼应）；粉色小圆点睡裙、浅蓝领子、蓝白条纹袜。随身抱着一只**小羊玩偶**（和"数羊"呼应：天上的羊数不睡月亮，她怀里的羊陪她睡着）。
- **月亮**：黄蜡笔圆盘 + 孩子画的脸：瞪得溜圆的眼睛 + 紫色黑眼圈（好几个星期没睡）、橙色环形山、橙腮红。表情：瞪眼 / 皱成一团翻身 / 眼珠跟着羊转 / 打哈欠 / 眼皮打架 / 闭眼。入睡时被紫色"被子"一点点涂上，变成侧脸睡着的弯月。
- **天上的羊**：白蜡笔身体、紫色脸，排队从月亮前跳过。
- 设定表：`demo/stills/modelsheet_v1.jpg`（女孩：四面转面、5 个表情、4 个关键姿势、12 支蜡笔色板）、`demo/stills/modelsheet_v1_moon.jpg`（月亮：5 个表情、入睡四步、蜡笔防水材质试样、天上的羊）。

## 四、分镜节拍表（按秒）

**音乐网格**：3/4 拍摇篮曲，72 BPM，1 拍 = 0.833 s，1 小节 = 2.5 s。所有剪辑点、动作重音落在拍上。
**镜头总设计**：**全片一镜到底**，镜头只在"一张画纸"上推、摇、拉（画纸世界坐标 3200×2000）。为什么：这是一页绘本，本来就是一张画；最后拉出成书页时，观众才明白前面所有的"镜头"都是在同一页上移动——一镜到底被结尾解释。

画面布局（世界坐标）：左下是孩子画的房子（正面山墙 + 斜侧墙 + 大片红屋顶 + 烟囱），侧墙上一扇亮着黄灯的窗 = 女孩的房间；房子左边一棵圆冠小树；底部一条草地；右上是月亮；左上是片名的位置；整片天空是白纸（上面早已用白蜡笔画满看不见的星星）。

## 五、原生招式与情绪高点

1. **蜡笔防水显星（情绪最高点，27.5–37.5）**：技术上是真的"蜡笔防水"：星星（白蜡）、月亮、屋顶、女孩都画在"蜡层"上；水彩着色器读每个像素的蜡覆盖率，蜡厚的地方水彩被推开，蜡笔跳过的纸纹缝里水彩渗进去——所以星星边缘是颗粒状的、蜡上还挂着小水珠。水彩本身有水痕边（颜料在边缘堆积）、颗粒沉积、浓淡渲开。
2. **世界替她画出来**：梯子一格一格在她手前出现。
3. **涂色即动作**：月亮的"被子"是一趟趟紫色排线涂出来的，月相就是被子。
4. **线条 12fps 沸腾**：所有线条、涂色每 2 帧重新抖动一次；入睡后幅度减半。
5. **书页揭示 + 翻页**：一镜到底被解释，工具（蜡笔、湿刷子）摆在旁边，暗示"那把看不见的刷子"是谁的。

## 七、声音设计

- **拟音跟着材质走**：蜡笔刮纸（粘滑摩擦的颗粒噪声，笔画越快越密，涂色是节奏性的来回"沙–沙"）；湿刷子（低通的柔软宽带噪声 + 鬃毛细颗粒，声像跟着刷子走）；星星 = 钟琴粒子；羊落地 = 毡子"噗"；翻身 = 被子嗖声；梯子一格 = 蜡笔"嚓"；翻页 = 真纸张的掀起、翻过、落下三段。
- **夜的底色**：极轻的蟋蟀（只在第 6、7 段）；最后书桌场景换成暖暖的室内底噪。
- **静音是工具**：数羊之后一整拍静音；唱歌前 0.3 s 空拍；片尾音乐盒自己停下。
- **旁白**：（v3 已换声为 Kokoro `af_heart`，更柔更暖，见 PRODUCTION_LOG「六」）原方案 Kokoro `bf_emma`（英式睡前故事女声），语速 0.82–0.88；轻压缩 + 一点小房间混响，贴着耳朵讲；音乐在旁白下闪避约 −7 dB。每句 whisper 校对（已试：6/7 通过，"Goodnight." 被听成 "A good night"，改写为 "Good night." 再测）。

## 八、字幕设计

- 字幕就是**书页上的字**：靛蓝蜡笔手写（Patrick Hand，OFL），54 px，底部居中；每个字母有自己的微小倾斜和上下错位，每 2 帧跟着沸腾一次；出现方式是 0.35 s 内从左到右"写出来"。
- 为了在草地、墙面上也能读：字的后面"留白"一块形状不规则的纸（像孩子画画时给字留出的空），不用深色底条。
- 停留：每句至少 1.8 s 且不短于语音 + 0.6 s；两句之间不重叠；唱歌段无字幕。
- 另交 `crayon-book.srt`（与烧录字幕同一份数据导出）。

## 九、和风格说明的差异（导演决定）

1. **刷子不出镜**：说明里写"一把大刷子扫过"。我让刷子本身不出现，只看见湿润的刷痕、鬃毛条纹和前沿的水光——它像是被她的歌声推着走；**直到最后拉出成书页，桌上那支笔头还湿着蓝色的平头刷才揭晓答案**。这样奇迹保持在画里，结尾多一层回响。
2. **夜空一开始是白纸**：孩子画画常常不涂天空。白纸夜空让"白蜡星星完全看不见"成立，也给了月亮睡不着一个孩子式的理由——夜还没被涂上。
3. **月亮变新月 = 拉上被子**：用"涂色"这个媒介动作完成月相变化，而不是形状变形。
4. **女孩睡在屋顶上是仰躺**，小羊趴在胸口，和天上那一群"数不睡月亮的羊"对照。
5. **时长约 52 秒**：唱歌段要让旋律完整走完 4 小节（10 秒，不能砍），7 句旁白各自需要阅读时间，片尾书页揭示 + 翻页 + 片尾卡需要约 7 秒。压到 45 秒只能砍旋律或砍停留，违背"节奏以观众为准"。

## 十、制作方案

- **引擎（demo/）**：Canvas2D 画"笔压层"（RGB = 蜡笔颜色，A = 笔压）→ WebGL2 合成：程序化纸纹高度场，**笔压 > 纸纹凹陷深度才附着**（蜡只挂在纸的凸起上）；水彩层读下方的蜡覆盖率做防水、水痕边、颗粒沉积；终合成做纸纹浮雕和暖暗角。角色是参数化 rig（视角 × 表情 × 姿势），部件遮挡时擦掉后面的线并在身后"留白"。
- 文件：`gl.js`（合成器）、`crayon.js`（笔触引擎：线、之字排线涂色、手写字、形状工具）、`rig.js`（部件/肢体/遮挡）、`chars.js`（女孩、月亮、羊）、`pal.js`（12 支蜡笔 + 1 管水彩）、`sheet.js`（设定表）、后续 `world.js`（房子、梯子、星星、水彩刷痕）、`film.js`（时间线、镜头、字幕、事件）、`music/score.py`、`mix.py`、`build.sh`。
- 流程：配音（已生成试听）→ whisper 校对 → 时间线 → 画面 → 两轮缩略图审查 → 配乐（优先 core 采样乐器：音乐盒/钟琴/长笛/单簧管；未就绪则 numpy 合成，可能 fork 子 agent 写）→ 拟音 + 混音 → 渲染 → mux（grain 1–2）→ 自检。
