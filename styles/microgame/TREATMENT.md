# Microgame Frenzy · 导演方案（Treatment）

**片名** *Five-Second Astronaut*（五秒宇航员）
**时长** 约 60 秒（120 → 140 → 160 BPM 三段速度网格，见第六节）｜ **画幅** 1920×1080 ｜ **帧率** 24fps 输出；角色动画的步进随速度升级：第 1 轮 8fps（on threes）→ 第 2 轮 12fps（on twos）→ Boss 关 24fps（on ones）。镜头运动、转场、引线火花永远 24fps。
**一句话** 笨手笨脚的见习宇航员 Cadet Dot 参加"五秒训练营"：秒表脑袋的主持人 Coach Tick 每按一下头顶的按钮，就把她丢进一个只有几秒、画风完全不同的微游戏；她在第一轮打了个喷嚏（输了一条命），第二轮敬礼把自己的天线敲飞（又输一条），只剩最后一条命进 Boss 关——亲手把返回舱降回地球。降落伞卡住的一瞬间，她故意吸了一口那颗曾害她输掉的灰尘：**一个水墨喷嚏喷出舱门，在天上洇开成一顶降落伞。**
**主题一句话**：你最丢人的那个失误，可能就是你的降落伞。

## 一、对标：学什么 / 刻意不学什么

| 对标 | 学什么（语法） | 刻意不学 |
|---|---|---|
| **《瓦里奥制造》系列（WarioWare, 2003–）** | ① 一个命令词 + 几秒 + 一个动作；② 微游戏之间回到主持人舞台，舞台显示剩余生命、关卡数；③ 每过几关 SPEED UP，最后 Boss 关更长；④ **每个微游戏画风完全不同**，画风反差本身就是笑点和节奏；⑤ 失败也要好笑，失败画面和成功画面同样被"演"出来 | 不出现任何原作角色、微游戏、UI 图形（炸弹、生命图标、舞台造型）、音乐旋律、字体；片中不出现 "WarioWare" 字样。炸弹引线计时条只借"引线烧完 = 时间到"的通用游戏语言，造型改成**一根缠着刻度的编织引线 + 末端一枚小冲天炮**，全部自己设计 |
| **Edgar Wright 式动作剪辑**（《Scott Pilgrim》《Hot Fuzz》的蒙太奇语法） | 一个动作 = 一个声音 = 一个剪辑点；快速插入镜头（按钮特写、脸部特写）打在拍点上；用画框本身做转场 | 不做它的具体画面、漫画拟声字排版、镜头设计 |
| **综艺 / 游戏宣传片的快切节奏** | 老虎机式滚轮、计分板翻牌、主持人冲镜头喊口号 | 不用任何节目的舞台布景、吉祥物、口号 |
| **70 年代放克 / 游戏配乐融合**（语法） | 十六分音符军鼓鬼音 + 拍手、slap 贝斯八度跳、铜管齐奏打重音、电钢琴切分和弦；每次加速用一个上行乐句"推"过去；成功 / 失败各有短 jingle | 不引用任何现成旋律、动机、音色标识；不做 8-bit 芯片音乐（pixel-rpg 做过）、不做间谍大乐队（spy-titles 做过）、不做 ragtime（rubber-hose 做过） |

**和 07 game-show 的区别**：game-show 是单一扁平画风、按拍切菜的节奏游戏；本片的核心是**命令词 + 微游戏 + 画风每 3–4 秒换一次**，并且画风变化本身参与叙事（失败的画风在 Boss 关变成解法）。

## 二、为什么这个媒介讲这个故事（原生能力 → 故事用法）

| 微游戏快闪的原生能力 | 故事里怎么用 |
|---|---|
| **画风硬切**：每个微游戏是一个独立的小世界，可以用完全不同的"绘画材料" | 7 个微游戏 = 本库 7 个风格（蜡笔绘本、水墨、ASCII 终端、孔版印刷、像素、蓝图、瑞士排版）。同一个主角在每个画风里被重新画一遍，**只保留三个剪影标志**（圆泡泡头盔、头顶的橙色弹簧天线球、胸前 05 号码），观众每次都能认出她 |
| **命令词**：一个动词就是整段剧情 | PUMP! / DON'T SNEEZE! / STRAP IN! / CATCH! / DODGE! / ZIP! / SALUTE! / LAND IT!——命令词就是字幕，也是节拍 |
| **生命值**：UI 本身就是情绪曲线 | 3 个头盔图标 → 2 → 1（闪烁）。观众不用任何旁白就知道"最后一条命"意味着什么 |
| **SPEED UP**：游戏可以整体变快 | 音乐 BPM、角色帧率、命令词停留、微游戏时长、舞台停留**五件事同时变快**，观众用身体感觉到加速 |
| **Boss 关把规则混在一起** | 一个画面里同时有 5 种画风：蓝图画的返回舱、蜡笔画的地球、ASCII 高度表、孔版印刷的海和云、瑞士排版的红色落点圆，以及——水墨的降落伞 |

**情绪弧**：好笑的开场（第一秒就在玩游戏）→ 自信（第一关过了）→ 丢人（水墨喷嚏，−1 命）→ 找回节奏（绑带、接三明治）→ 加速的兴奋 → 第二次丢人（敬礼把天线敲飞，−1 命）→ 静（最后一条命，灯暗，只剩心跳）→ Boss 关：降落伞失灵、全场静音 → **转折：她自己选择打那个喷嚏** → 水墨伞洇开、全乐队回来、升调 → 落在红圆正中 → 回响：主持人说"敬礼"，这次她敬得完美，天线球稳稳立着。
一个角色（Dot）、一个目标（通过训练营 = 把返回舱降回地球）、一次转折（她的失误变成解法）。

## 三、原生招式（放在情绪最高点）

1. **画风快切**（贯穿全片）：一个命令词切一次画风。转场统一成一套"电视框语法"：舞台中央有一台圆角大电视，进入微游戏 = 镜头冲进电视屏幕（6 帧放大到满屏，"呼"一声）；微游戏结束 = 整个画面缩回电视里（8 帧），同时盖上 ✓ 或 ✗ 的结果章。没有淡入淡出、没有空白帧。
2. **SPEED UP 老虎机**（26.0–27.9s，本片"让人记住的镜头"）：主持人一掌拍下舞台上的大按钮，整个舞台画面被竖着切成三条滚轮，像老虎机一样向上狂转（每条滚轮上滚过的是前 4 个微游戏的画面 + 舞台本身），三条滚轮在上行乐句的第 2、3、4 拍依次"咔"地停下，拼出 **SPEED | UP | !**。同一小节里音乐从 120 加速到 140。
3. **BOSS STAGE 拼贴**（39.0–40.6s）：7 个微游戏各自的最后一帧变成 7 块瓷砖铺满屏幕，随上行乐句翻面、飞向中心，拼成 Boss 关的画面——Boss 关本来就是"用前面所有画风的碎片搭起来的"。
4. **情绪最高点：水墨喷嚏降落伞**（Boss 关第 3–5 小节，43.6–48.1s）：拉伞失败（像素风的小伞"噗"地冒一下就变成 ERR 方块），音乐抽空只剩心跳和引线嘶嘶声；第 2 轮失败时飘来的那颗水墨灰尘又飘进舱里——Dot 看着它，眼睛一亮，**深吸一口**，"ah… ah…"；第 5 小节第 1 拍 **ACHOO!!**：一团水墨从舱顶喷出，在孔版印刷的天空上洇开、晕染、边缘积墨，长成一顶真正的伞盖，墨线垂下来变成伞绳。全乐队 + 铜管齐奏回来、调性上移一个全音。**失败时的画风，变成了解法的材料**——这是只有"多画风微游戏"这个媒介才讲得出的转折。
5. **炸弹引线计时条**：每个微游戏底部一根燃烧的引线（主持人舞台的造型语言，在所有画风上都保持一致 = "游戏引擎层"）。引线上每拍一个刻度结，火花**正好在拍点经过刻度**，最后一拍烧到末端的小冲天炮，冲天炮"噗"地弹出成功/失败章。Boss 关的引线加粗、带双股火星、长度是普通关的 4 倍。

## 四、角色（关卡 1 交设定表）

所有角色原创。主持人舞台（"家"）用统一的**粗描边扁平卡通**：8px 近黑描边 `#1a1030`、平涂 + 一层硬边阴影、高饱和配色。

- **COACH TICK（主持人）**：脑袋是一只**金色机械秒表**（圆形表壳 + 顶上的按钮表冠 + 挂环）。表盘是他的脸：奶油色表盘、12 道刻度围一圈、两只椭圆大眼、一张很宽的嘴；一根**红色秒针**从表盘中心伸出，平时指向 12 点，情绪激动时会转（喊 SPEED UP 时秒针飞转）。身体很小：品红亮片燕尾服、青色翻领、黑色领结、白手套、细腿大球鞋。标志动作：**一掌拍自己头顶的表冠** = 开始下一个游戏（"咔哒"）。另有一只手持麦克风。
  - 表情：大笑 / 冲镜头喊命令 / 捂脸（Dot 打喷嚏后）/ 严肃（最后一条命时，秒针停住、灯暗）
- **CADET DOT（主角，见习宇航员）**：约 2.3 头身的矮圆女孩。**圆泡泡玻璃头盔**（青色领圈，玻璃里能看见脸：桃色皮肤、大圆眼、雀斑、被头盔压扁的棕色丸子头）；头盔顶上一根**弹簧天线 + 橙色小球**（任何动作都会"啵嘤"地晃，是她的情绪指示器）；奶油白宇航服、橙色肩片和靴子、胸前 **"05"** 号码补丁（五秒训练营的 5 号学员）、橙色背包。
  - 表情：认真（舌头伸出一点）/ 憋喷嚏（眼睛眯、鼻孔张大、嘴歪）/ 慌 / 骄傲
  - **在 7 种画风里的"翻译"规则**：永远保留圆头盔 + 天线球 + 05；其余按该画风的规则重画（蜡笔 = 儿童画比例；水墨 = 几笔写意；ASCII = 字符拼成；孔版 = 两块色版叠印；像素 = 24px 小人；蓝图 = 正视工程图；瑞士 = 圆 + 矩形 + 红圆天线）。设定表里单独画一行"画风翻译"。
- **色板（家）**：舞台品红 `#ff2e88` · 紫 `#6b2bd9` · 深紫 `#2a0f5c` · 金 `#ffc928` · 暗金 `#e08a00` · 表盘奶油 `#fff6de` · 青 `#1fd1d1` · 宇航服奶油 `#f6f1e4` · 橙 `#ff7a1a` · 皮肤 `#ffc9a3` · 描边 `#1a1030` · 成功绿 `#3bdc5a` · 失败红 `#ff3b3b`

## 五、7 个微游戏（每个都有"目标 + 结果"）

| # | 命令词 | 画风（本库风格） | 目标 | 结果 | 为什么这个画风配这个游戏 |
|---|---|---|---|---|---|
| 1 | **PUMP!** | 蜡笔绘本（crayon-book） | 用打气筒给一枚气球似的火箭打气 | ✓ 火箭鼓成圆滚滚一只、离地浮起，Dot 蹦起来 | 儿童画里"火箭是吹起来的"最合理；开场要最友好、最暖的画风 |
| 2 | **DON'T SNEEZE!** | 水墨（ink-wash） | 一颗灰尘飘进头盔，忍住别打喷嚏 | ✗ **ACHOO!**——墨汁喷满整块面罩/画面，水墨晕开 | 喷嚏 = 一大团墨迹，只有水墨能把"喷"画成"洇开" |
| 3 | **STRAP IN!** | ASCII 终端（ascii-crt） | 把安全带扣上 | ✓ `====` 滑进 `[  ]`，扣成 `[##]`，终端反白显示 SECURED | 扣带子是"咔哒"一声的机械动作，配终端的继电器声 |
| 4 | **CATCH!** | 孔版印刷（risograph） | 失重舱里接住飘走的三明治 | ✓ 一把抓住，大咬一口 | 飘浮的柔软东西 + 粉/蓝/黄叠印，最松弛的一关，放在加速前 |
| 5 | **DODGE!** | 像素（pixel-rpg） | 跳过三颗飞来的陨石 | ✓ 三连跳全躲过（第三颗擦着靴底） | 横版跳跃是像素游戏的母语 |
| 6 | **ZIP!** | 蓝图（blueprint） | 把宇航服拉链拉到顶 | ✓ 拉链头沿虚线一格一格上去（每八分音符一格），盖红章 OK | 拉链 = 尺寸线上的刻度，一格一格"咔咔咔" |
| 7 | **SALUTE!** | 瑞士排版（swiss-motion） | 敬礼 | ✗ 手臂矩形转过头，一下敲飞头顶的**红圆**（天线球），红圆弹出网格滚出画面 | 瑞士网格里"一个元素出格"就是笑点；红圆在 Boss 关回来当落点 |
| B | **LAND IT!** | 混合：蓝图返回舱 + 蜡笔地球 + ASCII 高度表 + 孔版海与云 + 像素小伞 + 瑞士红圆落点 + 水墨大伞 | 把返回舱降落在海上的红圆里 | ✓ 正中红圆，水花溅起 | 前面每个画风的碎片都在这里"复用"，观众会自己认出来 |

**命令词设计**：主持人舞台的超粗展示字（OFL），白字 + 12px 近黑描边 + 金色硬投影，−6° 倾斜，占满半屏；第一拍"砸"进来（缩放 1.6 → 1.0，带 2 帧过冲），停 0.6–0.75s，然后缩到左上角变成一个小标签留到游戏结束。主持人同时喊出这个词。

## 六、速度网格与分镜节拍表

**速度网格**：第 1 轮 120 BPM（1 拍 0.500s，1 小节 2.000s）→ 加速小节 120→140 → 第 2 轮 140 BPM（1 拍 0.4286s）→ 加速小节 140→160 → Boss 160 BPM（1 拍 0.375s，1 小节 1.500s）。

| 舞台停留 | 1 小节 = 2.00s | 2 拍 = 0.86s | — |

## 九、字幕设计

- **命令词就是字幕**：命令词是满屏大字，不再重复烧录；只进 .srt。
- **旁白字幕**（主持人 / Dot 的非命令台词）：舞台风格的"对话牌"——金黄 `#ffc928` 圆角牌 + 6px 近黑描边 + 4px 硬投影，Lilita One（OFL）48px 近黑字；牌子左侧一个小图标（主持人 = 秒表，Dot = 头盔）。位置：底部居中、离下边 110px，**在微游戏里自动避开底部引线**（抬高到引线上方）。弹出：缩放 0.8 → 1.0，12fps 两步（和家画风的步进一致）。
- **停留**：每句 ≥ max(1.8s, 语音 + 0.6s)；两句不重叠；命令词大字期间不出旁白字幕。
- **.srt**：包含全部台词（含命令词）。

## 十、技术方案

- 纯 Canvas2D + 一个小 WebGL2"材料通道"（`glpass.js`）：把某个画风的中间画布送进着色器，出孔版半调（RGB = 三块色版的密度）、蜡笔上牙纸纹（A = 压力）、ASCII 的磷光辉光 + 扫描线、水墨湿边积墨。一个通道服务 4 个画风。
- 每个画风一个模块（`styles/*.js`），每个模块导出 `draw(ctx, t_local, params)`，只画自己的小世界；主持人舞台和引线 / 命令词 / 生命值是统一的"引擎层"。
- 其它风格目录的代码与素材**一律不拷贝**，只读它们的 STYLE.md 抓要点后用简化代码重画。
- 字体（OFL，自行下载到 `demo/fonts/`）：命令词与 UI 用超粗展示字，字幕 Lilita One，ASCII 用等宽终端字，蓝图用手写制图字，瑞士用无衬线怪诞体，蜡笔用手写体。
- 配乐 fork 一个子 agent 按本 cue map 写（契约：BPM 网格 + 每段配器 + 卡点列表 + 两处真静音），画面并行制作。
