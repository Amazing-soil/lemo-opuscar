# 60s Spy Title Sequence · 导演方案（Treatment）

**片名** *The Velvet Cipher*（虚构的 1964 年间谍片片头）
**时长** 约 43.6 秒（24 小节 × 1.818 秒，132 BPM）｜ **画幅** 1920×1080 ｜ **帧率** 24fps 输出；剪纸人物、剪纸毛边"沸腾"按 12fps（on twos）步进，像纸偶一格一格挪；镜头横移、网格飞线、字幕滑入按 24fps 平滑（镜头步进会被看成卡顿——brick-toy / risograph 的教训）
**一句话** 一个剪纸特工追一把被偷走的黄铜钥匙，穿过机场、夜班列车、赌场、屋顶——每个地方都是一行演职员字幕搭成的布景；追到屋顶，他接住钥匙的一瞬间，一路追过的几何碎片全部沿斜线飞回来拼成片名，片名里的"I"正好是个钥匙孔，钥匙插进去，片名合拢。
**钥匙开的是什么？** 开的是这部电影。"Nobody knows what it opens." → "Now you know what it opens."

## 一、对标：学什么 / 刻意不学什么

| 对标 | 学什么（语法） | 刻意不学 |
|---|---|---|
| **Saul Bass《North by Northwest》(1959)** | 斜线网格占满画面、字幕沿网格线飞入、网格本身就是转场；强烈的单色底 + 细线 | 不用它的绿底蓝线、不做玻璃幕墙大楼化出、不用它的字体 |
| **Saul Bass《Anatomy of a Murder》(1959)** | 剪纸断肢：人物是分开的纸片，关节处留缝；剪刀剪出来的毛边；3–4 个平涂色；字幕是画面结构的一部分，大块字母和人形同权 | 不用它的"尸体轮廓"、不抄它的手写字形与具体构图 |
| **Saul Bass《Vertigo》(1958)** | 圆形母题的图形匹配（螺旋 ↔ 眼睛）——本片转成"轮盘 → 瞳孔 → 月亮 → 钥匙孔"一路圆形硬切 | 不做螺旋、不做眼睛大特写渐入螺旋那套具体画面 |
| **Kuntzel + Deygas《Catch Me If You Can》(2002)** | 平面布景里的侧面追逐、布景一格一格"推"过去的节奏；**字幕即道具**（门牌、行李标签、跑道都是字）；角色靠剪影和姿势表演 | 不用它橡皮章/印章的颗粒质感（我们是剪纸 + 丝网平涂）、不用它的人物造型（长脖子高帽的追者和被追者）、不复刻机场/泳池等具体场景 |
| **60 年代间谍大乐队配乐（语法）** | 小调半音下行动机、铜管强奏当剪辑点、stop-time 断奏、冲浪吉他低音弦 twang、结尾"大和弦 + 小尾巴（button）" | 不用任何现成主题的音程与节奏（尤其是那个著名的 E–F–F#–F 半音爬行和 Em(maj9) 结尾和弦）；不做 007 枪管、粉红豹那种踮脚贝斯 |

## 二、为什么这个媒介讲这个故事（原生能力 → 故事用法）

| 片头字幕这个媒介的原生能力 | 故事里怎么用 |
|---|---|
| **字体即布景**：字母是纸剪出来的大块平面，可以是建筑 | 机场：演职员字幕 STARRING THE AGENT 的巨型字母就是航站楼的柱廊，**I 是特工躲在后面的柱子**；列车：MUSIC BY THE SAMPLER 每个单词是一节车厢，**特工在"车厢"之间跳**；赌场：and THE COURIER 里的 **O 是轮盘赌**；结尾：片名 CIPHER 的 **I 是钥匙孔** |
| **字幕本身就是节奏**：片头字幕天生按拍子出现 | 每个铜管强奏 = 一次硬切 / 一个字幕落地；每行字幕停留时间按阅读量定 |
| **图形匹配剪辑**：抽象到只剩几何形，圆就是圆 | 列车车轮 → 轮盘（车轮转成轮盘）→ 瞳孔 → 月亮 → 钥匙孔，一路圆形硬切，剪得一次比一次快 |
| **斜线网格**：开场网格是片头的"骨架" | 开场钥匙孔一刀劈成两半，切口繁殖成斜线网格；**高潮所有碎片沿同一套斜线网格飞回来**，拼成片名；片名最后沿同一条斜切线合拢——开场劈开的东西，结尾合上 |
| **剪纸人物 = 纸偶** | 永远侧面、一格一格挪（on twos）、断肢关节留缝；表演只靠姿势：奔跑、贴墙、回头 |

**情绪弧**：悬念（黑底红钥匙孔、磁带简报）→ 失窃（手一把抓走钥匙）→ 追踪（机场，躲在字母后面，紧张又滑稽）→ 升级（列车，跳车厢，stop-time 定格笑点）→ 加速（赌场—瞳孔—月亮三记连切）→ 高点（屋顶接住钥匙 + 全部碎片飞回拼成片名）→ 回响（钥匙 = 片名的 I，插进去合拢；一拍静音，一声邦戈；"Now you know what it opens."）。
一个角色（特工）、一个目标（夺回钥匙）、一次转折（钥匙开的不是任何一扇门，是这部片子本身——他一路追的碎片就是片名）。

## 三、原生招式（放在情绪最高点）

1. **字体即布景**（贯穿全片，每个地点一次）：字幕字母 = 柱子 / 车厢 / 轮盘 / 钥匙孔。每个地点只有一行演职员字幕，而它就是这个地点的布景。
2. **图形匹配硬切**（加速段 21.8–25.5s）：车轮 → 轮盘 → 瞳孔 → 月亮，每记铜管强奏一切，间隔从 2 小节缩到 1.5 小节再到 2 拍。
3. **高潮：碎片拼片名**（30.9–37.3s）：屋顶上他接住钥匙定格在月亮前 → 整个世界碎成剪纸碎片（屋顶、月亮、轮盘、字母、网格线），沿开场那套斜线网格飞回 → 最后一记铜管 + 镲拼成 THE VELVET CIPHER，I 是一块黑色锁板上的红钥匙孔、片名沿斜线错开一道缝 → 镜头推近到和开场一模一样的"黑底红钥匙孔"构图，一只手把钥匙竖着放进去（钥匙的轮廓正好填满它）→ "咔"，斜切缝合拢，button 和弦 → **1 拍静音，只剩一声邦戈**，硬切回完整片名。

## 四、角色（关卡 1 交设定表）

所有角色是**剪纸剪影**：墨黑纸片，剪刀毛边，四肢是分开的纸片、关节处留 3–4px 缝（Anatomy 的断肢语法），只在转面图里画正面和背面，**片中永远侧面**。

- **THE AGENT（特工）**：约 7 头身、窄长、锐角。窄檐软呢帽（帽带是一道纸白的细缝），宽肩收腰的西装外套（下摆后开衩，奔跑时开衩飘起），**一条信号红窄领带**——他身上唯一的颜色，奔跑时向后飘（运动方向指示器），尖头皮鞋。脸是纯剪影侧脸，鼻尖锐利，近景时剪出一道纸白的眼缝。
- **THE COURIER（信使 / 反派）**：比特工高 1.2 倍，一件长到小腿的 A 字风衣（大三角剪影），竖起的尖领，一顶**宽平檐帽**把脸藏在阴影里，只露一道纸白眼缝（瞳孔特写就是这只眼）。风衣内衬是信号红，跑起来翻开才看见。**钥匙用一根链子拴在他手腕上**，走路时晃——观众在每个场景都能一眼找到钥匙。
- **钥匙**：芥末黄黄铜钥匙：圆头（中间镂一个小钥匙孔——微缩的首尾呼应）、钥匙杆微收、两颗齿。**钥匙的外轮廓 = 片名里 I 的钥匙孔轮廓**。
- **色板（4 色）**：墨黑 INK `#1b1714` · 纸白 PAPER `#efe4c9` · 信号红 SIGNAL `#d23a22` · 芥末黄 MUSTARD `#e2a52a`（外加一个只用于阴影/凹痕的暗红 `#8e2417` 和暗芥末 `#a8761a`，都是同色纸的暗面，不算新颜色）。

## 六、Cue map（音乐先行；132 BPM，E 小调，60 年代间谍大乐队）

## 七、声音设计（拟音跟材质走：纸 + 金属 + 磁带）

- **纸**：每个剪纸形状入场 = 纸片"唰"（高通噪声短扫）；字母落地 = 厚卡纸"啪"（低频 thump + 纸的中高频噼啪）；劈开钥匙孔 = 剪刀"咔嚓"两刀；碎片飞回 = 一大把纸片刷刷声 + 每组落定一个"啪"。
- **金属**：钥匙链叮当（两个不和谐分音）；最后钥匙滑入锁孔（金属刮擦）+ 拧锁"咔"。
- **磁带**：旁白走磁带简报链路（带通 300–4000 Hz、轻微抖晃、嘶声底噪）；开场磁带开机"咔哒"。
- **地点环境**（都很轻，只点到）：机场 = 喷气机呼啸（滤波噪声扫频）；列车 = 车轮咔哒（军鼓承担节奏，拟音只补低频）；赌场 = 轮盘小球咔啦啦 + 筹码；屋顶 = 风。
- 混音：旁白前置，音乐在旁白下闪避约 −7 dB；stop-time 和结尾一拍静音要连混响尾巴一起切干净。最终 −14 LUFS，mux grain = 6（轻，模拟胶片印刷）。

## 八、字幕与标题设计（字幕也是片头的一部分）

- **演职员字幕**：League Gothic（OFL，窄长无衬线，60 年代片头气质）的字形轮廓用 opentype.js 取出来，**每个字母都重新"剪"一遍**：轮廓折线化 + 剪刀毛边抖动 + 每个字母独立的微小旋转/错位，像手剪的纸字贴在板上。字母就是布景，所以它们有重量：落地时"啪"一下。
- **旁白字幕**：一条纸白窄纸条（两端剪刀斜切），左侧一个红色小钥匙孔图标，文字 League Spartan 600（几何无衬线，60 年代打字感），句首大写，44px 墨黑。纸条在拍点上从左侧滑入、稍微倾斜 1°，与网格语言一致；背景亮时纸条改成墨黑底纸白字。位置固定在左下（x≈110，y≈960），不压画面主体。
- **片名**：THE VELVET CIPHER 用**自己拼的剪纸几何字形**（直线 + 圆弧拼成，笔画粗细不匀，基线错落，Bass 式的"不规整"），不参照任何真实片名 logo；CIPHER 的 I = 一块窄长的黑色"锁板"（远看就是一笔粗 I），中间剪出红色钥匙孔（圆 + 下宽的竖）；钥匙放进去后孔被芥末黄填满。
- **片尾卡**：同一片名缩小 + "60s Spy Title Sequence" + "LemoLab × Claude Opus 5.5"，下面一行小字 "a LemoLab picture · music by the sampler"。

## 九、对风格说明的调整（及理由）

- **时长 35s → 约 43.6s**：每个地点都有一行演职员字幕（它就是布景）+ 一句旁白字幕，观众要在同一个画面里读两样东西；按"每屏留足阅读时间"算，机场需要 4 小节、列车 3 小节，加上结尾"拼片名 → 钥匙入孔 → 合拢 → 静音 → 旁白"这一串不能压缩，所以放宽到 24 小节，仍在 30–60s 范围内，节奏上地点仍然一个比一个快（4 → 3 → 2 小节，瞳孔只有 2 拍）。
- **开场片名卡**：片头这种体裁的片名本身就是高潮揭示，所以开场 3 秒的卡是 "A LEMOLAB PICTURE"（第一行演职员字幕），真正的片名卡放在 32.7s 的高潮；开场的红钥匙孔就是片名的 I，片名以"碎片"的形式其实一开始就在画面里。
- **钥匙 = 哪个字母**：风格说明建议 C 或 O 的缺口；我选 **CIPHER 的 I**，因为钥匙孔（圆 + 竖）和一把竖着的钥匙（圆头 + 杆）轮廓天然重合，一眼就懂"钥匙放进去 = 字母补齐"，而且 I 在机场段已经当过"柱子"，结尾再出现形成呼应。
- **钥匙挂在信使手腕的链子上**：让观众在每个快速切换的场景里都能立刻找到目标物。
- **赌场的 O**：放在 and THE COURIER 的 COURIER 里（信使的演职员字幕），轮盘就是反派名字里的一个字母。
