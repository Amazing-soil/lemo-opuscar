## 1. 一句话故事与情绪弧

**1930 年除夕，星光大饭店。屋顶舞厅的乐队等着一首新歌——作曲家把它封在一只盖着金色高音谱号火漆的信封里，送到了楼下。十四岁的门童 Pip 要在午夜钟响前把信送上三十楼。电梯坏了。他从楼梯井一路冲上去，穿过后厨，在楼顶把信扔给乐队指挥——指挥接住信的那一刻，午夜第一声钟响；十二声钟，灯牌"THE STARLIGHT"一个字母一个字母亮起，最后一个字母在 Pip 身后亮起。第十三拍，乐队奏出信里的那首歌。**

- **主体**：Pip（唯一主角）。**目标**：午夜前把信送上屋顶。**转折**：电梯坏了（"OUT OF ORDER"牌子砸下来），他在一拍静音里扶正帽子，改走楼梯。
- **情绪弧**：慌张（大堂，按三次按钮）→ 定神（静音里扶帽）→ 找到节奏（楼梯井里脚步踩上查尔斯顿的拍子）→ 从容（厨房里帽子被托盘撞飞，他看都不看，帽子落回头上）→ 屏息（屋顶，钟停了，信在空中翻转）→ 敬畏（十二声钟，灯追到他身边）→ 喜悦（全乐队）。
- **回响**：开场他在街上仰望一块**黑着的**灯牌；结尾他**站在灯牌里**，灯一盏盏亮到他身后。开场收音机里传来的播音员声音（隔着喇叭、失真）→ 结尾在屋顶就是现场、干净无滤波——他一路爬向了声音的源头。片尾按钮：大堂的电梯"叮"一声修好了、牌子翻成 IN SERVICE——晚了。
- **因果链**（每个奇观都有剧情原因）：信里是歌 → 乐队等歌 → 钟敲十二下期间指挥拆信、举棒 → 第十三拍乐队奏新歌 = 全片配乐终于完整；灯牌逐字亮起是饭店午夜的仪式，而 Pip 恰好被困在灯牌的检修走道上——所以他站在灯里。

## 2. 对标：学什么 / 刻意不学什么

| 对标 | 学什么（语法） | 刻意不学 |
|---|---|---|
| **A. M. Cassandre 海报**（Normandie、Étoile du Nord、Nord Express） | 巨型几何主体 + 极端透视（仰角、两点透视，主体冲出画框）；**喷枪渐变**填在硬边几何形里；放射线、平行速度线表达运动；字体是构图的一部分 | 不复刻任何海报的构图、船 / 火车造型、字体设计；不出现任何真实交通工具品牌 |
| **克莱斯勒大厦 / 洛克菲勒中心的装饰母题** | 阶梯退台（ziggurat）、太阳放射、V 形 / 人字纹、鱼鳞纹、扇形、金属镶线 | 不画任何可辨认的真实建筑（塔冠用自己设计的阶梯 + 扇形，不用克莱斯勒的三角窗弧冠） |
| **Busby Berkeley 歌舞片**（1930s：*42nd Street*、*Footlight Parade* 的俯拍段落） | 正俯拍、对称队形、画面像机械一样开合；镜像万花筒；群舞组成几何图形 | 不复刻任何具体队形、服装、镜头；舞者是原创的扇子舞者 |
| **《了不起的盖茨比》(2013) 片头** | 金线在黑底上自己画出来、层层对称展开、金属高光扫过、颗粒质感 | 不用它的具体图形、字体、配色顺序、音乐 |
| **格什温式交响爵士**（语法） | 单簧管滑音开场的"开幕感"、钢琴主奏 + 弦乐铺底 + 弱音小号点评、狐步 → 查尔斯顿切分 | **旋律全部原创**；不引用《蓝色狂想曲》任何动机或和声进行；不做 60 年代铜管大乐队（spy-titles 的地盘） |

与已完成风格的区分：**spy-titles** = 纸剪影 + 四色 + 爵士大乐队；**film-noir** = 3D 动物 + 黑白雨夜；**stained-glass / papercut** = 材质透光。本片 = **黑金喷枪几何 + 金线 + 灯泡**，节奏语言是 1930 年代狐步 / 查尔斯顿 / 电台。

## 3. 原生招式（只有装饰艺术能做）

| 招式 | 位置 | 怎么做 / 为什么只有这个风格能做 |
|---|---|---|
| **① 对称开合**（统一转场语法） | 全片 6 次 | 装饰艺术的构图永远有一条中轴。转场 = 画面沿中轴像**拱门 / 电梯门 / 双开弹簧门**一样开合：片名拱门劈开进街景；楼梯双开门撞开进楼梯井；厨房弹簧门撞开进屋顶；片尾电梯门合上成为片尾卡。旋转门是它的"旋转版"（四扇玻璃翼逐拍扫过）。每次开合都有金线先沿中轴亮起、门缝里透光。 |
| **② 十二声钟 = 十二个字母**（情绪最高点） | 35.9–41.6 s | "THE STARLIGHT" 恰好 12 个字母。每一声钟亮一个字母（灯泡先过冲闪一下再稳住），画面上观众能数：钟声 = 字母 = 剪辑点。最后一个 T 在 Pip 身后亮起，金光打上他的脸。钟声之间只有风声和余音——全片最"空"的 6 秒。 |
| **③ Busby Berkeley 俯拍万花筒** | 42.1–46.2 s | 第 13 拍全乐队一进，镜头跳到正俯拍：16 名扇子舞者围成圈，扇子按八分音符**逐个打开** = 放射太阳纹绽开；画面按 8 向对称镜像、缓慢旋转；第二小节队形收成**钟面**：12 人是刻度，4 人排成指针指向十二点。装饰艺术的放射母题 + 歌舞片的机械对称 = 同一个图形。 |
| **④ 灯泡灯牌** | 屋顶全段、片尾 | 任意文字 → 字形骨架 → 等距灯泡；逐盏点亮、追逐闪烁（十六分音符追灯卡着全乐队）。 |
| **⑤ 电梯指针 = 章节进度 + 时钟** | 大堂、楼梯井 HUD、片尾 | 大堂电梯上方的半圆指针卡在 L 不动（坏了）；楼梯井里同一个指针变成角落的 HUD，跟着 Pip 往上爬；片尾它终于"叮"地转到 R——晚了。 |

## 4. 视觉语言

- **底色**：暖黑 `#0d0b09` / 漆黑 `#060504`；夜空黑蓝 `#0a0e16` → 地平线祖母绿 `#10231f`。
- **金**：渐变金 `#C9A24B → #F3D98B`，阴影金 `#6F5220`，高光 `#FFF4D2`。金线 = 暗金底线 + 金渐变主线 + 发丝高光（雕刻感）；金属渐变是"条带式"（暗—亮—高光—亮—暗），sheen 参数可动画成一道扫光。
- **点缀**：勃艮第红 `#8E1B2E`（门童制服，全片唯一的大面积彩色 = 观众的视线锚点）、祖母绿 `#1D6B57`（扇子、夜色、门框填色）、象牙白 `#F2E8D5`（大堂地毯、信封、手套）。
- **体积**：Cassandre 式**硬边 + 喷枪渐变**，无黑描边；受光一侧一条细金边（rim）。光从左上来。
- **母题库**（engine 已实现）：放射太阳纹、阶梯拱门、鱼鳞、V 形、扇形、平行速度线、四角闪光、钟面、半圆指针。
- **透视**：`engine/cam.js` 小针孔相机，场景按真实一点 / 两点透视画（大堂一点透视 + mode-7 地板；屋顶两点透视仰拍），所以推拉摇移都是真的透视变化，不是缩放平面。
- **字体（OFL）**：Limelight（片名 / 标题）、Poiret One（数字、灯牌字形骨架、标牌）、Josefin Sans（字幕、小标签）、Italiana（钟面罗马数字）。

## 5. 角色（关卡 1 设定表 `demo/stills/modelsheet_v1.jpg`）

- **PIP**，14 岁门童。约 5 头身；勃艮第红短款门童夹克，两排黄铜扣子收成 **V 形**（装饰艺术的 V），金色立领 + 肩章 + 人字下摆；深李子色长裤带金色侧条；白手套；**斜戴的圆筒帽 + 下颌带**；油亮的背头。
- **剪影标志**：斜圆筒帽、V 形扣、永远拿在手里的信（金色火漆 + 高音谱号 = 信里是歌）。
- **表情**：慌张 / 担心 / 决心 / 从容 / 使劲 / 敬畏（+ 喜悦）。换表情 = 换眼睑、眉、嘴的参数，12 fps 步进，关键表情前有 1 帧预备。
- **配角**：乐队指挥（高瘦、白礼服、白胡子、指挥棒，只有两个镜头）、侍者（一模一样的白外套，歌舞片式重复）、扇子舞者（只出现在俯拍，圆 + 裙 + 扇的几何体）、大堂宾客（金边剪影）。

## 10. 字幕设计

- **装饰字卡横条**（engine `subtitleCard`）：漆黑半透明（88%）横条，两端阶梯式外凸（和片名金条同一套"阶梯端"），双层金线描边；字 Josefin Sans SemiBold 42 px 象牙白 `#F2E8D5`。

- **出入场**：和转场同一语法——先一条金发丝线从中心向两边画开，横条沿中轴上下展开，字最后淡入（约 0.3 s）；退场反向合拢。

## 11. 与风格说明的差异及理由

1. **时长约 56 s（说明 40–55 s）**：十二声钟必须一拍一声（6.2 s），加上屋顶静音 2.7 s 和万花筒 4.1 s，这三段是全片的情绪核心，压缩会让"数钟声"和"屏息"失效；其余段落已按最短可读时间排。仍在 30–60 s 规格内。
2. **加了"信里是歌"的因果**：说明里信送到时钟响灯亮；我让信封里是乐队等的新歌（火漆是高音谱号），这样全片配乐本身成了剧情——主题只露碎片，直到指挥拆信后的第 13 拍才完整，声音和故事是同一件事。
3. **把除夕加进来**：午夜需要一个"为什么必须是午夜"的理由；1930 年除夕的电台直播（播音员）同时给了旁白一个剧中身份和"越爬越近"的声音设计。
4. **十二声钟 = 十二个字母**："THE STARLIGHT"正好 12 个字母，所以灯牌逐字亮和钟声一一对应（说明是"灯一盏盏亮起"，我把它收紧成可以数的节拍）。
5. **Busby Berkeley 放在钟声之后**：说明建议屋顶舞会俯拍、最后收成钟面；我把它放在全乐队第一拍，钟面在第二小节合拢——"十二点"这个图形是在钟敲完之后由人组成的，作为庆祝的回声。
6. **片尾按钮（电梯修好了）**：不在说明里；给结尾一个会心的笑，同时让"电梯指针"这个章节道具闭环。

## 12. 技术方案

- 纯 Canvas2D。`demo/engine/`：`deco.js`（色板、金属金、金线、喷枪填色、放射线、阶梯拱门、鱼鳞、V 形、扇形、闪光、速度线、任意形状 `drawShape` + "唯一彩色"）、`type.js`（金色标题条、数字 / 年份徽章 / 楼层章 / 钟面 / 电梯指针、字幕卡）、`bulbs.js`（任意文字 → Zhang-Suen 骨架 → 灯泡阵列，逐盏点亮 / 追灯）、`cam.js`（针孔相机 + 卡片仿射，用于真透视场景）。
- 场景只调用引擎：`scenes/lobby.js`（一点透视 + mode-7 地板）、`scenes/roof.js`（两点透视灯牌）、后续 `street.js` `stairs.js` `kitchen.js` `ballroom.js`。
- 角色 `chars.js`：Pip 2D 骨骼（FK），四个视角、8 种表情、命名姿势库。

- 声音：`mix.py` 按材质合成拟音（金属、纸、木、玻璃、灯丝），播音员五级空间滤波，音乐距离自动化与闪避；`mux.sh` grain 3，−14 LUFS。

## 13. 制作后记：与方案的差异

- **时长 58.4 s**（方案 56 s）：钟声段与万花筒按 116 BPM 网格排满，片尾卡 4.4 s。
- **楼梯井**改为建筑剖面一镜到底：上升 → 拉远成整座塔的剖面（Pip = 红点 + 速度线）→ 推回 "30" 楼层章 → 匹配剪辑到厨房银托盘。原来的"金弹簧 + 正俯拍漩涡"在 2D 里深度排序读不清。
