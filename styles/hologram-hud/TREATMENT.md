# Sci-fi Hologram HUD · 导演方案（Treatment）

**片名** *Volt · Spec Scan*（片内第一个画面就是产品名 VOLT，不单独做片名卡）
**场景** 硬件产品的卖点与参数讲解：产品页首屏视频 / 众筹视频的参数段 / 展会屏循环片
**产品** 虚构城市电助力车 **VOLT CE-01**（品牌、造型、参数全部原创）
**时长** 39 s（120 BPM，4/4，1 小节 = 2 s；场景 34 s + 片尾卡 5 s）｜ **画幅** 1920×1080 ｜ **帧率** 24 fps，全部逐帧平滑（全息界面是精确的机器运动，不做步进；只有乱码滚动按 24 fps 每帧换字形）
**旁白** 要。平静、自信的产品讲解，Kokoro 候选 af_nicole / af_heart（制作时两条都试，挑更"冷静而不冷漠"的那条）。字幕做成界面里的"语音转写条"。
**一句话** 一道扫描光带从投影台升起，把一辆自行车"扫"成发光的线框；目标框逐个锁定电池、电机、刹车，每次锁定都推近、局部拆开、拉出引线、数字从乱码滚到真值；三个部件归位后全场静音一拍，线框亮成实心的全息体转一圈，最后停成一张能直接当产品页首屏的参数海报。

## 一、对标：学什么 / 刻意不学什么

| 对标 | 学什么（语法） | 刻意不学 |
|---|---|---|
| **《钢铁侠》《复仇者联盟》的 HUD 与全息工作台**（Territory Studio、Perception 的界面设计） | 目标框"先大后小、斜着转正"的锁定动作；引线标注从锚点圈出发、先斜后平；数字滚动；前景界面 / 主体 / 背景网格三层视差；全息物体被手势"拆开"后悬浮；界面元素每一个出现都有声音 | 不做满屏堆叠的信息瀑布（那是"炫"不是"讲"）；不用红金配色、不出现任何角色、盔甲、logo、片中界面的具体布局与字体 |
| **《遗落战境》的全息界面**（GMUNK 等） | 克制的单色：几乎只有一种冷色 + 一个暖色；大量留白；细线（1–2 px）；界面文字小而疏；动效慢而稳 | 不用它的白色塑料质感和具体图标；不做无人机、地图等片中物件 |
| **工业 CAD 线框与爆炸图** | 管件是"环 + 纵线"组成的网格；零件沿装配轴线拆开并保持对齐；拆开的距离说明结构层级；爆炸时镜头给 3/4 角度让层与层分开 | 不做纸面工程图的线型、图框、标题栏（那是 blueprint 的事）；不做写实材质 |
| **产品页首屏 / 众筹参数段**（功能用途的对标） | 一屏一个卖点、大数字 + 单位 + 一行解释；最后一屏"所有参数 + 价格 + 行动号召"可以直接截图 | 不做滚动网页的排版；不出现任何真实品牌与价格体系 |

## 三、原生招式（只有"全息线框 + 界面"能做到的）

| 招式 | 放在哪里 | 怎么做 |
|---|---|---|
| **扫描生长** | 开场钩子；片尾反向擦除 | 世界高度 y 的扫描面：只画 y 以下的边，跨过扫描面的边在交点截断并画白点；扫描前沿 7 cm 内的边发白（"刚被扫到"）；扫描面本身是投影出来的椭圆 + 刻度 + 横向光幕 |
| **局部爆炸图** | 三个部件各一次 | 每个零件由若干 piece 组成，piece 自带爆炸向量；内部件（电芯、定子、转子）平时隐藏，爆炸时才出现；转子 / 定子反向自转、碟片慢转 |
| **目标框带镜头** | 贯穿全片的转场语法 | 目标框从 1.9 倍、45° 斜角缩到贴合零件；下一个部件时目标框飞过去，镜头跟着目标框甩过去（带速度线），所以每次转场都是"眼睛追框" |
| **滚动数字** | 每个数值、产品名、价格 | 每个字符先乱码（数字位用 0–9，字母位用 A–Z#%/），从右往左按拍锁定；锁定瞬间变琥珀色并闪白一帧 |
| **多层视差** | 全程 | 背景点阵（视差 0.2）、投影台（跟相机透视）、主体、前景刻度尺（视差 1.4）、界面文字（不动） |
| **放大镜画中画** | 刹车段 | 第二个相机在圆形取景框里以 3.9 倍放大卡钳和碟片，里面单独做爆炸；两条切线把放大镜和车上的小圈连起来 |
| **实心全息体 + 投影光柱** | 高点 | 四边面按屏幕空间菲涅尔（侧面越亮）填色，再乘隔行扫描纹理；投影台升起光锥和上升光尘 |
| **克制的故障闪烁** | 只在 24.0 点亮那 3 帧 | 横向切片错位 + 轻微色偏，不做第二次 |

## 六、Cue map（音乐先行，画面卡这张表）

**120 BPM，4/4，1 拍 = 0.5 s，1 小节 = 2 s，共 19.5 小节。调性 D 小调（Dorian 色彩），琶音用 D–F–A–C–E 五音循环。**

| 小节 | 时间 | 段落 | 配器 | 密度 / 情绪 | 卡点 |
|---|---|---|---|---|---|
| 1–2 | 0–4 | 扫描 | 投影台嗡鸣（D1 正弦 + 八度）、扫描上升（噪声带通 + 上行正弦 0→2.6 s）；2.0 起琶音（十六分，低通 400 Hz） | 神秘、克制 | 2.0 标题 / 2.5 扫描完成"叮" |

| 5–7 | 8–14 | 电池（慢讲） | + 低音八分（D2–A1）；琶音全开；无鼓 | 专注 | **8.0 锁定**（小节头）、11.0 数值确认（小节头）、13.6 J-cut |
| 8–9 | 14–18 | 电机 | + hi-hat 十六分 | 加速 | **14.0 锁定**、16.0 确认 |

| 12 | 22–24 | 重组 | 鼓撤掉；琶音减速十六分 → 八分 → 四分；23.0 下行断电音 | **减速、呼吸** | 22.0 / 22.5 / 23.0 归位 click；**23.5–24.0 真静音 ②** |
| 13–14 | 24–28 | 点亮 360° | **24.0 drop**：808 式低频 + 宽锯齿和弦（Dm9）+ 全部回来 | 全片最高 | 24.0；26.0 和弦换到 B♭maj7 |

| 18–19.5 | 34–39 | 片尾 | 和弦拖尾 + 嗡鸣（L-cut），琶音一个音一个音拿掉 | 余韵 | 34.0 反向扫描、39.0 归零 |

- **每个锁定落在小节头**（8.0 / 14.0 / 18.0），**每个数值确认也在小节头**（11.0 / 16.0 / 20.0）；整车点亮前静音一拍（23.5–24.0）。
- 条目数变化时（2–5 个），第一个部件 3 小节，其余各 2 小节，时间线和卡点自动顺延（`film.js` 的 `buildTimeline`），配乐脚本读同一份时间线生成。
- 配乐 fork 一个子 agent 按本表和导出的 `timeline.json` 写（numpy 合成为主：方波 / 锯齿 / FM 琶音、808 式低频；界面音单独做成音效库）。画面并行。
- 卡点自检：仿 microgame 的 `cuecheck.py`，比对配乐音符表与画面事件（EV），偏差 ≤ 1 帧。

## 七、声音设计表

| 段落 | 环境底 | 主要拟音（跟"光与机器"的材质走：发光线 = 高频电子，机械部件 = 低沉的伺服和金属） | 音乐状态 |
|---|---|---|---|
| 扫描 0–2.6 | 投影台嗡鸣（40/80 Hz + 轻微 60 Hz 交流声）、机房空调底噪 | 扫描上升音；扫描面刻度转动的细 tick；过部件的 tick | 2.0 起琶音（低通） |
| 标题 2–8 | 同上 | 字符滚动 tick（24 fps 颗粒）；每行确认音；三声探测 | 琶音 + 脉冲，VO 时让路 −6 dB |
| 静音 ① 7.5–8.0 | 只留房间嗡鸣 | — | 全停 |
| 电池 8–14 | 嗡鸣 | 锁定重击；外壳滑轨 + 伺服；电芯落位 click；引线 zip；数字滚动；琥珀确认 | 低音 + 琶音，VO 让路 |
| 电机 14–18 | 嗡鸣 + 电机电磁啸叫（J-cut 进） | 甩镜 whoosh；锁定；左右盖分开的气压"噗"；转子转动的调制嗡声 | + hi-hat |
| 刹车 18–22 | 嗡鸣 + 油压嘶声（J-cut 进） | 放大镜光圈开合；卡钳分开的金属 tink；碟片转动的细铃音 | + 拍手 |
| 重组 22–24 | 嗡鸣渐弱 | 归位 click × 3；断电下行 | 减速 → **真静音** |
| 点亮 24–28 | 投影光柱的高频"光"噪（带通白噪 + 慢颤音） | 故障 burst（3 帧数码爆裂）；转台 whoosh（多普勒） | 满编 drop |
| 落版 28–34 | 光柱噪声压低 | 三声 ping；两次滚动；CTA 确认 | 呼吸 |
| 片尾 34–39 | 嗡鸣（L-cut）淡出 | 反向扫描下行；字卡 tick | 和弦拖尾 |

混音：旁白最高优先级，音乐和环境底在旁白期间侧链压 6 dB；锁定重击和确认音不让路（它们是信息的"落点"）。响度 −14 LUFS，不加颗粒（grain 0）。

## 八、字幕设计（界面的一部分）

- 位置固定：画面底部居中（基线 y = 962），不随镜头移动。
- 样式：深色半透明底板（rgba(1,8,12,.62)）+ 对角两个青色括角 + 左侧 4 根跳动的"声纹"竖条，字体 Rajdhani Medium 38 px、近白青色。像 HUD 里的实时语音转写。
- 每条在语音开始前 0.1 s 出现，停留 ≥ max(1.8 s, 语音 + 0.6 s)，不和参数卡、放大镜重叠（参数卡右侧 x ≥ 1240、y ≤ 870；放大镜 y ≤ 580）。

## 九、可替换内容（`demo/content.json`）

所有文字、数值、配色、模型路径、旁白都从 content.json 读，代码里不写死文案。

| 字段 | 类型 | 说明 |
|---|---|---|
| `product` / `model_code` / `category` / `tagline` | 字符串 | 左栏标题块；标语超宽自动换行、缩字号 |
| `model` | 路径 | 线框模型 JSON（顶点 / 边 / 面 + 零件 / piece / 爆炸向量），由 `models/gen_*.mjs` 生成 |
| `hue` / `accent` | 0–360 | 全息主色相 / 唯一暖色（数值锁定色） |
| `voice` | {id, speed} | Kokoro 声线 |
| `intro_vo` / `outro_vo` | 字符串 | 开场与落版旁白 |
| `callouts[]` | 2–5 项 | `part`（模型里的零件 id）、`label`、`value`、`unit`、`detail`（可选）、`vo` |
| `footer` | 对象 | `weight` / `price`（label + value + unit）、`cta` |
| `film_title` / `credits[]` | | 片尾卡 |

时间线规则：第一个部件 3 小节，其余各 2 小节；镜头模式按 推 → 环绕 → 放大镜 循环；左栏芯片按条目数排（最多 5 条，间距 92 px）。关卡 2 交 `content_alt.json`（换一台完全不同的硬件，暂定折叠无人机）和 3 张静帧。

## 十、技术方案

- `demo/engine/holo.js`：线框引擎（透视投影、转台、扫描生长 / 擦除、局部爆炸、piece 自转、菲涅尔实心面 + 隔行纹理、景深雾化、两级辉光、扫描面、投影台）。纯 Canvas 2D。
- `demo/engine/hud.js`：界面层（目标框、引线、滚动数字、参数卡、芯片、热点、投影光柱、字幕条、取景框、故障闪）。
- `demo/models/mkmodel.mjs` + `gen_volt.mjs`：用基本体（管、环、盘、盒、座垫、辐条轮、电芯、定子、碟片）拼线框模型，输出 JSON。换产品 = 写一个新的 gen 脚本。
- `demo/film.js`：只做编排（时间线、相机、状态），调用引擎。
- 字体：Rajdhani（界面、数字）、Share Tech Mono（小字数据），均为 OFL，已放进 `demo/fonts/`。
