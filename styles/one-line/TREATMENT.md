# One-line Drawing · 导演方案（Treatment）

**片名** *The Line That Never Lifted*
**时长** 约 46 秒（风格说明建议 35 秒；理由见第九节：八个人生段落各需 3.6–5.4 秒才看得清，揭示后还要留出"认出这张脸"的停顿）
**画幅** 1920×1080 ｜ **帧率** 24fps 输出，线条与镜头逐帧平滑（一笔画的魅力就是"正在画"的连续感，不做步进）
**一句话** 一根笔尖从不离纸的线，画完一个人的一生：出生、风筝、自行车、初恋、房子、失去、自己的孩子、变老。最后镜头拉远——他走过的一生正好是他自己晚年的一张脸。一只小手接过笔，新线从旧线的末端歪歪扭扭地往前画。
**题眼** 一生中所有的事情最后都长在了脸上。**两只耳朵是两次出生**（左耳是他攥着父亲的手指，右耳是他的孩子攥着他的手指；那根大人的手指同时是眼镜腿），**眼镜是少年那辆自行车**，**嘴是初恋**（两张侧脸鼻尖相碰，共用一条线——全片唯一一段红线，所以老人脸上唯一的颜色是他的笑），鼻子是那座房子，**右眼下那滴泪是失去时笔尖停下洇开的墨点**，**最后一笔是他闭上左眼**。

## 一、对标：学什么 / 刻意不学什么

| 对标 | 学什么 | 刻意不学 |
|---|---|---|
| Osvaldo Cavandoli《La Linea》(1971) | 线既是世界也是角色；**线的变形就是转场**（风筝尾巴弯成车把，戒指成了房子的圆窗，眼角的鱼尾纹变成他伸给孩子的手指）；空白背景上只有一条线的纯粹 | 不用它的小人造型、不做叽里咕噜配音、不做"画外之手"的喜剧互动，不用它的色块背景 |
| Picasso 1949 光绘（Gjon Mili 摄） | 一笔成形的速度与自信：**快处细、慢处粗**，转折处笔会停半拍再走；线条是动作的轨迹，观众看到的是"画的过程" | 不用光（我们是纸上墨线），不复刻任何一幅光绘（半人马、公牛等） |
| Norman McLaren《Begone Dull Care》《Boogie-Doodle》 | **画面跟着音乐画出来**：笔的速度、转折、停顿都卡在大提琴的弓法上——线快弓快，线停音延长，每个拐角落在一个换音上 | 不做抽象的直接在胶片上作画，不做爵士，不用它的色彩爆炸 |
| 当代单线插画（continuous line art）与"一笔肖像" | 一条线同时承担轮廓与细节；连接笔画（connector）是合法的，观众会自动忽略；大特征（眼镜、耳朵、笑纹）一旦对了，脸就立起来 | 不复刻任何具体插画；不做"微缩画（micrography）"那种用小字排出脸的做法 |

## 二、原生招式（只有一笔画能做到）

| 一笔画的天生能力 | 片中怎么用 | 位置 |
|---|---|---|
| **笔永不抬起** | 全片是**一条**连续路径（代码里就是一个点数组，从第一帧的落笔到最后一帧），没有任何剪辑点。镜头像跟拍一样一直跟着笔尖，带柔和的延迟和预判 | 全片 |
| **线就是时间** | 线的性格随年龄变：童年细、轻、快（墨色偏淡）；壮年饱满有力；老年微颤、断墨、飞白。**初恋那一段线变成红色**（只在嘴上），到房子时变回墨色——全片唯一一次颜色 | 全片 |
| **停笔 = 失去** | 线画出一只闭着的眼睛，在外眼角往下轻轻一勾，**停住** 1.7 秒一动不动，墨点慢慢洇开、往下坠成泪滴形，配乐同时静下来；然后线继续 | 0:23.9–0:25.6 |
| **尺度揭示（反向设计）** | 最后镜头连续拉远，一生的所有段落拼成一张老人的脸：两次出生是两只耳朵（大人的手指是眼镜腿），自行车是眼镜（车座是左眉、车把是右眉、车架是鼻梁两侧），风筝是头顶翘起的一缕，初恋是（红色的）嘴，房子是鼻子（两扇圆窗是鼻孔），停笔的墨点是眼角的一滴泪。**最后一笔是他闭上左眼** | 0:33–0:38.6，情绪最高点 |
| **交接** | 一只小手的影子接过笔，新线从旧线的末端继续——细、歪、快、更淡（又回到童年的线）。高音钟声像一个新声部加入 | 0:39.6–0:42.6 |

**反向设计是本片的技术核心**：先把最终的"脸"设计成一张成立的一笔肖像，再把它切成人生段落，每个段落在局部放大时读作一个生活场景、在全脸里读作一个五官。关卡 1 的第三张风格帧就是这张脸的完整一笔画（整条路径一次画完），用来自检"拉远后能认出这张脸"。

**路径拓扑（每块区域只画一次，连接线都落在自然的脸部线条上）**：左耳（出生，从左镜片外上方落笔）→ 头后侧、头顶（风筝线）→ 风筝 → 尾巴落回头右侧、弯进右眉外端 → 车把（右眉）→ 车架右侧 → 右镜片（前轮）→ 车架左侧 → 车座（左眉）→ 左镜片（后轮）→ 中轴 → 沿左镜框下到左法令纹 → 嘴（红：笑 + 两张侧脸）→ 右法令纹 → 房子（鼻子）→ 沿右镜框进到右眼 → 闭眼、停笔成泪（失去）→ 鱼尾纹出到镜框 → 右耳（孩子，出生的完全镜像）→ 右耳后脸边 → 下颌 → 下巴 → 左脸边 → 左眼（最后一笔）。

## 三、主体

**唯一主体是这条线**（也是这个人）。人从头到尾不出现具象形象，直到最后拉远——他是那张脸。
画面里另有一个"真实世界"元素：**笔的影子**。我们不画笔，也不画画画的人，只在笔尖处有一个很小的触纸点和一道柔和的笔杆投影（左上方来光，影子落向右下）。结尾交接时出现两只手的投影：老人的大手（微颤）和孩子的小手。投影不是墨线，不违反"无填色、无阴影"——画里没有阴影，只有纸上方真实的笔。

## 五、cue map（音乐先行）

**配器**：只有一把"独奏"大提琴（`cellos` 低力度 + 单声部 + 窄声像模拟独奏的连奏长音），童年段 `cellos_pizz`，结尾一声 `hand_chimes`（D6）。**没有钢琴，没有弦乐铺底**。调性 D 大调（空弦 D、A 共鸣最好），失去段转 B 小调色彩，结尾回 D。

| cue | 时间 | 速度 | 配器 / 写法 | 情绪 | 卡点 |
|---|---|---|---|---|---|
| A 握 | 1.0–4.9 | 自由 ~66 | 弓奏，D3 从 niente 渐入；动机 D–F#–A，攥紧上行到 D4 | 初生、温柔 | 1.0 落笔（音乐在第一笔起）；4.3 攥紧 = D4 |
| B 风筝 | 4.9–9.6 | 104 | 拨奏跳跃的上行音型，每笔一拨 | 轻快、好奇 | 风筝四个角 4 拨；两个蝴蝶结 2 拨 |
| C 骑车 | 9.6–13.9 | 88 | 弓奏回来，两轮各一句上行琶音（D–A–D–F#），换弓在圆周的最低点 | 自由、加速 | 前轮合圈、后轮合圈各落一个换弓 |
| D 初恋 | 13.9–19.2 | 72 | 最高、最长的一句旋律（A 大调色彩的倚音），连奏，揉弦加深 | 心动、歌唱 | 线变红 15.0 起渐强；鼻尖相碰 = 全曲最高音 A4 |

**声画同步做法**：先按 cue 表定每段的起止时间；段内的笔速按路径曲率自动分配（拐角减速），把每个"拐角到达时刻"导出为音符起点，写旋律时让换音/换弓落在这些时刻上（线快弓快、线停音延长）。笔速同时驱动沙沙声的强弱和亮度。

## 六、声音设计

- **笔尖沙沙声（本片最重要的音效）**：连续合成——带通噪声（1.8–7 kHz）× 纸纤维颗粒（随机细小"咔"声，密度随笔速）；响度 ∝ 笔速^0.7，亮度随笔速升高；慢处更闷更"湿"（墨多）；老年段加入断续（断墨时声音也断）；孩子的笔更轻、更快、更碎。声像跟随笔尖在画面里的横向位置。
- **落笔**：轻木质"嗒" + 纸的闷响；**停笔洇墨**：几乎听不到的湿润声，主要是静音。
- **底噪**：极轻的室内空气声（−52 dBFS），静音段一起切掉。
- **人声**：温和、回望的男声（老人自己在讲）。先试 `am_liam` 与 `am_eric`，按音高、共鸣和语气选更温暖的一个，速度约 0.88。5 句，每句都短，给线留空间。音乐在人声下闪避约 6 dB（大提琴本来就很轻）。
- 混音：人声压缩；大提琴一把琴一个声像（稍偏左，像坐在画家身边）；沙沙声在中间随笔移动；总响度 −14 LUFS；**grain = 0**（纸纹自己做）。

## 七、视觉规格

- **纸**：暖白 `#F4EFE4`，程序化纸纹（大尺度云斑 ±3%、细纤维、极细颗粒），纸纹锚定在纸上随镜头移动缩放；拉远时细颗粒淡出防闪烁；轻暗角 0.12。
- **墨**：暖黑 `#1D1A17`；童年墨色 0.78 透明度、壮年 0.96、老年 0.9 + 飞白。**红线** `#B3332B`（只在初恋到戒指这一段）。无填色、无阴影、无第三种颜色。
- **笔触**：路径按弧长重采样，线宽 = 年龄基准宽 × 速度系数（快细慢粗，0.65–1.45）；边缘有一点毛（高频噪声 ±6% 线宽）；慢处和停笔处墨会积（更黑、更粗、圆形墨点）；老年段垂直于路径的颤抖（振幅 0.9 单位，~7 Hz 空间频率）+ 断墨飞白（沿弧长的长尺度噪声决定断点）。线宽以纸面单位定义（拉近时线变粗，像微距镜头下的真墨线）。
- **镜头**：跟拍笔尖，带 0.3 秒延迟与 0.35 秒预判的平滑；每段有构图关键帧（中心、缩放、微转），跟拍与构图按权重混合，保证场景完成时构图完整、笔尖始终在画内；转动 ≤ ±10°。
- **笔**：触纸点一个 3 px 暗点 + 柔和的笔杆投影（高斯模糊楔形，朝右下，透明度 0.16）。

## 八、字幕与片名设计

- **字幕**：手写感 OFL 字体 **Caveat**（500，46 px），墨色 78% 透明度，无底框，底部居中（基线距底 104 px）；出现时**从左到右"写"出来**（0.45 秒遮罩）、消失时淡出；背后一圈极淡的纸色光晕，避免与经过的墨线打架。小而安静。每句 ≥ 语音 + 0.6 秒且 ≥ 1.8 秒。
- **片名**：**Sacramento**（单线连笔的手写体，本身就是"一笔画"的字）88 px，从左到右写出，下方 Caveat 小字 "a one-line drawing"。
- **片尾卡**：片名 + "ONE-LINE DRAWING"（Caveat 600，字距加宽）+ "LemoLab × Claude Opus 5.5"，写在右侧空白纸上，孩子的新线还在旁边画。

## 九、与风格说明的差异及理由

1. **时长 46 秒而非 35 秒**：八个人生段落（出生、风筝、自行车、初恋+戒指、房子、孩子、失去、老年）每段 3.6–5.4 秒才能让观众读出画的是什么；揭示后需要 1 秒纯凝视 + 交接 3 秒 + 片尾 3.4 秒。压到 35 秒会让每段只剩 2.5 秒，违背"节奏以观众为准"。
2. **最终图像的五官映射**：风格说明建议"拉远组成一张脸"，我把每个段落都设计成一个五官（而不只是散落在轮廓上的小画），让揭示有"原来如此"的层次：观众会依次认出眼镜、耳朵、红色的笑、泪。
3. **红线的位置**：说明允许初恋段短暂变红。红线最终留在脸上成为**笑容**——老人脸上唯一的颜色就是他爱过的人。
4. **笔的呈现**：只用投影表现笔和手，不画笔、不画手，保持画面里只有一条线。
5. **"失去"放在"房子"之后、"孩子"之前**（风格说明的顺序是孩子在前）：一是拓扑——右眼在镜片里面，右耳在外面，只有"先画眼、再出到耳朵"才能让下颌轮廓从右耳后一笔画完，不产生多余的脸颊线；二是情绪——失去之后紧接着一个新生命攥住他的手指，"And then it goes on" 有了具体的画面。
6. **五官的具体画法经过十几轮迭代**（见 PRODUCTION_LOG）：嘴试过"两个头组成的心""转 90° 的唇"，最后定为"笑的弧线中间两张鼻尖相碰的侧脸"（像鲁宾花瓶，局部读得出两个人，全脸读得出嘴）；眼睛从"带眼袋的杏仁眼"改成"闭着的眼睑 + 三根睫毛"，读得最清楚。

## 十一、关卡 1 之后的修改（按协调者意见，制作阶段已落实）

1. **耳朵**：婴儿的小拳头竖着弯成耳廓的 C 形贴在头侧，大人的手指（眼镜腿）从镜片外上方伸进拳头，指尖藏在拳里；四个短胖圆润的指节包在手指上，拇指从下面扣上来，手腕一道褶，胖胖的小胳膊就是耳垂。
2. **秃顶**：头顶是一条干净的圆弧，风筝线从头顶翘出来成为唯一一根头发；风筝画完、尾巴飘完，笔顺着尾巴和头发原路"收线"回到头顶（重描），再沿头顶另一半下来——头型不再被风筝线破坏。
3. **下半脸**：更长的椭圆，下颌收窄，脸颊微凹，单线轮廓（从右耳垂一笔画到左脸），只保留一道左法令纹和两道鱼尾纹。
4. **嘴**：去掉两个头顶之间的弧；两张侧脸的后脑成为上唇的 M（丘比特弓），下面一道红色弧线是笑；两人的脖子在笑弧中点汇合，一笔回路在鼻尖相碰处交叉；侧脸放大到 1.05。
5. **线宽**：线宽用的缩放下限 1.3，拉远时屏幕线宽保持约 3–4 px，笔压变化保留。
6. **婴儿小手**：见第 1 条；小手更小更胖，四根短胖手指，拇指在另一侧。
7. **旁白微调**（whisper 校对）：L4 改为 "Sometimes the line stops. / And then it goes on."（分两段，"goes" 落在笔重新出发的一刻）；L5 改为 "Your turn now."（"Your turn." 被听成 "Your turns"）。
8. **最终时长 47.5 秒**：停笔延长到 3.05 秒（L4 两句都在停笔里说完，"goes on" 时笔才走）；交接改为"拉远看全脸 1 秒 → 推近到闭上的左眼交接 → 跟着孩子的新线拉回"，新线在左边空白纸上画一只歪歪的小风筝，片尾卡写在右边。
