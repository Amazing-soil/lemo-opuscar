# Low-poly Isometric Island · 导演方案（Treatment）

**片名** *The Island That Grew*
**时长** 约 53 秒（风格说明建议 40 秒，理由见第八节）｜ **画幅** 1920×1080 ｜ **帧率** 24fps 输出，全部运动每帧平滑（程序化生长靠弹性曲线，不做步进）
**维度** 3D（three.js，flat shading，正交等距相机）
**一句话** 一片空海里只有一只浮标会响一个音；海底一块一块升起地块、树和房子，每放下一块就响一个音，岛长成了，歌也写成了——直到夜里，出海的小船找不到家，最后一块"音符"是灯塔。
**声线** Kokoro `af_sky`（清亮女声），5 句旁白

---

## 一、对标：学什么 / 刻意不学什么

| 对标 | 学什么 | 刻意不学 |
|---|---|---|
| **Townscaper** | "点一下长一块"的建造快感：每一块落定都有弹性回弹和声音；建筑自动长出可爱细节（屋顶、烟囱、窗）；**建造本身就是表演**，不需要角色 | 不做它的不规则四边形网格、不做它的运河城市造型和彩色墙面排列；不用它的点击光标 UI |
| **Monument Valley** | 正交等距视角的几何美、柔和低对比的粉彩配色、整块渐变天空作背景（场景像悬在色彩里）、安静克制的节奏和留白 | 不做不可能几何 / 视错觉、不做它的白衣小人与神庙建筑、不用它的字体设计 |
| **低多边形岛屿插画**（通用语法） | 平面着色的切面在光里一格一格闪、海面三角网格起伏、浅滩一圈亮色泻湖、白色浪花环 | — |

从两者合起来提炼的**核心语法**：*一个被正交相机凝视的小世界，一切都是几何块，一切出现都带弹性和声音。*

## 二、为什么这个故事适合这个媒介（原生能力 → 故事用法）

| 低多边形等距岛的原生能力 | 本片怎么用 |
|---|---|
| **程序化生长**：地块从海里升起、楼层一层层弹性堆叠、树"啵"地长出 | 整个第一幕就是生长。每一块 = 一个音符 = 一个拟音 |
| **正交等距 = 微缩模型的凝视** | 没有透视消失点，岛像桌上的模型；结尾正交放大缩小（zoom）做尺度揭示，岛在大海里缩成一粒 |
| **转盘旋转** | 生长全程是一个不剪的转盘长镜头（绕岛 90°），观众看着岛从各个角度长全 |
| **平面着色 + 光向** | 日夜循环时，每个切面随太阳角度一格格变色、影子扫过全岛（延时摄影），不用任何贴图就能讲时间 |
| **发光块在暗场里** | 黄昏窗户一盏盏亮（每盏一个音），夜里灯塔的光束像八音盒的拨片扫过全岛 |

## 三、情绪弧与结构

一个主体（岛）、一个目标（把歌写完 / 长成一个家）、一次转折（夜里小船迷路，歌缺最后一个音）。

| 幕 | 时间 | 情绪 | 发生什么 |
|---|---|---|---|
| 冷开场 | 0:00–0:06.25 | 孤独、好奇 | 空海，一只浮标"叮"一声，涟漪一圈圈荡开；片名字母像地块一样从水里升起 |
| 第一幕 生长 | 0:06.25–0:21.25 | 惊喜 → 加速的快乐 | 第一块地升起（第一个音），接着地块、山丘、树、房子、风车、码头、小船……音符越来越密，变成旋律 |
| 第二幕 一天 | 0:21.25–0:31.25 | 满足 → 温柔 | 白天延时：影子扫过全岛，风车转，小船出海；黄昏窗户一盏盏亮 |
| 转折 夜 | 0:31.25–0:36.25 | 不安、寂静 | 音乐几乎全停，只剩浪和虫鸣。远海里小船的一点灯在黑浪里晃，岛北端的礁石还空着："But one note was still missing." |
| 高潮 灯塔 | 0:36.25–0:41.25 | 爆发、温暖 | 灯塔一环一环弹性升起（上行琶音），第 12 小节强拍点亮；光束扫过全岛，**光束就是八音盒的拨片**，扫到哪家窗户哪家就响——完整的旋律第一次完整奏出；光束扫到小船，小船的灯回闪一下，调头回家 |
| 尾声 尺度 | 0:41.25–0:48.75 | 回响 | 小船靠岸；正交相机一路拉远，岛缩成大海里的一粒光，光束仍在转。画面右下极远处，**另一只浮标亮了一下，响起开场的同一个音**——另一座岛要开始长了 |
| 片尾卡 | 0:48.75–0:53.0 | 余韵 | 夜海远景上叠片名、风格名、LemoLab × Claude Opus 5.5 |

**首尾呼应**：开场浮标的一个音（D5 钟音）= 结尾远处另一只浮标的同一个音；开场旁白 "only one note" ↔ 结尾 "its first note"。
**尺度揭示**：开场是一只浮标占满画面的近景，结尾同一个正交视角拉到岛只剩几个像素。

## 四、原生招式（放在情绪最高点）

1. **建造即作曲（全片骨架）**：每个生长事件（地块 / 树 / 楼层 / 屋顶 / 风车 / 码头木板 / 灯塔环）在页面里生成一条 `EV` 事件，带音高；配乐的旋律声部直接由这些事件合成。岛长完 = 旋律写完。
2. **灯塔光束 = 八音盒拨片（高潮）**：点亮后光束旋转，扫过每栋房子的瞬间那扇窗闪亮并响一个音（音高按房子的方位角排好，扫一圈正好奏出主题）。这是只有"等距微缩 + 发光块 + 程序化事件"才能同时做到的：画面的空间顺序直接就是乐谱的时间顺序。
3. **不剪的转盘生长长镜头**：第一幕 15 秒一个镜头，正交相机绕岛旋转 90° 同时缓慢拉远，岛始终居中长大。
4. **正交尺度揭示**：结尾正交缩放 ×12，岛从占满画面到一粒光点，灯塔光束在大海上像指针一样扫。

## 六、配乐 cue map（音乐先行）

**配器**：卡林巴（主旋律，Karplus-Strong + 金属簧片泛音）、马林巴（低音与固定音型，木质）、氛围合成垫音（去谐锯齿波低通，慢起慢收）、沙锤 / 木块 / 很轻的底鼓（只在白天和高潮）、浮标钟（D5 钟音，全片的"那一个音"）。环境：浪、海鸟、夜里虫鸣。**不用钢琴和弦乐。**
**调性**：D 大调（五声为主）。**和声**（按律动小节）：D | Bm | G | A | D | Bm | G–A | D | D | Bm | G | A(sus) | D | Bm | G–A | D | D。
**旋律声部 = 画面事件**：页面导出的 `EV` 里每个生长事件都带 `note`（MIDI 音高，取当前小节和弦音，按"块高 → 音高"排轮廓），配乐脚本逐个合成——画面长一块，旋律响一个音。

## 七、声音设计

拟音跟材质走——这个世界的材料是**水、木、石、小块几何体**，声音都是"圆润、短、带一点音高"的：
- **地块升起**：水下气泡上扬（正弦扫频 + 带通噪声）+ 破水"啵" + 细碎水花；块越高声音越低越大。
- **树长出**：短促的木质 pop（带音高）。
- **楼层落定**：木块"咚"（木鱼 / 木块音色，和马林巴同家族），弹性回弹时有一声更轻的二次触碰。
- **屋顶扣下**：陶瓦"嗒"。
- **码头木板**：空心木板"哒哒哒"。
- **风车**：轻微木头吱呀（白天循环）。
- **浮标 / 船铃**：钟音（D5），带长尾。
- **灯塔点亮**：玻璃"叮" + 低频"嗡"的起辉声 + 持续的轻微电嗡。
- **环境床**：浪（低通布朗噪声 + 慢起伏），白天海鸥，黄昏以后虫鸣，夜里只剩浪。
- **静音**：夜的第 10 小节乐队全停；灯塔最后一环之后到点亮前半拍（36.0–36.25）连垫音都切掉。

混音：人声压缩后比音乐高约 10 dB，音乐在旁白下闪避约 −8 dB，成片两遍 loudnorm −14 LUFS，grain = 0。

## 八、字幕与片名设计

- **旁白字幕**：Quicksand 600，44 px，白字 + 柔和投影（不用底框——Monument Valley 式的"浮在画面上"）；左侧一个**小六边形地块图标**（顶面 + 两个侧面三色，平面着色），图标顶面颜色随时间变：黎明粉、白天草绿、黄昏橙、夜里窗户的暖黄。位置：画面下方居中，距底 120 px。
- **片名**：Josefin Sans 600，全大写，字距 0.22em，"THE ISLAND THAT GREW" 的字母逐个从一条水线下弹性升起（像地块），底下一行 Josefin Sans 300 小字 "a low-poly island film"。
- **片尾卡**：同一字体系统，夜海远景压暗，六边形图标 + LOW-POLY ISLAND · LEMO-OPUSCAR + LemoLab × Claude Opus 5.5 + 署名。
- 字幕与片名不同时出现；字幕显示区间不短于语音 + 0.6 s、至少 1.8 s，前后两句不重叠。

## 九、视觉规格（摘要，细节进 STYLE.md）

- 正交相机（OrthographicCamera），默认俯角 30°、方位角 45°；按段落调整俯角（22° / 35° / 50°）与缩放。
- 全部材质 `flatShading`，无贴图；六边形柱地块（沙 / 草 / 山 / 礁石），顶面色与侧面色分开。
- 海面：三角网格顶点动画（多组正弦叠加），浅滩泻湖颜色由"已长出的地块"实时生成的浅水图驱动，岸边一圈白色浪花环。
- 后期（自写，正交相机版）：GTAO 柔和环境光遮蔽 → 按深度把远处海面融进渐变天空（天空色随日夜关键帧变）→ 很轻的移轴模糊（微缩感）→ 辉光（窗户、灯塔）→ 粉彩调色 → 2× 超采样。
- 日夜循环：天空渐变、海色、太阳方向与色温、环境光一起按关键帧插值；夜里星星只出现在远处"天"的部分。

## 十、为什么比风格说明更长（约 53 s，而不是 40 s）

风格说明建议 40 s。我加入了"小船出海 → 夜里迷路 → 灯塔把它照回家"这条线，给灯塔一个情绪理由（它不只是最后一块积木，而是"把人照回家的那个音"）；同时 5 句旁白每句要 ≥ 语音 + 0.6 s 的阅读时间，结尾尺度揭示和片尾卡也需要停留。压到 40 s 就只能砍掉转折或砍停留，两样都会伤片子，所以按观众节奏放到约 53 s（仍在 30–60 s 规格内）。

## 十一、风险 / 最没把握的地方

- 正交相机下"天空"只能出现在远处海面融化的位置，夜里的星空要靠画面上方的渐隐区来表现，需要实测是否像天。
- 灯塔光束（透明加色锥体）在正交视角下的体积感。
- 事件驱动的旋律（建造顺序决定音符）要既好听又和画面卡得住，配乐子 agent 的输入契约要写清楚。
