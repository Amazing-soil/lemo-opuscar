# Data Storytelling · 导演方案（Treatment）

**片名** *A Hundred Summers*（一百个夏天）
**时长** 约 50 秒（90 BPM，4/4，1 拍 = 0.667 s，1 小节 = 2.667 s，共 18¾ 小节）｜ **画幅** 1920×1080 ｜ **帧率** 24fps，全部逐帧平滑（数据图表是精确的数字运动，不做步进）
**一句话** 一支红蓝两头的铅笔，在一张米色纸上替一个 1926 年夏天出生的女人画她的一生：每个夏天一个点，点的高度是那年夏天全世界的平均气温，点落下时发出一个音。童年的点安静地挤在一起，像一首摇篮曲；中年以后点开始往上爬，越爬越快、越来越高、越来越不和谐，冲破图表的天花板；音乐在 2025 年戛然而止（比小节线早半拍）——全片唯一的一刀——铅笔悬在空白处，落下今年的最后一个点：她的第一百个夏天，也是有测量以来最热的夏天。然后整条折线在一拍之内倒下、变成一整条从蓝到红的色带，最后一格空着：*Next summer?*
**主题一句话** 一百年的变暖，刚好装得下一个人的一生；下一格还没画。

## 一、对标：学什么 / 刻意不学什么

| 对标 | 学什么（语法） | 刻意不学 |
|---|---|---|
| **Hans Rosling《200 Countries, 200 Years, 4 Minutes》（BBC, 2010）** | 数据点在动、有人在讲；**一个点就是一个"角色"**，观众跟着它走；讲述者的语气平静，数字本身制造戏剧 | 不做气泡图、不做真人合成、不用他的配色和版式 |
| **Ed Hawkins 的 warming stripes（2018）** | **一条条色带讲完一百年**；色阶以一个参考期平均为中心、对称拉开（本片按他的做法以 1971–2000 平均为色阶中心）；去掉所有坐标，只剩颜色 | 不复刻他的具体图（数据集、年份范围、尺寸比例都不同）；片中不出现他的名字或图的名称；色带只在签名镜头之后出现，而且是由折线"变"出来的 |
| **The Pudding / 纽约时报滚动叙事图表** | **一次只讲一个想法**；坐标轴跟着故事长出来，不是一开始就画完；注释是钉在数据点上的小段文字 + 细引线；标题在图表左上的空白处；说明文字就是图注 | 不复刻任何一篇的具体图表设计、交互、字体；不做滚动网页的 UI（没有滚动条、没有按钮） |
| **图表批注的手写传统（编辑的红蓝铅笔、科学家的实验记录本）** | 手写注释 + 细引线 + 随手的小涂鸦（一道浪、一颗心）让冷的图表变成个人的；红蓝两头的编辑铅笔本身就是一条色阶 | 不做手账 / 剪贴簿风格，纸面保持干净的图表版式 |

**和同库其它风格的区别**：dark-keynote 是暗色产品发布 UI；iso-infographic 用等距插图讲流程；swiss-motion 是网格排版。这里**图表本身就是叙事、数据是真的**：每一个点的高度、颜色、音高都来自 NASA 的实测值。

## 二、数据（真实，不编）

- **来源**：NASA GISS Surface Temperature Analysis（GISTEMP v4），全球海陆表面温度距平表 `GLB.Ts+dSST.csv`（美国政府作品，公版），2026-09-26 下载，原样存于 `demo/data/`，由 `demo/tools/extract_data.py` 取出 **JJA 列（6–8 月，北半球夏季的全球平均距平，相对 1951–1980 平均，单位 °C）** → `demo/data/jja.json`。
- **她的一生** = 1926–2026，**101 个夏天**（她 1926 年夏天出生，2026 年夏天满一百岁）。
- 片中用到的事实（全部由脚本从数据算出，见 `extract_data.py` 输出）：
  - 1926–1976 这五十年，夏季距平在 −0.38 ~ +0.17 °C 之间徘徊（"For fifty years, her summers barely moved."）；
  - 1978 年是最后一个低于基准线（0 = 1951–80 平均）的夏天，此后再没回去（"…and they never came back down."）；
  - 1998（+0.70）是当时的纪录夏天；2026（+1.28）是 1880 年有记录以来最热的夏天（"It was the warmest ever measured."）。
- 她的个人事件（出生、第一次看海、女儿出生）是虚构的注释；**数字一个都不改**。

## 三、为什么这个媒介讲这个故事（原生能力 → 故事用法）

| 数据叙事的原生能力 | 故事里怎么用 |
|---|---|
| **一个点 = 一个事实** | 一个夏天一个点。第一个点就是她出生的那个夏天：一个淡蓝色的小点 + 手写 "1926 — she is born." 抽象的全球平均变成一个人的记忆 |
| **坐标轴跟着故事长** | 开场只有一个点；第二小节 x 轴从这个点向右画出去；旁白说到"温度"时 y 轴才出现（"0 = 1951–80 average"）；年代刻度在铅笔经过时才写上去 |
| **注释钉在数据上** | 早年的注释是个人记忆（蓝铅笔：出生、看海 + 一道小浪、女儿出生 + 一颗小心），后来的注释变成纪录（红铅笔："1998 — hottest yet"）。注释的内容从"记忆"变成"警告"，就是情绪弧 |
| **坐标轴重新缩放（rescale）** | 数据冲破图表上沿——图表"装不下了"——y 轴刻度被压缩、网格线往下滑、上面长出新的刻度。这是只有图表才有的"镜头运动"，用在不安升级的两个拍点上 |
| **数据声音化（sonification）** | 每个点的温度 = 一个音高，**曲线就是旋律**。越热音越高、越不和谐（音阶量化逐步放开 + 双振荡器失谐）。观众"听见"变暖 |
| **图表变形（line → stripes）** | 签名镜头：101 个点在一拍之内从左到右依次倒下、拉长，变成 101 条色带；每一条变形的那一帧，正好是它那个音被重新弹一遍的那一刻——她的一生在 0.67 秒里被重放成一个上行滑奏 |
| **尺度切换** | 一个夏天的特写 → 她的一百年 → 1880–2026 整个测量记录（她出生前的 46 个夏天在左边铺开，蓝得很平静）。最后一格空着 |

## 四、情绪弧与"表演"

**情绪弧**：温柔的怀旧（稀疏的点、蓝铅笔手写、摇篮曲一样的音）→ 平稳（五十年的点挤在一起）→ 逐渐不安（点开始爬、蝉声渐起、镜头开始倾斜）→ 冲破（天花板被戳穿、铅笔翻转成红头）→ 失控（点密到像地震仪的针在抖）→ **全片唯一一刀：静音** → 清醒（最后一个点、旁白、整条曲线全貌）→ **变形成色带（签名镜头）** → 回响（尺度拉远；最后一格空着：*Next summer?*）。
**一个主体**：她的时间线（由那支铅笔替她"演"）。**一个目标**：画完她的一百个夏天。**一次转折**：画到最后，她的一生变成了一整条红起来的色带——而下一格还空着。

**铅笔是全片唯一的"演员"**（原创造型：红蓝两头的编辑铅笔，只露出笔尖一段，从右下方入画，像一只右手在写）：
- **预备 / 动作 / 跟随**：每一次落点 = 抬起（预备，影子离开笔尖）→ 点下（动作，影子与笔尖重合，"嗒"）→ 轻微回弹（跟随）。早年每一下都从容；后来越点越急；32 分音符段笔尖像地震仪的针在纸上抖。
- **翻转**（26.67–27.3 s，1998 冲破天花板的那一拍）：先让观众看清点戳在天花板外面（0.67 s），铅笔同时抬起、首尾翻转 180°，蓝头换成红头（"嗖—咔"），之后的注释都是红色。这是"她意识到了"的那一刻，不用一句台词。
- **犹豫**（31.0–32.0 s，静音）：铅笔悬在 2026 的空位上方，失焦的大笔身占满前景；一动不动 1 秒；然后微微上抬（预备）——落下。
- **退场**：画完空格、写完 "Next summer?"，铅笔抬起、从右下方出画。**笔留给观众**。

## 五、原生招式（放在情绪最高点）

1. **数据声音化**（贯穿全片，高点在 27–30.7 s）：101 个点 = 101 个音。映射：`midi = 62 + (v + 0.4) × 17`（v = 距平 °C；1929 年 −0.38 → D4 附近，2026 年 +1.28 → G6 附近）。**和声规则随温度放开**：v < 0.25 量化到 D 大调五声音阶（永远和铺底和谐）；0.25 ≤ v < 0.7 量化到半音（开始出现 F、C、G#，和 D 大调铺底打架）；v ≥ 0.7 不再量化 + 第二个振荡器失谐 `(v − 0.7) × 60` 音分（拍频"发抖"）。音色是模块合成器的**低通门"咚"声（LPG plonk）**：FM 指数随温度从 0.3 升到 4，冷的时候像木头，热的时候像金属。节奏从四分音符 → 八分 → 十六分 → 三十二分音符：**同一个 90 BPM，点越来越密**。
2. **签名镜头：折线变成条纹**（37.33–38.67 s）：一拍之内，点从左到右依次倒下、拉成竖条、铺满色带，折线段被"吸"进条纹里；每一条变形的帧 = 它的音在滑奏里响起的帧。变形完停 2 拍给观众看清。
3. **尺度切换**（32.0 → 42.67 s）：2026 这个点的特写 → 拉远到她的一百年全貌 → 变成色带 → 再拉远到 1880–2026 整个记录，一道铅笔括号标出 "her hundred summers"。
4. **坐标轴破顶 + 重缩放**（26.67 s、30.83 s）：点戳穿上沿（"啪"一声，天花板线上留下一道带毛边的缺口，之后一直留着像一道疤），y 轴一拍之后分四下"咔咔咔咔"压缩重排（三十二分音符的棘轮）。
5. **首尾两个数字**：第一个点落下时旁边排出它的真实数值 `−0.22°C`，2026 落下时排出 `+1.28°C`。开场就告诉观众"这个点是一个数"，结尾用同一个排版收住。

## 六、镜头表（2D 摄影机 = 一张纸上的一台摄影机）

**全片是一个镜头走在一张纸上，只切一刀**：音乐在 2025 年戛然而止的那一帧，硬切到 2026 空位的特写——全片唯一的剪辑点，也是全片唯一的静。其余所有"剪辑点"都是**卡在拍点上的机位变化**（快推、急停、破顶震动），一个动作 = 一个声音 = 一次机位变化。
**2D 纵深**：纸面（格线、数据、注释）一层；铅笔在纸面之上，有柔和投影（离纸越高影子越远越虚）和景深（笔身越往后越虚）；机位移动时铅笔和纸面有视差。镜头运动全部 24fps 逐帧平滑，微弱的"手持呼吸"只在追拍段出现。

## 十、画面系统

- **纸**：米色 `#F6F3EC`，极淡的纤维噪声（随机种子固定在纸上，跟着机位走）+ 很淡的 5 mm 格点 `#E7E1D5`（给摄影机运动一个参照）。
- **墨**：轴线 / 折线 `#2B2723`（折线 2.5 px），网格线 `#DDD6C9` 1 px，刻度数字 IBM Plex Mono 20 px `#6E665C`。
- **数据点**：半径 6 px，填色 = 色阶，1.5 px 墨色描边（保证接近中心的浅色点在米色纸上也看得见）。
- **色阶**（warming stripes 语法，中心 = 1971–2000 平均 0.22 °C，半幅 0.85 °C）：`#2166AC` → `#4393C3` → `#92C5DE` → `#D1E5F0` → 中心 `#F2EEE8` → `#FDDBC7` → `#F4A582` → `#D6604D` → `#B2182B` → 超出上限 `#7A0F1E`。色带有 1 px 墨色外框。
- **手写**：Caveat（OFL），蓝铅笔 `#2F5D8A`、红铅笔 `#A8283A`，石墨颗粒质感（文字填色后用噪声挖掉 12% 像素）；写字 = 从左到右的揭示 + 笔尖沿基线上下跳动地跟随。引线是略带抖动的二次曲线，数据点外画一个没闭合的小圈。
- **标题 / 图注**：Newsreader（OFL）。片名 96 px 500；字幕 42 px。
- **铅笔**（原创）：红蓝双头编辑铅笔，六棱笔杆（蓝 `#2F5D8A` / 红 `#A8283A` 两半）、削开的木头锥 `#E3C79C`、石墨芯；只露出笔尖一段，从右下方约 35° 入画；投影 `rgba(70,50,30,.18)` 高斯模糊，离纸越高越偏越虚；笔身景深：离笔尖越远越虚。
- **唯一彩色口子**（引擎通用）：任意元素可以指定 `accent` 颜色，绕过色阶保持自己的颜色。

## 十二、对风格说明的调整（及理由）

- **时长约 50 s（说明参考 35–45 s）**：101 个点要让观众先"学会"一点 = 一个音（前 7 个点每拍一个），2026 前的静音、变形后的停留、尺度揭示和"Next summer?"都需要完整的呼吸；片尾卡还要留够读署名的时间。已经把点的节奏压到 32 分音符，不再注水。
- **加了一个"演员"：红蓝两头的铅笔**。说明里的主体是一条时间轴，没有角色；但"表演"（预备/动作/跟随、犹豫、翻转）需要一个身体。铅笔是做图表的手的延伸，它的两头正好是色阶的两端，翻转 = 转折。它只露出笔尖，不抢数据的戏。
- **"再拉远到更长的时间尺度"用真实的 1880–2026 测量记录**，不引入古气候重建（那需要另一套数据和不确定度表达，30 秒讲不清，也不能编）。
- **全片一个镜头、只切一刀**：数据叙事的力量在连续性（同一张图、同一支笔）；唯一的一刀给静音，让"切"本身成为事件。
- **不做纪录旗标**：试想过每个纪录年打一个红色小旗，但会和注释、破顶抢"一次只讲一个想法"；纪录只用两条注释（1998、2026）和两次破顶来讲。
