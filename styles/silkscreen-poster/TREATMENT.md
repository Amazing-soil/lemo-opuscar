# Silkscreen Travel Poster · 导演方案（Treatment）

**片名** *Three Trails*（画面上的片名来自 content.json：`3 Trails in Granite Valley`）
**场景** 户外步道指南：虚构的 Granite Valley 园区，游客中心墙上的三张步道海报 + 一条横幅，从印刷台一路印到上墙。
**时长** 38.4 s（片尾卡 3.6 s 在内）｜ **画幅** 1920×1080 ｜ **帧率** 24 fps，刮板、镜头每帧平滑；套色抖动按 12 fps 步进
**节拍** 100 BPM，4/4，一拍 0.6 s，一小节 2.4 s，全片 16 小节
**旁白** 无（按派单）。信息全在海报上，不需要字幕和 `.srt`。
**一句话** 刮板把第一层天空推满画面；三张步道海报按"天空 → 远山 → 中景 → 近景 → 信息带"一层层印出来，一张比一张快；第三张不再重印，镜头沿步道从谷底升到山脊，时间从中午走到黄昏，整张海报被重印了两遍；最后三张海报挂在游客中心的墙上，全部信息同时在场。
**看完能说出** "这个能拿去做景区 / 国家公园 / 户外品牌的路线介绍，游客中心屏也能放。"

> **关卡 1 后的修改（协调者意见，已全部落实）**
> 1. 第 3 张不重演逐层印刷：批准。
> 2. 签名镜头的重印：刮板改成斜着推（−12°），只露刀口、墨珠和一截手柄。刮板两侧几何完全一致，只换墨色，山脊线和步道虚线都跨过刀口接上。
> 3. 视差的"纸版感"：爬升时每层上沿多一道 3 u 纸白缝和一道 9 u 纸厚阴影，套色错位放大到约 ±6 px。静一拍后"卡嗒"，错位和阴影同时归零。
> 4. 钩子里的墨珠：改成圆润厚实的湿墨条（受光半边、背光下沿、连续高光，亮点随刮板滚动，短粗拉丝挂一滴）。刮过的地方透出网格。镜头拉开到 z≈2.7，让网框的边和刮板木柄入画。
> 5. 信息带加高到 326 u（场景上移 50 u，裁掉一点天空）。上墙后标签约 18 px，数值约 31 px。列宽按内容分配，文字墨色按对比度自动挑。
> 6. 瀑布：岩壁内侧加两块深色切面，把纸白瀑布夹在中间。水潭波纹简化成两道。
> 7. 时长 38.4 s（含片尾卡）。4 条步道怎么压缩写在 STYLE.md §11。

> **关卡 2 后的返修（v2；v1 备份为 `silkscreen-poster_v1.mp4` 和 `demo_v1/`）**
> 1. **片名横幅：选"保留横幅、贴近"，不把片名并进第 1 张海报。** 理由有三条：
>    - 横幅就是落版墙上的页眉，开头印、结尾挂，首尾呼应；
>    - 如果把片名并进第 1 张，三张海报的页眉会不一致，系列感就破了；
>    - 分色刮铺天空的钩子也要一张横向的纸才成立。
>
>    改法：
>    - 横幅从 7:1 改成 4:1（1800×440），片名断成两行；开场拉开后撑满画宽（左右边距约 5%），占画高约 39%。
>    - 台面换成旧木工作台：木板、木纹、节疤、干掉的墨渍（颜色压暗）、撕剩的胶带条。随机彩点去掉了。
>    - 墙上的横幅缩到 1150 px 宽，居中挂在海报上方，保证上墙后海报数值仍 ≥30 px。
> 2. **第 2 张快印段**：
>    - 起始机位 z = 1.25，整张纸宽和上沿一直在画里，海报占画高 100%，不会再出现整屏只有一块浅色平涂；
>    - 拉到信息带时 z = 1.5，海报占画高约 78%。
> 3. **信息带完整入画**：第 1 张 z = 1.55（左右边距约 12%），第 2 张 z = 1.5（约 13%），第 3 张下摇到信息带时 z 从 2.06 降到 1.72（约 7%）。CLIMB 一栏和 "01" 都完整。
> 4. **片尾卡改成最后两刮**：第一刮用分色墨珠印出一张横版小海报（天空色带、日圈、山脊、步道虚线、片名），第二刮印深色信息带：风格名、Lemo-Opuscar、LemoLab × Claude Opus 5.5、字体与采样署名。第二刮有自己的刮墨声。

## 一、对标：学什么 / 刻意不学什么

| 对标 | 学什么（语法） | 刻意不学 |
|---|---|---|
| **1930–40 年代 WPA 国家公园丝网海报** | 4–6 个不透明平涂色；山体用"受光面 + 背光面"两块硬边色；天空用**色带台阶**代替渐变（粗条到细条）；底部一条深色信息带、大写粗体园区名；太阳用同心圈 | 不抄任何具体海报的构图、园区名、字体设计；不写 "National Park" 之类的真实机构字样 |
| **当代 Fifty-Nine Parks 系列** | 现代丝印的套色克制；留白（纸色）当第七个颜色用；海报做成系列：同一套版式，每张换一套时间色 | 不学它的具体插画、编号样式和 logo 位置 |
| **丝网印刷的物理过程**（参考工作室拍的印刷过程影像） | 网版铰链抬起落下；刮板把墨珠推过网纱；**分色刮（split fountain）**：刀口前摆几种墨，一刮出一条色带；刮痕、针孔、墨层边缘的厚度光；套色错位露出的细白缝 | 不做真实照片感的网版和刮板，全部按丝印自己的平涂语言画（两色木柄、一色胶条、平涂投影） |
| **Wes Anderson 的俯拍桌面镜头**（只学镜头语法） | 俯拍、正交、物件对齐画框；快速横移接硬停 | 不学他的配色和对称人物调度 |

## 二、和库里相近风格的区别（开工前看过成片和 STYLE.md）

| 库内风格 | 它是什么 | 本风格怎么区分 |
|---|---|---|
| **risograph**（*Sunday Ride*） | 半透明荧光专色叠印出第四、第五色；网点半调、墨粒颗粒；角色喜剧 | **不透明**平涂墨层，后印的完全盖住先印的；**没有网点、没有荧光色、没有叠色混色**（唯一的叠色只在错位的一条细边上）；颜色数 4–6 且每张海报独立一套；场景是信息海报，不是故事 |
| **ukiyoe**（浮世绘） | 木版、墨线轮廓、普鲁士蓝、木纹与马连擦痕 | **完全没有线描**：形状只由色块的硬边界定义；纸面无木纹；天空是色带台阶，不是 bokashi 渐变 |
| **lowpoly-island** | 3D 多边形小岛，平面着色的三角面 | 纯 2D 版画：山体切面是手工式的锯齿大块，不是三角网格；有纸、有墨、有套色错位 |
| **woodcut** | 黑白刻线、刀痕 | 彩色、无刻线、无刀痕，靠平涂色面 |
| **swiss-motion**（音乐会海报自排版） | 网格排版、纯字体动态 | 本片的字只是信息带里的一层版，主角是风景插画和印刷过程；排版固定成"旅行海报"模板 |

库里已有的 demo 场景没有"路线 / 景点指南"，本片不撞场景。

## 三、信息弧（替代情绪弧）

1. **钩子（0–1.2 s）**：第一帧就是刮板正在推墨：分色墨珠（橙红 / 金黄 / 青绿三段）在刀口前滚动，身后天空色带一刮就铺满整个画面。
2. **分层上场**：
   - 片名（横幅）→ 第 1 张：五层逐拍印，每层一个扫弦 → 信息带：名称 → 难度 → 距离 → 用时，一次只亮一个。
   - 第 2 张用八分音符快印（加速），信息带同样顺序。
   - 第 3 张的信息最重要（最难、最长、唯一有爬升），给它全片唯一的长镜头和高点。
3. **一个高点**：山脊步道。镜头沿步道从谷底升到山顶，近景松林沉下去、三道山梁依次向两侧让开；步道虚线跟着镜头一段段印出来；海报被整张重印两次（中午 → 午后 → 黄昏），告诉观众"这条要走一整天"。到顶后静一拍，各层"卡嗒"一声套准，全乐队进。
4. **落版**：三张海报 + 横幅挂在游客中心的木墙上，全部信息可读，停 4.2 s。这一帧就是可以直接截图的海报 / 封面。

## 四、原生招式（只有丝印能做的）→ 怎么服务信息

| 丝印原生能力 | 本片用法 |
|---|---|
| **一次一色的套印** | 每一层 = 一个节拍 = 一声扫弦；观众的眼睛被一层一层领着走，信息带最后印，所以最后被读到 |
| **分色刮（split fountain）** | 开场钩子：一把刮板刮出三条色带，片名横幅的天空一刮成形 |
| **色带台阶代替渐变** | 所有天空：一块大色 + 五条由粗到细的条纹过渡；横幅同理 |
| **套色错位 → 细白缝 / 叠色边** | 太阳和光圈是从天空版里**镂空**的，错位让一边露出一弯纸白；每块版二次轻压一层 multiply 的边，留下一道深色叠印边；高点之前各层故意松开，"卡嗒"一声套准 |
| **同一张海报整体换色表示时间** | 高点里的两次重印：一把大刮板从下往上推过整张海报，推过的地方从中午色换成黄昏色——"7 h"这条数据被画出来了 |
| **墨层厚度的微弱光泽** | 每块墨的左上边一道亮边、右下边一道暗边；刚刮过的湿墨在刮板后面亮一截，随后变哑 |
| **纸是第七个颜色** | 第 2 张的瀑布不上墨，就是纸本身（从岩壁版里镂空） |

## 七、Cue map（100 BPM；配乐：美式户外民谣）

## 九、字幕 / 文字设计

- 无旁白、无字幕。文字全部是"印出来的一层"：Big Shoulders Display 900（大标题、步道名、编号，窄体粗无衬线，接近 WPA 手绘标题字）+ Outfit（数据、标签、页脚，几何无衬线）。两者 OFL。
- 信息带是固定模板：步道名（自动缩字号适配宽度）+ 右侧编号 + 太阳色分隔线 + 2–4 个数据项（难度 / 距离 / 用时 / 爬升，爬升为空就不出现，列宽自动平分）。
- 每个数据项自己一刮（从左往右 0.18 s），不做淡入。

## 十、content.json（本批核心交付，初稿在 `demo/content.json`）

| 字段 | 内容 |
|---|---|
| `park`、`title`、`footer` | 园区名（每张海报页眉）、片名（横幅）、页脚（横幅底条，落版时读） |
| `trails[]`（1–4 条） | `name`、`difficulty`（easy / moderate / hard）、`distance`、`time`、`elevation`（可空）、`scene`（lake / waterfall / ridge / forest / coast，引擎内置）、`time_of_day`（dawn / noon / golden / dusk / night） |
| `palette` | `paper`、`wall`、每个时刻一套 6 色（`sky1 sky2 far mid near sun`，可选 `glow` 受光面色）、横幅色 `banner` |
| `banner_time`、`units` | 横幅用哪套色；距离、爬升单位 |

时间线规则（代码里已实现）：第 1 条 = 完整印刷，中间各条 = 快印，最后一条 = 签名爬升；每段的停留按"字数 / 12 + 1 s"自动算，最短 1.5 s，并对齐到拍。1 条时只有完整印刷，没有爬升。
