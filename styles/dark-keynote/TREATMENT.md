# Dark Tech Keynote · 导演方案（Treatment）

**片名** *Room to Think*（留点地方想事情）｜ 虚构 app **Tidy** 的发布片
**时长** 约 42 秒（21 小节 × 2 s，120 BPM，4/4）｜ **画幅** 1920×1080 ｜ **帧率** 24fps，全部逐帧平滑（软件 UI 的动效就是 60Hz 的精确运动，不做步进）
**一句话** 一个青柠色的文字光标想打一句话，打到一半被通知打断；镜头一路往后拉，桌面、相册、收件箱像两台不同步的马林巴一样越堆越乱，直到光标被埋掉。全场冻住、静音一拍——光标自己蓄力按下去，一圈光扫出去，几百个窗口和图标在一拍里按网格飞回原位。原来这个光标就是 Tidy 的标志。最后屏幕上只剩它，它把开场没打完的那句话打完：**Room to think.**
**主题** 乱不是东西太多，是节奏错了位。Tidy 把一切对回同一拍。

## 一、对标：学什么 / 刻意不学什么

| 对标 | 学什么（语法） | 刻意不学 |
|---|---|---|
| **Apple 发布会产品片**（Apple Watch 初代揭幕片、AirPods 揭幕片） | 黑底 + 柔光；产品从黑暗里被一道光"扫"出来，而不是直接出现；一句话一屏、字很少；产品慢慢转进画面，机位几乎不动、只让光动；旁白是克制的陈述句，没有形容词堆砌；大数字单独占一屏 | 不做实物玻璃 / 金属渲染（那是 glass-product 的事）；不出现任何 Apple 的界面、字体（SF）、系统控件（红黄绿三个窗口按钮、菜单栏、Dock）、"one more thing" 式台词 |
| **Linear / Stripe / Vercel 的发布视频** | UI 本身是主角：精确的吸附网格、1px 细线、柔和光晕、近黑渐变底；动效是"弹性但克制"（快出、带一点过冲、立刻停稳）；大号无衬线数字；等宽小字做标签；一种品牌强调色只给最重要的一个元素 | 不借用任何品牌资产、配色组合、logo、界面布局；不做它们招牌的"3D 倾斜网格地板"与彩虹渐变 |
| **Steve Reich《Piano Phase》《Music for 18 Musicians》**（配乐语法） | 同一个 12 音音型由两件乐器演奏，一件慢慢加速 → 两条线错位，产生越来越密的"假旋律"；音型是全片的时间骨架；结尾用"减法"一个音一个音拿掉 | 不用原曲音型、音集、配器顺序；不做"钢琴 + 弦乐"，也不做 EDM |
| **Edgar Wright 式插入镜头** | 混乱高点用 4 个半秒插入镜头打在拍点上，一个动作 = 一个声音 = 一个剪辑点 | 不做漫画拟声字、不抄具体镜头 |

**和 glass-product / dataviz 的区别**：glass-product 的主角是一个 3D 实物；dataviz 讲数据背后的故事。本片是**软件发布**：主角是界面、光标、窗口本身，数字只出现一次、只是产品卖点。

## 二、为什么这个媒介讲这个故事（原生能力 → 故事用法）

| 暗色发布片 + 软件 UI 的原生能力 | 故事里怎么用 |
|---|---|
| **UI 元素可以无限复制、瞬间出现** | 混乱不用"画"，而是"生成"：通知、文件、照片、标签页按音符一个个生成，越来越快，几百个 |
| **吸附网格（snap grid）** | Tidy 的全部卖点就是一个动作：所有东西一拍之内吸回网格。网格平时隐形，按下那一刻才显形 |
| **光标是屏幕上唯一"活着"的东西** | 光标 = 主角。它会眨（每拍一次，就是节拍器）、会被通知挤开、会犹豫、会蓄力按下。它是全片唯一的青柠色，也是 Tidy 的 logo |
| **界面可以暂停** | 按下之前全屏冻结：几百个元素停在半空，声音一起断掉——只有屏幕能做到的"时间停止" |
| **暗场 + 柔光** | 产品界面先是黑的，一道斜光扫过去，光扫过的地方才亮起来 |
| **数字从乱码滚成答案** | "12,408 files." 每一位先是乱跳的字形，按十六分音符从右往左一位位锁定 |

**情绪弧**：安静专注（光标打字）→ 被打断（第一声通知）→ 焦虑累积（拉远、越堆越乱、越来越快）→ 淹没（光标被埋、插入镜头连打）→ **冻结 + 静音**（全片最静的一秒）→ **按下**（全片最重要的声音）→ 释放（一拍收拢）→ 惊喜（原来光标就是 Tidy）→ 信任（大数字）→ **呼吸**（东西一件件收好、音乐一个音一个音减掉、第二次静音）→ 回响（光标把开场那句话打完）。
一个主体（光标）、一个目标（把那句话打完）、一次转折（它不再躲，而是自己按下去）。

## 三、原生招式（放在情绪最高点）

1. **界面收拢**（16.0–17.0，签名镜头，情绪最高点）：冻结一秒后，光标先向上拉长（蓄力，2 拍，无声），16.0 猛地压扁成一个方点——"咚"——一圈青柠色光环从它身上扩散出去。光环扫过哪里，哪里的窗口、图标、照片、通知就被"吸"走：带运动模糊、旋转归零、弹性过冲，在同一拍里落进 24×12 的吸附网格。镜头同时从光标特写急速拉到全景（1 拍），让观众看见"几百个东西一起归位"的尺度。17.0 网格线"咔"地显形 0.5 秒再隐去。
2. **错相 = 混乱**（贯穿前半段）：两条马林巴演奏同一个音型，第二条慢慢加速错位。**画面上每个元素的出现都挂在一个音符上**：第一条线（在拍上）生成文件和照片，第二条线（错位的）生成通知。观众看到的混乱就是听到的错相。按下那一拍两条线重新对齐成一个和弦——声音和画面同时"对齐"。
3. **光的揭幕**（20.0–21.5）：收拢后的网格压进一个窗口，灯光暗下；一道斜向柔光带从左上扫到右下，光扫过的像素才亮，前沿有一道窄高光。窗口同时慢慢转正（透视 −22° → 0°）。
4. **大数字**（26.0–29.5）：镜头钻进窗口底部状态栏的计数器，计数器变成满屏的 "12,408"——每一位先乱跳（字形 + 竖向运动模糊），26.5 起按十六分音符从右往左逐位锁定，每锁一位一个马林巴音；27.0 "files." 落下；28.0 第二行 "Sorted in **0.8** seconds."（0.8 是青柠色）。
5. **窗口缩回光标**（32.5–33.0）：最后 Tidy 窗口竖向压成一条线、再横向压成一根竖条——变回那个光标。

## 四、主角与视觉系统（关卡 1 交 3 张风格帧，无角色设定表）

**主角：光标**（Tidy 的标志）。青柠 `#B7F34A` 圆角竖条，宽:高 = 1:14，带 24px 同色柔光。表演：
- 眨眼 = 节拍：拍上亮 0.5 s、灭 0.5 s（1 Hz，和真实光标一致）。
- 被打断：通知滑进来时它被"挤"一下（x 位移 8px + 挤压 0.9/1.1，0.2 s 弹回），然后停止眨眼、常亮两拍（愣住）。
- 蓄力：高 ×1.35、宽 ×0.8（ease-in，1 拍）；按下：2 帧内高 ×0.3、宽 ×2.4；跟随：弹簧回弹 0.6 s，恢复眨眼。
- Tidy logo = 圆角方块里一根青柠光标；文字标 "Tidy" 后面永远跟着这根光标。

**色板**
| 用途 | 色值 |
|---|---|
| 底（渐变） | `#0A0B0F` → `#151822`（上中心略亮的径向渐变） |
| 细线网格 | `rgba(255,255,255,.035)`，48px 模块，每 4 格一根 `.06` |
| 窗口面 / 抬升面 | `#12151C` / `#1A1E28`；1px 描边 `rgba(255,255,255,.08)`；顶边内高光 `.10` |
| 正文 / 次要字 | `#E8EAF0` / `#8A90A0` / 标签 `#5C6272` |
| **品牌强调（唯一彩色）** | 青柠 `#B7F34A`，光晕 `rgba(183,243,74,.35)` |
| 噪音红（只在混乱段） | 角标红 `#FF5A5F`——混乱是红色的小点，秩序是一根青柠光标。收拢之后画面里再也没有红 |
| 冷光晕（纵深） | `#3B4CCA` 8% 大径向光斑 |

**UI 元素（全部原创，代码绘制）**：圆角窗口（半径 14，标题栏 40px，只有一个小 app 图标 + 标题，不画任何系统按钮）；通知卡（半径 18，图标方块 + 两行字 + "now"）；文件图标（折角纸 + 文件名：`final_v2.pdf`、`final_FINAL.pdf`、`Untitled 38`、`IMG_4471.jpg`、`notes (copy).txt`…）；照片缩略图（程序化渐变小风景）；邮件行（未读圆点）；浏览器标签条（标签越分越细）；红色计数角标；存储条；转圈加载。
**字体（OFL）**：Inter（UI、字幕、大字，可变字重）、Inter Tight（大数字）、JetBrains Mono（标签、文件名、状态栏）。

## 七、Cue map（音乐先行；画面卡这张表）

**配乐类型**：极简主义（Reich 式错相）。马林巴（VCSL，CC0）+ 颤音琴硬槌 / 弓奏（VCSL，CC0）+ 钟琴（VCSL，CC0）+ numpy 合成铺底（去谐锯齿波低通）+ 低频正弦脉冲 + 噪声沙锤。**A 大调 / 升 F 小调之间的调式游移**，120 BPM，十六分音符 = 0.125 s。
**音型 P**（原创，12 个十六分音符 = 1.5 s，和 4/4 小节形成 3:4 错拍）：`A3 E4 B4 E4 C#5 E4 | A3 E4 B4 E4 D5 C#5`（前后半只差最后两个音，错相时会"咬"出新旋律）。
**错相实现**：第二声部演奏同一音型，速度从 120 → 121.8 BPM（8.0–14.0，约错开 3 个十六分音符），14.0–15.0 再加速到 127 BPM；第三声部（钟琴，只奏 P 的高音）反向减速。音符时间表写进 `timeline.js`，**画面生成元素直接读这张表**，配乐也读这张表——同一个数据源。

## 八、声音设计表

**核心想法**：混乱的声音是**散的**（音高各差几十音分、声像乱摆、每种来源一个音色），Tidy 的声音是**一套**（同一种"毛毡 + 玻璃"材质、全部调在 A 大调里、居中）。按下那一刻，散的声音被对齐成一个和弦——声音本身在讲"整理"。

| 段落 | 环境底 | 主要拟音 | 音乐状态 |
|---|---|---|---|
| 片名 0–3 | 安静的房间 + 极低的电脑风扇（棕噪声低通 180 Hz，−48 dB） | 光标"嗒"（2 kHz 带通短脉冲，极轻）、矮轴键盘（每字一个软"嗒"，随机 ±1 半音）、回车（更重的"咔"） | 无 |
| 打断 3–4 | 同上 + 远处模糊的通知群淡入（J-cut） | 通知"叮"：短正弦 + 二次谐波 + 玻璃高频，音高取音型高音 | 无 |
| 拉远 4–12 | 风扇声逐渐升高、加一点线圈啸叫（6.8 kHz 细正弦，越来越响） | 文件落下（软"噗嗒"）、照片甩入（纸牌"唰"）、窗口弹开（短"嗖"，大窗口低、小窗口高）、邮件滚动（细"沙沙"）、标签分裂（极短"嗞"）、角标计数（细"嘀"） | 马林巴 → 同度 → 错相 → 三声部 |
| 插入 12–14 | 风扇 + 啸叫达到最高 | 每个插入一个"故障"重音：数字噪声 + 下滑的方波；存储条变红一声低沉错音"嘟" | 最密 |
| 淹没 14–15 | 同上 | 叠放的低频"咚咚"（东西越压越重）、上升扫频 | 上升 |
| 静音 1 15–16 | **全部切断** | 无 | 无 |
| 收拢 16–18 | 底噪回来但变干净（只剩极低的空气声，风扇和啸叫消失） | **"咚"**（毛毡槌 + 55→40 Hz 正弦下滑 + 室内混响尾巴）；光环"呼"（低通噪声扫过全频）；归位"嗒"群（每个元素一个玻璃短音，按落位时间排开，音高全在 A 大调里）；17.0 网格"咔"（清脆高频） | 全体齐奏和弦 |
| 分类 18–20 | 干净的空气 | 格子滑动（毛毡"嗒"，八分音符）、窗口框画出（细线"嘶"） | 单声部对齐音型 |
| 揭幕 20–26 | 干净的空气 | 光扫（高频微光"嘶——"，带通噪声从 3 kHz 扫到 9 kHz + 几个高次泛音）；勾（玻璃"叮"，调内） | 弓奏和弦 + 轻音型 + 脉冲 |
| 大数字 26–29.5 | 干净的空气 | 乱码颗粒（极短随机点击，密度渐增）；锁位（毛毡"嗒" + 马林巴音）；第二行（一次柔和"嗖"） | 上行锁定音 + 和弦点 |
| 呼吸 29.5–33 | 干净的空气，逐渐变得更安静 | 每收起一件一声轻"嗒"；窗口压成光标（低"呼"收成一点） | 减法 |
| 静音 2 33–34 | −60 dB | 无 | 无 |
| 回响 34–42 | 安静的房间（和开场同一个底噪，但没有风扇啸叫） | 光标"嗒"、键盘、最后两声"嗒" | 最后一个和弦 |

**混音**：旁白压缩后在最上层，音乐在旁白下闪避 −8 dB，拟音闪避 −4 dB；静音 1 是**数字静音**（全部轨道 0）；响度 −14 LUFS；颗粒 0。
**J-cut / L-cut**：① 3.25 通知群的模糊声先于拉远镜头进入（J）；② 16.0 的和弦用弓奏颤音琴拖进 20.0 的揭幕（L）；③ 19.6 光扫的微光声先于光带出现（J）；④ 27.0 的和弦点拖进呼吸段（L）。

## 十、对风格说明的调整（及理由）

| 项 | 风格说明 | 本方案 | 理由 |
|---|---|---|---|
| 时长 | 30–40 s | 约 42 s | 大数字段和结尾回响各需要 ≥ 3 s 阅读时间；每句字幕 ≥ 1.8 s。不注水，但不为压时长砍停留 |
| 按键前静音 | 1 拍 | **2 拍（1.0 s）** | 1 拍（0.5 s）在 120 BPM 下像一次掉帧；2 拍才读得出"时间停了"，也给光标蓄力留出动作时间 |
| 谁按下 | "一键" | **光标自己按下** | 让唯一的主角完成转折（导演要求：一个角色、一个目标、一次转折），也顺手揭示"光标 = Tidy 的 logo" |
| 结尾 | 只剩光标闪烁 | 光标先把开场没打完的话打完，片尾信息淡出后**只剩光标闪两下** | 首尾呼应多一层：打断的那句话在结尾完成 |
| 红色 | 只要一种强调色 | 混乱段允许红色小角标 | 红 = 噪音、青柠 = Tidy；收拢后画面里再无红色，颜色也在讲故事 |

## 十一、技术方案

- 纯 Canvas2D，一张 1920×1080 主画布 + 离屏画布（前景虚化层、产品窗口层、光扫遮罩）。
- `engine.js`：暗色发布片的绘制引擎（背景 / 网格 / 光晕 / 圆角面板 / 窗口 / 通知 / 文件 / 照片 / 角标 / 光标 / 任意路径的"发光 UI 形状" / 光扫揭幕 / 乱码滚数字 / 吸附飞行（运动模糊 + 弹性）/ 2.5D 摄影机 / 条带透视 / 字幕气泡），场景文件只调用引擎。
- `timeline.js`：速度网格 + 音型 + 三条声部的音符时间表（错相）——画面生成元素、配乐、混音、卡点自检共用。
- 配乐 fork 子 agent 按本 cue map 和 `timeline.json` 写（契约：音符表 + 卡点 + 两处静音）；画面并行制作。
- 自检：`tools/cuecheck.py`（配乐卡点 ↔ 画面事件），whisper 逐句，ebur128。
