# Isometric Infographic · 导演方案（Treatment）

**片名** *From Bean to Cup*
**时长** 约 57 秒（风格说明参考 35–45 秒；理由见第十节）｜ **画幅** 1920×1080 ｜ **帧率** 24fps 输出，人物与小物件 12fps 步进（on twos，像信息图里的小动画），镜头、水面、烟、光圈每帧平滑
**一句话** 一颗红色咖啡果从枝头落进采豆人的手心，旁边的小标签写着 **0 km**。镜头一镜到底跟着它走过一整张等距地图：山坡、晒床、卡车、港口、货轮、大海、烘焙厂、咖啡馆。在一整船、上亿颗豆子里，镜头钻进船舱、集装箱、麻袋，找到**你的那一颗**。最后它变成你手里的一杯咖啡，构图和开场一模一样，标签变成了 **11,000 km**。镜头一路拉远，整条路线是一张完整的信息图。
**题眼** 数字越变越大（2 颗 → 40 万颗 → 1.4 万个集装箱），这颗豆子越来越"不见了"；信息图最擅长的"高亮一个数据点"在最拥挤的地方把它找回来。**从一双手，到你的手。**

## 一、对标：学什么 / 刻意不学什么

| 对标 | 学什么（语法） | 刻意不学 |
|---|---|---|
| 《纪念碑谷》(2014) | 等距投影本身的建筑美：纯色块、每个面固定三档明度、没有透视也没有描边；镜头在等距空间里平移、缩放，永远保持正等距；小人极简（圆头 + 锥形身体），靠姿势和比例表演 | 不做不可能几何、不用它的建筑造型、角色、配色和音乐；不做 90° 旋转解谜 |
| 《模拟城市 2000》式等距剖面 | 一块浮在空中的"沙盘"：土层侧面、海的剖面、一眼看到一个系统的全部；建筑可以被"切开"看内部 | 不做游戏 UI、像素贴图、网格地块的格子感 |
| Kurzgesagt 的科普叙事 | 开头一个问题 → 一路推进 → 每一步一个清楚的视觉比喻；数字大到读不懂时，换一种尺度让观众"看见"它；旁白少而准，画面先于解释 | 不用它的角色（鸟、细胞人）、配色、渐变光效和配乐风格 |
| Isotype（Otto Neurath / Gerd Arntz） | **重复图标 = 数量**：21 个太阳 = 21 天；70 颗豆子排成一只杯子；每个图标同样大小，数量靠个数读，不靠放大 | 不复刻 Arntz 的具体图标，全部自己画 |
| Powers of Ten（Eames, 1977） | 一镜到底的尺度跳跃：连续推进穿过几层尺度 | 不做宇宙/分子尺度，只在"船 → 集装箱 → 麻袋 → 豆"四层里推 |

**和本批相近风格的区别**：dataviz 讲的是真实数据曲线，lowpoly-island 是 3D 实景，pictogram-motion 的主角是象形人的动作，blueprint 是工程制图。本片是**等距 2D 信息图：一张供应链流程图活起来**，主角是"一颗被追踪的豆子"，数字和图标就是画面本身。

## 二、情绪弧

**一个主体**：一颗咖啡豆（被一个细墨虚线圈"追踪"着，像地图上的 *you are here*）。
**一个目标**：到达你的手里。
**一次转折**：在最拥挤、最匿名的地方（40 万颗一袋、320 袋一箱、1.4 万箱一船），全片静下来，画面除了它全部褪成灰，只有它还是彩色的：*Somewhere in here is yours.*

| 段落 | 情绪 | 画面密度 | 音乐密度 |
|---|---|---|---|
| 山坡清晨 | 宁静、亲手 | 稀，一棵树、一只手 | 一把吉他 + 卡林巴 |
| 晒床、麻袋 | 耐心、时间 | 中 | + 沙锤、邦戈 |
| 港口装船 | 越来越忙、机器接管 | 满，集装箱越堆越快 | + 贝斯、卡洪、康加，拍子越来越密 |
| 大海 | 辽阔 → 快进 | 大面积蓝 | 先抽空（呼吸），再全乐队十六分音符 |
| 钻进船舱 | 被淹没 | 一层比一层挤 | 每推一层抽掉一件乐器 |
| **找到它** | 静、温柔 | 只剩一颗彩色的豆 | **真静音** |
| 汽笛、城市、烘焙 | 苏醒、热 | 中 | 律动回来，噼啪声当打击乐 |
| 咖啡馆、磨豆 | 亲密、转化 | 聚焦一台机器 | 渐慢到停 |
| **倒咖啡** | 安静的早晨 | 一只手、一杯咖啡 | **真静音**后，一滴咖啡落进杯子，一把吉他 |
| 拉远全图 | 回望、完整 | 整张地图 | 吉他 + 每一站一个卡林巴音 |

**开场 3 秒**：大特写，一颗红果在枝头被两根手指捏住、一拧、落下，0.9 秒后落进摊开的手心，"嗒"。
**结尾回响**：同一个构图、同一个位置，手心里换成一杯咖啡，另一种肤色的手；标签从 **0 km** 变成 **11,000 km**。

## 三、原生招式（只有等距信息图能做到）

| 招式 | 片中怎么用 | 位置 |
|---|---|---|
| **一镜到底的等距沙盘** | 整个世界是**一块正方形的等距沙盘**（投影后正好约 16:9 的菱形）：山在最远的顶角，海是横穿中部的一条蓝带，城市在近处，咖啡馆在最近的底角。路线在沙盘上走一个 **Z 字**：顶角 → 右（向右下降）→ 横穿海面向左 → 向右下到底角。全片没有一个剪辑点，镜头只有平移、推、拉、跟 | 全片 |
| **剖面揭示** | 统一一个"刀线 → 外皮滑开 → 露出斜线剖面"的动作：果实被切开露出两颗种子；船体的近侧一片滑走，露出船舱里的集装箱；集装箱侧板滑走，露出麻袋；麻袋撕开，露出豆子；烘焙厂、咖啡机也这样打开。刀线是细墨虚线（信息图里的 cut line），剖面是奶油色加 45° 斜线 | 7.2 / 27.6–29.4 / 34.8 / 43.2 |
| **数字即图标（Isotype）** | 每一站一个标签和一个"用图标排出来的数字"，每一站的图标换一种排法：2 颗种子 / 21 个太阳排成 3×7 的日历（一个十六分音符亮一个，晒床的果子同步变深）/ 麻袋图标堆成一垛 / **货轮本身就是集装箱的 Isotype 图** / 18 个日夜图标 / 温度计升到 220 °C / **70 颗豆子飞过去排成一只杯子的轮廓** / 路线虚线：每一段虚线 = 100 km | 每一站 |
| **高亮一个数据点**（情绪最高点） | 推到豆子层，整袋豆子褪成灰，只有"你的那一颗"保留颜色，外面画出一个追踪圈。这就是信息图的 *focus + context*，也是引擎的"唯一彩色"口子 | 30.0–32.4 |
| **画中画放大镜** | 信息图的 detail callout：从地图上一个点拉出一根引线，末端长出一个圆形放大镜，里面是同一个世界的特写。地图（系统）和特写（个体）同时在画面里 | 8.4 / 40.2 |
| **拉远 = 全图** | 结尾从杯子一路拉远到整块沙盘，路线虚线从山坡一站一站亮到杯子，所有标签同时在场：片子最后一帧就是一张完整的信息图海报 | 50.7–53.7 |

**转场语法（统一）**：**线先走，画面跟上**。镜头换站永远由地图上的路线虚线领路（虚线先画出去，镜头再跟过去）；放大镜由引线拉出来；剖面由刀线切开。没有淡入淡出，没有硬切，没有空白帧。

## 四、主体与角色

- **豆子**：果实阶段是咖啡红 `#B3352B` 的小球（顶亮/左中/右暗三档 + 一个小高光）；生豆是灰绿 `#A9B27C` 的椭圆，中间一道 S 形沟；烘焙后是深棕 `#6A3B22`。**追踪圈**：细墨 `#2E2522` 虚线圆，缓慢转动，旁边一个小标签（开场是 "0 km"，结尾是 "11,000 km"）。
- **人物**（纪念碑谷式极简，原创）：圆头、锥形身体、没有五官，靠帽子和姿势认人。
  - 采豆人：宽檐草帽（奶油）、咖啡红上衣、腰间竹篮；开场只露出她的手（暖棕肤色）。
  - 晒床工人、卡车司机、吊车、码头工人：小尺寸群像，只做循环动作。
  - 咖啡师：奶油围裙、海蓝上衣。
  - 你：窗边座位的一只手（浅肤色），和开场的手同一个构图。
- 没有对白角色，只有旁白。

## 九、视觉规格

- **投影**：正等距（轴与水平线 30°），`sx = (x − y)·cos30°`，`sy = (x + y)·sin30° − z`。全片不做透视、不转动画面。
- **明度三档**：每个面按法线取色：顶面最亮、左面（+y 面）中、右面（+x 面）最暗。色板（中间档 / 顶 / 暗）：
  - 咖啡红 `#B3352B` / `#CF5140` / `#8C2620`
  - 叶绿 `#5E8C4A` / `#7BA75F` / `#476F37`
  - 海蓝 `#3C7FB1` / `#5A9BCB` / `#2D6390`
  - 奶油 `#F2E6D0`（背景）/ `#FBF4E6` / `#D9C8A9`
  - 土棕（沙盘侧面分层）`#9A6B45` / `#7C5234` / `#5E3C25`；石灰 `#B8B2A6`；集装箱加一个芥黄 `#D9A53A`
  - 墨色（线、字）`#2E2522`
- **没有描边**：形状全靠三档明度分开；只有信息图元素（引线、刀线、追踪圈、路线虚线、标签）用 2 px 墨线。
- **沙盘**：浮在奶油色背景上的一块厚板，前两个侧面露出土层（三条深浅不同的土）和海的剖面（三层蓝，越深越暗）；板下一个很淡的投影。背景有极淡的等距点阵。
- **前景视差**：几朵扁平的等距白云在沙盘上方漂，平移时比地面快（假视差），给 2D 一个"摄影机"。
- **标签**：圆点（2 px 墨线圈 + 奶油填充）→ 竖引线 → 横线 → 字。标题字 Jost 600 全大写、字距 0.12em；数字 Jost 300 大号；Isotype 图标同尺寸排成行或网格。字后有一圈奶油色描边，压在任何颜色上都读得清。
- **Isotype 图标**：全部是同一套等距小图形（太阳、麻袋、集装箱、日夜、豆子），和地图里的物件同一种三档明度画法。
- **片名**：等距立体字（Jost 700 挤出成块，顶面奶油、侧面咖啡红两档），立在山顶上方的奶油色天空里。

## 十、与风格说明的差异及理由

1. **烘焙挪到海运之后**：风格说明的顺序是"晾晒、烘焙、装船"。真实的咖啡是**生豆**漂洋过海，在消费国烘焙（生豆耐存放，烘好的豆子几周就不新鲜）。Kurzgesagt 式的科普片数字和顺序要站得住，所以改成：采摘 → 晾晒 → 装袋 → 卡车 → 装船 → 海运 → 卸船 → 烘焙 → 咖啡馆 → 磨豆 → 萃取。
2. **时长约 57 秒**（参考 35–45）：10 站的旅程，每站要有"一个动作 + 一个标签 + 一组图标"才读得懂（每站 2.4–4.8 秒），再加两处静音、结尾拉远和片尾卡。压到 45 秒就得砍掉两站或让标签一闪而过。制作中如果某段读起来有余量，优先砍盘山路（C6）和送货自行车（C14）。
3. **路线做成一块正方形沙盘上的 Z 字**，而不是一条直的长卷：直长卷拉远后是一根细斜条，画面大半是空的；正方形沙盘在等距投影下正好约 16:9，结尾拉远时整张信息图填满画面，而且一路上镜头有三个不同的平移方向。
4. **"海"用快进 + 日夜图标**，不做"比例尺断开"的折叠：折叠在一镜到底的世界里会破坏空间的连续性。
5. **增加了"钻进船舱找豆子"**：风格说明的情绪弧是"宁静 → 繁忙 → 安静"，我在繁忙的最高点加了一个转折（被淹没 → 被找到），让"一颗豆子"真的成为主角，也让"高亮一个数据点"这个信息图招式落在情绪最高点。

## 十一、字幕与片名设计

## 十二、技术方案

- **纯 Canvas 2D**。`demo/engine.js` 是等距引擎：投影与相机（中心 + 对数缩放）、按法线取三档明度、画家算法排序；基础体（盒子、任意多边形挤出、圆柱/锥、球、坡面、屋顶）、面上贴图（窗、集装箱棱纹）、极简人物；信息图层（标签钉、引线、放大镜画中画、刀线剖面、追踪圈、路线虚线、Isotype 图标阵列、等距立体字）；**"唯一彩色"**：整帧褪灰，指定元素保留原色。**任意形状**：给一条 2D 路径就能挤出成等距实体并按三档明度着色（例如 `#D97757` 的四角光点带一截光标尾巴）。
- `demo/world.js` 布置沙盘（地形、梯田、晒床、道路、港口、海、城市、烘焙厂、咖啡馆），`demo/film.js` 写时间线、相机路径和每站的动作；场景只调用引擎。
- `demo/timeline.js` 是速度网格和卡点的唯一来源，画面、配乐、混音、自检共用。
- 拟音 `mix.py` 全部按材质程序化合成（`core/audio/sfx.py` 起步）；配乐 `music/score.py` 用 `core/audio/sampler.py` 的采样乐器。
- 人物 12fps 步进，镜头与水面每帧平滑；颗粒 0。

## 十四、制作阶段修订（关卡 1 意见落实后，以成片为准）

| 项 | 方案原稿 | 成片 | 理由 |
|---|---|---|---|
| 港口帧船头压到陆地 | 船中心 (182,22)，码头边 y=12 | 码头边改 y=16，船中心 (194,25)，船头离岸留出约 17 格水面；离港先平移离开码头再转向 | 意见 1：船要完全在水里；原转向会让船尾扫进吊车 |
| 里程数字 | 卡车 400 + 海运 9,800 = 10,200 ≠ 11,000 | **卡车 400 + 海运 10,500 + 市内卡车 100 = 11,000 km**；全图多了一个 "TRUCK 100 km" 标签；图例里的 11 格里程条按三段比例上色（第 1 格 40% 黄，末格 10% 黄） | 意见 2：数字要能加起来 |
| 城市太密 | 满城楼块 | 公园比例 16% → 24%，楼高压低，站点周边半数楼块拿掉；烘焙厂（砖红）和咖啡馆（红白遮阳棚）各加一圈奶油色底板 + 墨色虚线框 | 意见 3 |
| 两个手部大特写 | 未画 | `hero.js` 扁平切面手：同一个 palm() 姿势、同一个相机偏移（相机在手心上方 0.17 单位）、同一个标签几何（"0 km" / "11,000 km" 同一像素位置）；先单独渲 `?test=hero` 自审，再进片（`demo/stills/frame_v2_hands.jpg`） | 意见 4 |
| 三层剖面节奏 | 每层 0.6–0.8 s | 第一层（船体 → 集装箱）0.9 s，第二层（集装箱 → 麻袋）0.6 s，第三层（麻袋 → 豆子）0.6 s，缩放 13 → 60 → 420 → 3,200，形成"坠落"加速；每推一层配乐抽掉一件乐器 + 低通收紧 | 意见 5 |
| 静音 1 | 1 小节（30.0–32.4） | **1.5 小节（30.0–33.6）**，汽笛移到 33.6，之后所有时间点后移 1.2 s；总长 58.8 s | L5 需要 2.0 s 语音 + 0.6 s 停留，并在台词后留出约 0.7 s 纯静音，汽笛才有分量 |
| 旁白时间 | L1 2.8 / L2 8.1 / L3 12.3 | L1 2.55 / L2 8.4 / L3 12.9 / L4 23.4 / L5 30.9 / L6 49.9；片名移到 5.4–8.1 | 每句停留 ≥ 语音 + 0.6 s，且不与片名重叠 |
| 片名 | 立在天空的立体字 | 奶油色底板平放在地面平面上，四个词按八分音符挤出成块（屏幕空间的独立等距变换，不跟随世界相机） | 拉镜中途世界相机的缩放在 330 左右，把字放进世界坐标会看不到 |
| 豆子层 | 世界坐标里的豆子 | 屏幕空间的豆子堆，锚定在被追踪的那颗豆上、按 k 缩放；船在豆子充满画面时从海中间瞬移到目的港 | 船的朝向变化不影响豆子排布，时间跳跃不可见 |
| 倒咖啡 | 近景 | 静音 2 期间镜头停在出水口和杯子（k≈340），一滴咖啡在出水口慢慢鼓起，45.9 落下 | 静音需要一个"等"的画面 |
| 顾客 | 窗边座位 | 站在吧台前，杯子沿吧台滑过去 | 画面更紧凑，杯子一路在镜头里 |
| 路线虚线 | 每一段虚线 = 100 km | 虚线只表示路线，图例改为 11 格 Isotype 里程条（1 格 = 1,000 km，按陆 / 海 / 陆比例上色）+ NOT TO SCALE | 海段距离占 95%，按距离画虚线会让陆段几乎没有虚线 |
