# Mid-century Cartoon · 导演方案（Treatment）

**片名** *Meet Pip*（认识一下 Pip）
**场景** 产品上手指南：*Your New Robot Vacuum · Set Up in 3 Steps*（虚构产品 Pip 扫地机器人）。放在产品页、包装盒二维码、帮助中心。
**时长** 40.0 s（22 小节 @132 BPM；场景 36.4 s + 结尾卡 3.6 s）｜ **画幅** 1920×1080 ｜ **帧率** 24 fps 输出；角色、道具按 12 fps on twos，机位、转场、线色错位的抖动永远 24 fps 平滑。
**一句话** 1950 年代教育片口吻的说明书动画：一个盒子像舞台幕布一样打开，"Meet Pip." 三个步骤各用一个圆形字章开场、一个关键手部动作收尾；按下开始后，Pip 的清扫路径在俯视平面图上画成一整张 50 年代的圈点花布，花布最后变成落版海报的底边。
**看完能说出** "我能拿这个做任何小家电 / 小工具的上手指南：三到五步，每步一个动作，一张能截图的总结页。"

## 一、对标：学什么 / 刻意不学什么

| 对标 | 学什么（语法） | 刻意不学 |
|---|---|---|
| **UPA 工作室 50 年代有限动画**（*Gerald McBoing-Boing* 1950、*Rooty Toot Toot* 1951、*The Tell-Tale Heart* 1953） | ① 线和色是两张赛璐珞，色块故意错位几像素；② 背景只是抽象色块、一条不闭合的地平线，不画完整房间；③ 身体不动，只动手、嘴、眼睛（有限动画），一个姿势到下一个姿势用 1–2 张中间画"跳"过去；④ 场景切换靠整片背景色换掉 | 不用任何原作角色造型、剪影、配色组合、片头字体；不做原作的"声音当画面"梗 |
| **Coronet / Encyclopaedia Britannica 50 年代教育短片** | 温和权威的旁白腔（"Meet ___."）、每一步一张字卡、一句旁白对一个画面、结尾一张总结卡 | 不用任何片头标识、真实机构名；不模仿老胶片划痕 |
| **Charley Harper、Mary Blair** 的配色与造型 | 原子时代的柔和对比色（芥末黄、珊瑚、土耳其蓝、牛油果绿、灰蓝、淡粉）；几何化的人物与家具（回旋镖桌、肾形沙发、星芒植物） | 不照搬任何一幅画、任何动物造型 |
| **50 年代印刷说明书 / 家电广告**（语法） | 编号圆章、弯曲的指示箭头、局部放大圆框、光芒放射背景 | 不出现任何品牌、商标、真实产品外形 |

### 和库内风格的区别
| 容易撞的 | 它是什么 | 本片怎么不一样 |
|---|---|---|
| **rubber-hose**（30 年代橡皮管卡通） | 黑白、满屏弹跳、每个物体都在跳舞、热爵士大乐队 | 本片是 **50 年代彩色扁平 + 有限动画**：身体静止，只动手和道具；线色分离错位；颜色是原子时代柔和对比色；配乐是冷爵士小乐队（颤音琴 + 长笛 + 刷子鼓），不是 ragtime / 热爵士 |
| **scifi-toon**（科幻情景卡通） | 粗描边沸腾线、对白喜剧、传送门 | 本片线条细而断续、不沸腾；没有对白喜剧，是旁白讲解"跟着做"；没有发光、没有科幻道具 |
| **whiteboard**（白板讲解） | 在白板上边讲边写、讲**原理** | 本片讲**操作步骤**（跟着做），一步一个动作；画面是印刷色块与纸感，不是书写过程 |
| **iso-infographic / dark-keynote / living-screencast** 等已有场景 | 咖啡产地旅程、产品发布会、Claude Code 教程 | 本片的场景是"新买的东西三步装好"（上手指南 / 快速入门），不是发布、不是流程图、不是软件录屏 |

## 三、原生招式

1. **线色错位（贯穿）**：每个形状 = 墨线层 + 色块层，色块层整体偏移约 (6, 4) px，并在 on twos 的每一张画上重新抖 ±1.6 px；墨线有粗细呼吸和故意的断笔，永远不完全闭合。文字也是两版套印（墨版 + 色版错位）。
2. **有限动画**：June 的身体是一张"held drawing"，只有手臂、手、眼、嘴、道具在动；姿势之间只给 1–2 张中间画，12 fps 步进。机位和光一直 24 fps 平滑——这个"画面在跳、镜头在滑"的反差就是 50 年代的味道。
3. **抽象背景**：没有完整房间。每一步只有一整块底色 + 一条不闭合的地平线 + 一两个道具（插座、墙脚线）。场景切换 = 底色整片换掉。
4. **会动的说明书箭头**：弯曲墨线箭杆自己画出来，实心箭头按拍子"点头"（回拉 18%），虚线箭杆的点会顺着方向走。
5. **高点：路径即花布**（签名镜头）：Pip 用"螺旋清扫"模式走过整个平面图，路径是一条拉长的次摆线（prolate trochoid），每走一个圈，圈心"啵"地弹出一颗芥末黄圆点（吸走的灰尘）。拉远之后，整张平面图是一块 50 年代圈点印花布。这块布随后变成落版海报的底边——**打扫本身就是装饰**，只有这种"色块 + 墨线图案"的媒介能把功能画成纹样。

## 四、角色与道具（关卡 1 设定表：`demo/stills/modelsheet_v1.jpg`）

- **June（主人）**：几何化的 50 年代女性，约 600 px 高（s=1）。蛋形头 + UPA 式长尖鼻（打破轮廓）、深棕波波头外翻、芥末黄发带；珊瑚红 A 字摆连衣裙 + 白圆点 + 白色裙边条纹、白色小圆领、芥末黄腰带；两条细墨线腿、尖头平底鞋；手臂是细墨线，手是连指手套形。
  - 表情：平静 / 开心（眯眼张嘴）/ 惊讶（圆眼 O 嘴）/ 专注（眉头下压、舌尖）/ 心领神会（单眼眨）。
  - 关键姿势：TA-DA（双臂上举）、TAP（单手举手机、拇指点）、TIP!（食指竖起）。
  - 规则：身体不动，只动手臂；转面只有 正面 / 3/4 / 侧面 / 背面 四张。
- **Pip（产品）**：圆盘形扫地机，土耳其蓝顶盖 + 奶油色保险杠 + 一圈镀铬条；顶上一个奶油色电源键；前脸一颗珊瑚色"眼睛"状态灯；两只星号形边刷。侧视（3/4 俯角）和俯视两套画法；状态：灯灭 / 灯亮 / 按键按下。
- **充电座**：50 年代收音机式的奶油色梯形，土耳其蓝格栅，两片镀铬触点。
- **色板**：纸 `#F4EAD5` · 墨 `#2B2420` · 珊瑚 `#E4613F` · 芥末 `#E8B43A` · 土耳其蓝 `#3FA7A0` · 灰蓝 `#7F9CC0` · 牛油果 `#A7AE5B` · 淡粉 `#F0B4A8` · 李子紫 `#6E4A6B` · 发色 `#3A2621` · 肤色 `#F2C7A0`。
  - 同色叠加检查：Pip（蓝绿）不上土耳其蓝底；June（珊瑚）不上珊瑚 / 淡粉底；每步底色与主体至少差一个明度档。

| 6 | 贴士 | 中近景侧面 | **色块滑换**（淡粉整块从右滑进来盖住平面图）+ 轻微**上移**：June 用两根手指从画面上"揭起"一根线——这根线只是墨线层，被揭走后色块层留下一道淡影；"TIP"星芒章敲下 | 3.64 s | 呼吸段：慢一半，一个动作，一句话 |

关键时刻主体高度：开箱 Pip + 盒子 ≈ 1/3 画高、June ≈ 55%；第 3 步 Pip 顶盖 55%；落版主体（圆章行）≈ 1/3。

## 七、Cue map（音乐先行，画面卡这张表）

**配乐类型**：原创 50 年代西海岸冷爵士小乐队——颤音琴（主和弦 + 琶音）、长笛（旋律）、低音提琴拨弦（行走贝斯）、刷子鼓（军鼓一抹 + 叮叮镲）、钢片琴（点缀）。**132 BPM，F 大调 → 高点升到 G 大调**。
- 乐器：优先 `core/audio/sampler.py`（vibraphone、flute、upright/electric bass、drum_kit、celesta 视 INSTRUMENTS.md 为准），缺的用 numpy 合成（刷子 = 带通噪声包络，颤音琴震音 = 振幅 LFO）。

## 十一、技术方案

- 纯 Canvas2D，`window.render(t)` 确定性渲染。
- `demo/engine/toon.js`：风格引擎（线色错位 `reg()`、`shape()`、断笔墨线 `ink()`、两版套印文字 `text()`、星芒 / 光芒 / 原子 / 回旋镖 / 肾形、会动的说明书箭头 `arrow()`、自动换行缩字号 `fit()`、纸感收尾）。任意路径都能用这个风格画出来。
- `demo/engine/chars.js`：June 与 Pip 的画法（有限动画的姿势参数）；`demo/engine/icons.js`：图标库。
- `demo/film.js`：只调用引擎，时间线从 content.json + 配音时长生成，卡在 132 BPM 网格上。
- 起点代码：读过 `promo/opuscar98/sets/29/upa.js`（错位印刷 + 蜡笔颗粒 + 压力墨线的思路），在本目录重写并改为 12 fps 抖动错位、更细更断的线、更轻的颗粒；不 import、不复制电影内容。
- 配乐 fork 一个子 agent（Opus 5.5）按本 cue map 写；高点的颤音琴"每圈一个音"由 `events.json` 导出的圈时刻驱动。
- 渲染：整片走 `batch/tools/render_slot.mjs` 限流器，`--workers 2`。
