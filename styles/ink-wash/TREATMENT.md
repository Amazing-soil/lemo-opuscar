# Chinese Ink Wash · 导演方案（Treatment）

**片名** *The Swordsman and the River*（片内竖排英文题字 + 朱文印"水"）
**时长** 约 48 秒（风格说明建议 45 秒；多出的 3 秒全部给字幕阅读和出剑前的静默，理由见第八节）
**画幅** 1920×1080 ｜ **帧率** 24fps 输出；侠客按 12fps（on twos）步进，镜头、墨晕、水纹、飞溅每帧平滑
**一句话** 一个无名侠客踏水过江，江心巨浪拦路；他以剑为笔，在空中写下一个"水"字——最后一笔就是那一剑。江被劈开，他走过去；身后江水合拢，照旧东流。
**题眼** 李白"抽刀断水水更流"。剑能劈开水一瞬，不能让水停下。侠客过了江，向江行了一礼。整片最后收成一幅手卷，他只是画里很小的一笔。

## 一、对标：学什么 / 刻意不学什么

| 对标 | 学什么 | 刻意不学 |
|---|---|---|
| 上海美影《山水情》(1988) | ① 留白就是空间：江面、天、雾全是纸本色，不画；② 墨色五分（焦浓重淡清），远山淡、近石浓；③ 湿墨在纸上晕开的边缘（墨晕、水痕、边缘积墨）；④ 古琴主导的呼吸式节奏：长音、泛音、停顿比音符多；⑤ 人物"几笔成形"，靠衣纹的笔势表演 | 不用它的人物造型（老琴师与少年）、不用它的具体构图与鹰、不用它的琴曲旋律；不做它的慢，本片 48 秒要有一次爆发 |
| 《卧虎藏龙》竹林段 | ① 轻功的"失重感"：落点轻、腾空长、衣袂比身体慢半拍；② 静与动的对比：大动作之前完全静止；③ 横向跟拍 + 前景植物掠过带出速度 | 不做打斗对手戏，不用竹林（换成芦苇、江面），不做武打剪辑的快切，整片只有一个动作高潮 |
| 中国手卷（长卷）观看方式 | 手卷从右往左展开：开场镜头**自右向左横移**，像展卷；侠客也自右向左过江（逆着西方观众的阅读方向，本身带"逆流而行"的阻力感）；结尾拉远成整幅长卷，盖印题跋 | 不仿任何具体名画 |

## 三、角色

**无名侠客**（全片唯一角色）：斗笠、宽袖长袍、背一柄长剑、剑柄系一缕**朱红剑穗**。

- 写意造型"几笔成形"：斗笠 = 一笔侧锋浓墨；袍身 = 两三笔饱含水的淡墨大笔（湿，会晕）；衣纹、袖口、腰带 = 几笔干一点的重墨；腿 = 两笔细劲的焦墨线（奔跑时才露出来）；剑 = 一根极细的焦墨线。脸几乎藏在斗笠下，只在特写里露出眉眼（两三笔）。
- **朱红剑穗**是全片除印章外唯一的颜色。远景里侠客只有指甲盖大，这一点红让观众一眼找到他；片尾印章的朱红与它呼应。
- 表演靠笔势：静立时衣袂微动；腾空时袍摆拖成长长一笔；拔剑时袖子甩成一道弧。
- 关卡 1 交付：角色设定表 `demo/stills/modelsheet_v1.jpg`（四面转面、四个表情、四个关键姿势、墨色与朱红色板）。

## 七、声音设计与字幕设计

**拟音跟材质走**（纸、墨、水、丝、铁）：墨滴落纸（软、湿、短，高频少）；毛笔破空（带毛刷质感的气流，不是金属嗖声）；踏水（轻、水花小、带一点纸的"噗"）；拔剑（长而细的金属清鸣）；墨点溅落（许多极短的湿点）；盖印（木印压纸的闷响）。风和水始终很低，留足空间。

**字幕 = 题跋**：不用黑底条。Cormorant Garamond 斜体、焦墨色、字距略开，两行以内，**放在当前画面的留白处**（题跋本来就写在画的空处），每句左侧一枚小朱红方印作句首记号；出现与消失都是墨晕（从淡到浓 0.35 秒，消失时化开）。停留 ≥ 语音 + 0.6 秒且 ≥ 1.8 秒。

**片名**：竖排英文（Cormorant SC，逆时针旋转 90° 自上而下读），宽字距，下接朱文方印"水"（印文用代码画的篆意线条，不用字体）。

## 八、对风格说明的改动与理由

1. **时长 45 → 约 48 秒**：五句旁白每句要 ≥ 语音 + 0.6 秒，出剑前的静默要足 1.8 秒，还要给结尾长卷留回响。按"节奏以观众为准"的原则多给 3 秒，不砍停留。
2. **"出剑前全静音"细化为两段静默**：浪起硬切后 0.8 秒静音（观众被突然抽空），拔剑写字时只有泛音，最后一笔前再给 1.8 秒绝对静音。高潮落在第二段静默之后。
3. **阻碍选"巨浪"**：对手就是江本身，和题眼（剑斩不断水）是一回事；不引入第二个角色。
4. **"一笔飞白横贯画面"与"写水字"合成一招**：飞白就是"水"字的最后一笔，字与剑、书法与武功在同一个动作里完成。
5. **加了朱红剑穗**：远景可辨认 + 与结尾印章呼应。
6. **自右向左的运动方向**：手卷的展开方向；也给"过江"一点逆行的阻力。

## 九、关卡 1 之后的改动（按批准意见）

1. **"水"字**：改用 OFL 楷书字体 Ma Shan Zheng 的"水"作骨架——在字形上按笔顺描出四笔中线（竖钩、横撇、撇、捺），笔压取字形粗细，加 45° 藏锋起笔、撇与钩出锋；笔触引擎用 `solid` 模式逐笔写出。试过用字形轮廓裁边，交叉处出现缺口，最终只把字体当骨架。
2. **侠客少笔**：脸几乎一直藏在斗笠下；静默段的大特写改成"只见笠檐、须与下颌、一滴水"，不画眼睛；唯一一次露出眉眼是抱拳时的中景（两弯笑眼）。
3. **腾空重做**：身体前倾约 30°，一膝收起、一腿后拖，袍被风拉成一大块淡墨（背面浓边），双袖后扬；每次点水一个墨圈，三圈错开扩散约 2.4 秒。
4. **动作稳定**：笔毫断点与宽度噪声按"归一化弧长 × 固定参考长度"计算，种子按笔固定；只保留 5 张一循环的微小边缘抖动。
5. **断流**：飞白扫完（4 帧）后浪才裂开——上半沿切口向上翻卷、化开，下半向下塌落、压扁；两道裂口各一排含墨浪头向外翻卷，加淡墨大块；墨点顺剑势向右飞溅、落纸留痕；中间露出纸白。
6. **过江段的江底白路**：两侧水墙改为宋人水图式的平行波纹线（近路浓密、远处疏淡）+ 路沿小漩；身后按合拢前沿用横向渐变抹掉，江面只剩涟漪。
7. **配乐**：古琴 pluck.py guqin + 采样长笛低八度作箫 + gran_cassa / timpani，由 fork 子 agent 按本方案的 cue map 写成，卡点实测误差 ≤ 1 帧。
