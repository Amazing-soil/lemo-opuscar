## 2. 一句话故事与情绪弧

**你的手机不是在看地图，而是在"听天上的钟"。相对论让那些钟每天快 38 微秒——不修正，你的位置一天漂 11 公里；所以工程师在发射前就把钟调慢了。**

主体 = 那枚橙色的"你在这里"图钉磁铁。目标 = 被找到、并待在对的位置。
好奇（你在这里）→ 理解（延迟 = 距离，三个圆交于一点，图钉"啪"地落下）→ **转折（静音："But, there's a catch."）** → 紧张（两个钟、两支笔的二重奏渐渐错拍）→ 笑点（图钉一天一格地溜出手机，周日掉进海里，鱼冒出一个问号）→ 解决（板擦倒带把图钉拉回家；轨道钟被擦掉重画，两层音乐"咔"地对齐）→ **回响（全板拉远：整堂课挂在墙上，笔一支支落回笔槽；片名旁补写署名）**

## 3. 原生招式（只有白板能做到的）

1. **单线字体一笔一画写出**：用 EMS Tech（Architects Daughter 的单线版，OFL），每个字母按真实书写顺序出现，而不是遮罩擦出来。
2. **一块板、一镜到底**：片头的图钉、片名、卫星、公式、时钟、大海都在同一块 8000×4500 的板上，镜头只在板上移动；片尾拉远一次揭示全部。
3. **板擦 = 时间倒流**（情绪最高点之后）：板擦沿着漂移轨迹倒着擦回去，图钉被拖回手机，配乐是漂移进行曲**倒放 + 3.5 倍速**的磁带回卷声。
4. **两支笔的二重奏 = 两个钟**：黑笔按地面钟的拍子画刻度，橙笔按轨道钟（快 7.3%）的拍子画刻度，画面与两层马林巴同时错位。
5. **磁铁是板上唯一的"实物"**：图钉磁铁有高光、有投影，能被拿走、落下、滑动，这是白板上唯一能合法"动"的东西，所以漂移、落水、倒带都交给它。
6. **擦不干净的鬼影**：擦掉的笔迹留 10% 残影；板上还散落着"上几节课"没擦净的痕迹（f(x)、lab 3、TUE……）。

## 6. 声音设计表

| 段落 | 环境底 | 主要拟音 | 音乐状态 |
|---|---|---|---|
| 片头 0–10 | 房间底噪 + 挂钟每秒一响 | 笔帽、磁铁落在钢板上（金属共鸣 + 板体闷响）、马克笔摩擦 | 无 → 弱起 |
| 片名 | 被音乐盖住 | 大字母的长笔画 | 全奏 |
| 卫星 / 公式 | 同上 | 虚线"嗒嗒嗒"、写字的沙沙声、偶发的白板笔"吱" | 让位人声（-9 dB） |
| 三圆定位 | 同上 | 长弧线摩擦；磁铁拿走（抽离）与落下（大） | 稀疏 → 全奏落点 |
| **静音** | 只有房间 + 挂钟 | — | 0 |
| 相对论 | 同上 | 两支笔同时画刻度（左右声像分开） | 相位漂移 |
| 漂移 / 落水 | 同上 | 虚线轨迹、落水、气泡 | 进行曲 → 停 |
| 倒带 | — | 板擦快速摩擦（9 Hz 抖动） | 倒放进行曲 |
| 校准 | 同上 | 板擦擦尺、橙笔八分音符刻度 | 对齐 |
| 片尾 | 挂钟回来 | 三次落槽、笔帽扣上 | 终曲 → 尾音 |

- **每一笔都有自己的声音**：拟音由引擎导出的 999 个事件生成，摩擦声的包络就是引擎里"慢起—快中—慢收"的手速曲线；声像跟笔画在画面里的横向位置；镜头越近越响。
- **两处真正的静音**：43.6–46.4（只剩挂钟），85.0 落水之后（音乐停，只剩气泡）。
- **声音转场**：J-cut——"to ticking clocks" 下面已经响起四下木鱼，进入片名；L-cut——落点和弦的余音盖住推近镜头进入静音；倒带声把落水段拉回手机。

## 7. 字幕设计

白色圆角标签（90% 不透明、轻投影）+ 左下一小段橙色马克笔划线，字体 Architects Daughter（与板上手写同源的 OFL 字体）。按从句拆句，单行 ≤ 44 字符，短从句并入上一句；超过 1250 px 自动折成两行。字幕在画面底部 60 px 以内，所有镜头都给底部留了空。
