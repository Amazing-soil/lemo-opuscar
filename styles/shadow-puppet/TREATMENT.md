> 2D ｜ 目标时长 ~54 s（说明里建议 50 s，理由见第 9 节）｜ 1920×1080 · 24 fps ｜ 旁白 Kokoro `am_michael`（说书人）｜ grain 2

## 1. 一句话故事

**十盏油灯烧成了十个太阳；弓箭手后羿每射落一个，幕后就熄一盏灯——直到只剩最后一盏，而那一盏，正是照亮这出戏的灯。**

核心构思：**太阳 = 幕后的油灯**。开场只点亮一盏灯（戏开演），旁白一说"十个太阳"，幕后又接连亮起九盏，幕布亮到发白、过曝、颜色被烧褪；每射落一个太阳就熄一盏，画面暗一档、颜色一档档回到正常的暖金色。最后留下的那个太阳，就是开场第一盏灯。结尾绕到幕后，观众亲眼看见"太阳"原来就是一盏油灯——故事的结局（只需要一个太阳）和媒介的真相（皮影戏只需要一盏灯）在同一个镜头里合上。

情绪弧：
- 角色：后羿（唯一角色）。
- 目标：射落烤焦大地的太阳。
- 转折：第十支箭已经搭上，他停手了——留下一个太阳。
- 回响：1 盏灯 → 10 盏 → 1 盏；开场醒木 ↔ 结尾醒木；开场片名皮影牌 ↔ 结尾片尾皮影牌。

## 3. 原生招式（只有皮影能做）

| 招式 | 在片中的位置 | 为什么只有皮影能做 |
|---|---|---|
| **① 绕到幕后：太阳原来是一盏油灯**（主招式，放在情绪最高点之后的回响处） | 43–50 s | 皮影戏的"舞台"是一块被灯照亮的布。镜头横移，舞台立柱在前景一闪而过（遮挡转场），出来已在幕后：幕布从背面发光，艺人的手（剪影）捏着三根操纵杆把后羿按在布上，面前只剩一盏点着的油灯，身旁九盏刚熄的灯还冒着细烟。故事的"太阳"和戏的"光源"在同一画面里对上。 |
| **② 光就是剧情：一箭一灯，画面暗一档** | 27–34 s | 皮影的画面亮度直接由幕后油灯决定。十盏灯时画面过曝发白、驴皮颜色被烧褪（热、刺眼）；每熄一盏，整块幕布的曝光和色温都实打实地降一档，最后一盏时颜色最饱满——"救世"在画面上就是"曝光恢复正常"。连射段用**固定机位全景**让观众看清这 9 档台阶。 |
| **③ 离布即虚：影子离开幕布就变大、变虚** | 太阳登场 / 太阳坠落 / 片名牌退场 | 真实皮影里，影人离开幕布靠近灯，影子会放大并虚化。太阳从"巨大模糊的光团"压到布上变清晰 = 登场；被射中后，里面的三足金乌（神话里太阳就是乌鸦）跌落并离开幕布，越掉越大越虚，化进光里 = 死亡。 |
| **④ 透光的彩色驴皮 + 镂空** | 全片 | 颜色是"透过"来的：重叠的两片皮更暗；镂空处漏出最亮的光；英雄是"空脸"（脸部镂空，只剩眉眼鼻口的细皮线）。 |

## 4. 视觉语言

- **幕布**：米白棉布，细密经纬纹 + 大尺度的疏密不匀 + 边缘被木框压暗。只有背后的灯把它照亮。
- **渲染模型**（WebGL2 合成）：`画面 = 色调映射( 灯光场(x,y) × 驴皮透射率(x,y) × 布纹 )`。
  - 灯光场 = 每盏灯一个宽光斑（σ≈650 px）+ 太阳位置一个窄核（σ≈110 px），各自独立闪烁；十盏灯时总亮度约为一盏的 4–5 倍 → 高光溢出、颜色褪成橙白。
  - 透射率画在 2D 画布上：底色白，影人各片以 `multiply` 叠上去——**重叠处自然更暗**，镂空处是白（全透）。
  - 辉光（亮部金字塔模糊）、热浪扭曲（十日段）、暗角、灯焰闪烁都在着色器里。
- **驴皮色（透射色）**：朱红 `#c3261a`（后羿铠甲）、焰橙 `#e0561c`、姜黄 `#e6a91e`、石绿 `#2b7b3f`、靛青 `#2a6c86`（河）、本色皮 `#e7c68c`、墨 `#1a100a`（轮廓线、头发、靴）。
- **灯光色**：一盏灯 = 暖金 `#ffdca0`；十盏 = 近白 `#fff6d8`（过曝）。
- **影人结构**：后羿 11 片 + 道具（弓、箭、箭壶），铆钉可见（深色小圈 + 浅色线结），三根操纵杆（颈杆 1、手杆 2）以离布的虚影出现。
- **镂空纹样库**：鱼鳞甲、云头卷、回纹边、联珠、梅花、水波、火焰——都是代码生成的通用纹样，不复刻任何具体传统影人。
- **舞台**：开场和结尾能看到红黑漆木框、雕花横楣、两根立柱、前排几个小观众的后脑剪影。
- **幕后**：深褐暗场，唯一光源是一盏油灯；幕布从背面发光；艺人的手和袖子是剪影带暖色轮廓光；九盏熄灭的灯冒细烟。

## 5. 动作语言

- **皮影是现场表演，不是定格** → 影人动作走 24 fps 连续（不做 on twos），加上**手持的微颤**（2–3 px 低频噪声）和**油灯闪烁**，这两样才是皮影的"活气"。
- 主杆带动身体平移，**腿不受控、靠惯性像钟摆一样甩**（预模拟的摆锤），翎子（两根雉尾）同样是弹簧链。
- 动作语汇：碎步急上 → 一个小跳 → **亮相**（大锣一锤，全身定住 0.6 s，只有翎子还在颤）→ 转头望日 → 开弓（慢、弓身逐渐弯）→ 放箭（快，一帧到位）→ 收弓低头。
- 火焰 = 三块镂空火焰皮片 12 fps 轮换抖动（皮影做火的土办法）。
- 太阳：缓慢自转 + 上下浮动；被射中时光芒散片、金乌翻滚坠落并离布虚化。

## 8. 声音设计（拟音跟材质走：布、皮、竹、木、火）

- **醒木**：硬木拍桌（短促瞬态 + 1.1 kHz/2.3 kHz 木共鸣 + 小房间反射）。
- **火柴 / 灯芯**：擦划噪声 + 火苗"呼"地燃起；全片底层有轻微灯芯噼啪。
- **影人**：竹杆碰布的"嗒"、驴皮片翻动的干脆"啪"（高频短噪声）、影人贴上幕布的轻响。
- **弓箭**：竹木弓身吱呀（creak）、弦震"嗡"、箭啸（带通扫频 whoosh）。
- **太阳坠落**：锣击 + 金乌扑翅（一次） + 灯芯被捏灭的"噗—嘶"。
- **焦土**：低频热嗡、木头爆裂噼啪。**回春**：细水流声。
- **幕后**：室内底噪、竹杆轻碰、艺人一声很轻的呼吸。

## 9. 字幕设计

"说书人的题板"：一块窄长的黑漆木牌（深褐 `#1e0e09`，内勾一圈细金线 `#a8813f`），左端一枚朱红小方印（马善政体"说"），英文字幕用 Cormorant Garamond SemiBold 46 px、米色 `#f3e2bf`；牌子居中贴底 64 px。出现时 0.2 s 从下方滑上并伴一声极轻的木板"嗒"，消失时淡出。片名/片尾是**镂空字的皮影牌**（字是透光的洞）。字幕每句停留 ≥ 语音 + 0.8 s 且 ≥ 1.8 s；相邻两句之间留 ≥ 0.3 s 空白。

## 10. 与风格说明的差异及理由

1. **时长 ~54 s（说明写 50 s）**：静场（S8，2.4 s 完全无乐）和幕后揭示（S11，6 s）是本片的两个情绪支点，压掉任何一个都会伤害结构；字幕停留按观众阅读时间留足。仍在 30–60 s 规格内。
2. **"太阳 = 幕后的灯"**：说明是"射一个太阳，幕后熄一盏灯"，我把它推进一步——开场只点一盏灯，旁白一说"十个太阳"再亮九盏，最后留下的那一个就是开场第一盏。这样幕后揭示不是附加彩蛋，而是故事的答案。
3. **动作不做 on twos**：皮影是现场操纵的，连续运动 + 手颤 + 灯闪才是它的质感；只有火焰皮片用 12 fps 轮换（这是皮影里真实的做法）。
4. **"表情"改为"头部姿态 + 身段"**：传统皮影的头茬是刻死的，不会变表情。设定表里用 4 种头部角度/身段（平视、仰望、低头、亮相）代替表情。
5. **金乌**：太阳被射中后跌落的是一只三足乌（后羿神话中太阳的本体），让"射落太阳"有一个可见的、非血腥的结果。
