# Glass Product Render · 导演方案（Treatment）

**片名** *Aura — Hear the Light*（片内标题卡：AURA ／ A GLASS PRODUCT FILM）
**时长** 32 秒（30 s 正片 + 片尾卡多留 2 s 阅读时间）｜ **画幅** 1920×1080 ｜ **帧率** 24fps，全部运动逐帧平滑（产品片不做步进）
**产品** 虚构真无线耳机 **Aura**：无柄、透镜形的"玻璃鹅卵石"耳机 + 鹅卵石形旋盖玻璃充电盒。品牌、造型、名字全部原创。
**一句话** 一只在黑暗里只会反射别人光线的玻璃耳机，被拆成零件、再在低音落下的一瞬合拢——从此它自己发光：声音变成沿玻璃内部流动的光。
**主题** 透明 = 没有秘密；声音 = 光。

## 一、对标：学什么 / 刻意不学什么

| 对标 | 学什么（语法） | 刻意不学 |
|---|---|---|
| Nothing Ear 透明耳机广告 | "透明结构之美"：把内部元件当装饰展示；零件爆炸视图的工业美感；黑白 + 一个强调色 | 不用柄式耳机造型、不用点阵字体、不用红色点缀、不出现任何可辨认的外形/图案 |
| Apple 产品发布片 | 黑场里一道光扫勾出轮廓；慢速环绕；微距拉焦；每个剪辑点卡在拍点上；极简字体排版（超细字重、宽字距、一个名字 + 一句 slogan）；零件悬浮 → 合拢的节奏 | 不用任何 Apple 字体、音效、旋律、配色模板；不做"白底"（本片是黑场暗场布光）；不抄具体镜头 |
| 玻璃摄影的"暗场布光"（dark-field） | 黑背景 + 两侧/背后条形灯 → 玻璃只剩一圈白色轮廓，厚玻璃边缘出彩虹 | — |

**改动说明（相对派单建议）**
1. **HDRI → 自建灯条环境**：影棚 HDRI（photo_studio_loft_hall）里有窗户和杂物，在玻璃上反射成乱纹。玻璃产品摄影的核心是"可控的条形反光"，所以环境贴图改为每帧由一个"灯条场景"（黑屋 + 5 根柔光条）现场烘出。这样**光扫就是真的有一根灯条从镜头背后划过**：玻璃上的反光带、折射、色散全部物理地跟着走，而不是 2D 贴一条高光。
2. **合拢放在 drop 上，但不切走**：爆炸镜头延长到 17.0 s，让观众在同一个机位里看到"零件冲回 → 16.0 合拢 → 光纹第一次亮起"，再切正面。卡点 + 因果都在一个画面里。
3. **结尾加了一个"回响"**：开场它被外部光扫照亮；结尾同一道光扫再划过时，它已经在自己发光。两只耳机落回托槽（28.0 磁吸 click），盒底的磨砂玻璃像充电一样从内部透出柔光。

## 二、原生招式（只有"玻璃 + 渲染"能做到的）

| 招式 | 放在哪里 | 怎么做 |
|---|---|---|
| **暗场光扫** | 开场两道、微距段每拍一道、结尾一道 | 灯条在镜头背后的弧上划过，PMREM 每帧重烘；玻璃上的高光带与片名字面上的高光同步 |
| **透射 + 透镜放大** | 微距段 | 正面玻璃穹顶是厚透镜（transmission 1、thickness 4.5、IOR 1.52），里面的驱动振膜波纹被放大、弯曲 |
| **色散彩虹边** | 所有厚玻璃边缘 | three.js MeshPhysicalMaterial `dispersion`（r170 原生支持），数值 5 |
| **慢动作爆炸视图 → 合拢**（情绪最高点） | 12.0–16.0 | 10 个零件沿耳机轴展开、各自悬浮自转；15.0 悬停；15.5 音乐全静；15.75 零件被"吸回"（加速），**16.0 合拢 = 808 低频 drop = 光纹第一次点亮** |
| **声音 = 光** | 16.0–24.0 | 每个 kick 在导光圈上发出两束光，反向绕圈；螺旋导光槽里一束光从中心冲到边缘；地面上玻璃投下的焦散随 kick 外扩成彩色声波环 |
| **焦散** | 声音可视化段 | 地面着色器：透镜环形焦散（RGB 三通道半径错开 = 色散）+ 自写 Voronoi 焦散丝网 |

## 三、情绪弧

**被照亮（黑暗、安静、冷）→ 被打开（好奇）→ 被看透（亲密、微距）→ 被拆开（悬停、屏息、全静）→ 合拢点亮（爆发）→ 自己发光（律动、自信）→ 回到盒子（安放、余韵）**

一个主体（右耳机）、一个目标（发出自己的光 / 声音）、一次转折（拆开后在 drop 上合拢）。
开场 3 秒内的钩子：纯黑里第一道光扫划过，只露出一圈带彩虹边的玻璃轮廓。
结尾回响：同一道光扫、同一个名字，但这次物体自己在发光。

## 五、配乐 cue map（原创，极简电子；120 BPM，F 小调）

| cue | 时间 | 小节 | 配器 | 情绪 | 卡点 |
|---|---|---|---|---|---|
| A 黑场 | 0.0–4.0 | 0–1 | F1 正弦次低频嗡鸣（缓慢起伏）+ 高频玻璃泛音 shimmer（光扫时出现） | 冷、悬 | 0.5 / 2.0 光扫 shimmer；2.0 软 kick |

| C 微距 | 8.0–12.0 | 4–5 | 琶音滤波继续打开；kick 每拍 1 下（软，短尾）；细碎高频（颗粒噪声 tick） | 亲密、精密 | 每拍 kick = 每道光扫 |
| D 爆炸 | 12.0–15.5 | 6–7 | 白噪声上升 + 音高上扬的锯齿 riser；军鼓滚奏加密（很轻）；琶音升调 | 张力 | 15.0 零件悬停时 riser 到顶 |

## 六、声音设计（拟音跟着玻璃走）

- **光扫**：高频带通噪声扫频 + 几个非谐波正弦泛音（像手指划过玻璃杯口的"shimmer"），立体声从左扫到右，跟着灯条方向。
- **玻璃旋盖**：低沉的玻璃-金属摩擦（带通 300–1200 Hz 的粗糙噪声，慢速调制）+ 最后一声磁吸 click。
- **磁吸 click**：极短瞬态 + 3.2 kHz / 5.1 kHz 金属共振 + 一点低频"咚"。
- **零件爆开**：每个零件一口轻气流（低通噪声 puff），慢动作感 = 音高下移的长 whoosh。
- **合拢**：反向 whoosh 冲进 16.0，一串 5–6 个错开 15 ms 的磁吸 click + 玻璃叮（C6/E6/G6 非谐波三音）+ 808 drop。
- **光纹脉冲**：不另加音效（音乐的 kick 本身就是它的声音）；地面声波环不加声音。
- **结尾**：两次落槽 click（左、右，声像分开）；28.0 最高音玻璃叮 + 长余音。
- 响度 −14 LUFS，颗粒 0（玻璃和黑场上的颗粒会闪）。

## 七、旁白与字幕

**声线**：am_michael，speed ~0.9，低沉、克制的发布会男声。只有 4 句，全部短：
1. 8.55 *Nothing to hide.*
2. 12.45 *Every part, in plain sight.*
3. 24.6 *Aura.*
4. 25.55 *Hear the light.*

**字幕样式 = 一块磨砂玻璃**：底部居中圆角长条（高 76 px、圆角 38 px），条内是当前画面的实时高斯模糊（18 px，提亮 1.25）+ 10% 冷白罩色，1.2 px 渐变高光描边，顶边一道冰蓝 → 淡紫的细色散线；文字 Inter Tight 300、40 px、字距 1 px、近白。每句至少停留 1.9 s 且不短于语音 + 0.7 s。
结尾两句不用字幕条：它们就是画面上的产品名和 slogan（AURA 超细 200 字重 + 56 px 字距；Hear the light. 300 字重）。

**字体**：Inter Tight（OFL，Google Fonts），整片只用这一个家族。

## 八、视觉规格（摘要）

- **布光**：暗场。左右后方两根竖灯条（勾轮廓）、背后一根横灯条（地平线轮廓光）、顶部大柔光（弱）、前方低位补光（很弱）、一根移动的"光扫"灯条、一张随光纹亮度变化的冰蓝反光卡。环境贴图每帧由灯条场景重烘（PMREM）。
- **玻璃**：透明 = transmission 1 / roughness 0.015 / IOR 1.52 / dispersion 5 / 近中性衰减色；磨砂 = transmission 0.82 / roughness 0.4 / 奶白。
- **金属**：钛腰线、镀铬磁铁、拉丝钢电池、香槟色驱动振膜（同心拉丝粗糙度贴图）、石墨 PCB 带金色走线。
- **强调色**：光纹只用一组冰蓝 #62DCFF → 淡紫 #A98BFF，脉冲中心带白热核心。
- **地面**：黑色亮面，模糊镜面反射（手动每帧更新一次）+ 焦散 + 声波环。
- **后期**：2× 超采样、物理景深（微距光圈大、爆炸镜头光圈小）、辉光（只让导光 > 1.1 的亮部发光）、Neutral 色调映射（AgX 会把冰蓝洗成白）。

## 九、关卡 1 之后的变更（按审片意见与制作中发现）

| 变更 | 原方案 | 现方案 | 理由 |
|---|---|---|---|
| 充电盒开盖方式 | 旋盖绕 +X 端金属销水平旋开 | **后缘铰链翻盖**：4.5–7.6 s 缓慢立起约 99°，停在盒子后方 | 平放的旋盖像锅盖；立起来的玻璃盖被背光和背景渐变折射成一圈"玻璃光环"，正好给悬浮的耳机做背景 |
| 磨砂底座 | 暗场里是一块深灰 | 底座内加不透明发光盘 + 弱点光源，经磨砂玻璃模糊成柔光；开盖后微亮，结尾落槽后"充电"全亮 | 磨砂玻璃要"透" |
| 结尾耳机姿态 | 竖直悬浮（读成两朵蘑菇） | 悬浮时 3/4 朝向镜头，透镜正面和导光圈可见；落槽时回正 | 审片意见 |
| 爆炸视图 | 零件一条扁平直线，只占左 40% | 轴与视线夹角 40°、略上扬的纵深斜线，横跨 ~80% 画面；每个零件确定性的不同倾斜；顶部真实面光源（RectAreaLight）+ 顶前方环境柔光箱；背景深灰径向渐变 sweep；合拢后镜头顺势推近 | 审片意见 |
| 光纹 | 高斯脉冲 + 整圈底色 | 彗星形脉冲：窄高斯头 + 身后指数拖尾（4× 宽度）+ 白热核心；整圈底色压到几乎为零 | 审片意见：别整圈亮 |
| 旁白第 3 句 | "Aura." | **"Meet Aura."**（24.5 s），第 4 句移到 25.8 s | 单独一个 "Aura." 被 whisper 听成 VORA / Dora / Laura，观众也会听错；画面上补一个小字 MEET，让烧录文字与旁白一致 |
| 片尾卡 | 画面压暗 + 文字居中压在产品上 | 片名一直留在上方，署名从底部淡入，镜头同时后拉给署名让位，最后 0.6 s 淡出到黑 | 不遮挡产品，不重复出现片名 |
| pair 镜头 | 左耳机从地面以下升起（穿过地面） | 从画左飞入 | 穿地是穿帮 |
